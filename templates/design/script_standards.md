# 口播脚本标准 · 编剧 + 内核提炼师 + 留存设计师 联合验收

> **禁止** 仅把 P0 信息点串成列表即视为脚本完成——必须对 **VO mp3 听感** 与 **成片口播** 签字。  
> **双人互评：** `room/scorecards/编剧.yaml` ≥2 人 · 不同角度 · **avg ≥ 90**（铁律）。

## 必过项

| 项 | 标准 | 不通过示例 |
|----|------|------------|
| 场景入戏 | 前 5s 有**谁在哪做什么**，非数字开场 | 「300多个老客户，复购全靠Excel记」 |
| 原话/对话 | ≥**4** 句**引号对话**或用户原话转述（来自 topic_brief） | 全篇陈述句排比；**<4 条 fail** |
| 节奏 | 短句+长句交替；禁止 5 句同结构 | 连续「X靠Y」「不是让你…」模板 |
| 信息落地 | P0 融进叙事，**禁止字段名朗读** | 「购买日、周期、下次触达日、沉默标记」连读 |
| 价值锚 | 全文只出现 1 次，自然嵌入 | 与钩子重复套话 |
| 模板去重 | **不得**与上一条同骨架（见下） | D03「不是让你多买系统」→ D04 原样复用 |
| 三版差异 | v0/vA/vB **结构明显不同**，非 stub | vB 仅一行「要科学管理…」 |
| 音画同步 | 句界对齐 storyboard 节拍 | VO 念 field list 时画面在 pain |

## 禁止通过的「模板口播骨架」（出现即 reject）

```
① 数字钩子一句
② 痛点排比两句
③「不是让你多买/上系统」
④ 字段名连读（购买日、周期…）
⑤「只讲跟进不讲功效」
⑥ 讨论型 CTA
```

与上一条有 **≥3 处** 同序同句式 → **编剧 + 编导** 退稿，不得 render。

## 产出物

```
publish/{week}/Dxx-*/scripts/
├── v0.md · vA.md · vB.md    # 三版结构须不同
├── chosen.md                 # 选用理由 + 未选版本取舍
└── design/script_review.md   # pass/reject + 听感验收
```

## 门禁

- `script_review.md` 为 **reject** → 禁止 TTS / 禁止 P004 build
- 编剧不得自批 pass；须 **留存设计师**（节奏）+ **内核提炼师**（P0/原话）联签
- **`room/scorecards/编剧.yaml` avg ≥ 90**（≥2 reviewer，不同 angle）
- render 后 **编导** 听 VO 与 mp4 对齐复验 + Phase B scorecard 重评
- storyboard/动效大版本变更 → 强制 Round 4b + 编剧 scorecard 重评
- **禁止** 为卡成片时长压缩叙事；应加长 VO/片长或改分镜

## 三版最低形态

| 版 | 主形态 |
|----|--------|
| v0 | 故事/场景/纪录片向 |
| vA | 数据/反差/punch 向 |
| vB | 单场景或单原话深挖 |

任两版 ≥3 处同序同句式 → reject。vB/v0 一行 stub → reject。
