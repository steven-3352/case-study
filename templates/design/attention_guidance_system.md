> **定位：** `form_strategy` 管「每镜选哪种**表达方式**、服务哪个指标」；本层下沉一级，管「这个表达**有没有制造单一视线路径**」。

## 0. 一句话

**逐帧控制观众那只不受意志支配的眼睛落在哪。** 任一帧只许一个视线赢家；丰富全塞背景层；抓人时刻和看懂时刻分开做。

## 1. 第一性原理（为什么是"单焦点"）

- 人眼只有约 2° 的中央清晰视觉，其余是模糊余光；眼睛每秒跳动 3–4 次，**下一跳落哪由余光里的"前注意特征"自动决定**，来不及思考。
- 刷手机时，**是否划走发生在余光、发生在意识到内容之前**；余光只对**运动**和**强对比**敏感。
- 所以"一屏一主信息"不是审美偏好，是生理刚需：两个东西同等尖叫 → 眼睛乒乓 → 认知负荷飙升 → 划走。

## 2. 两根轴 · 四象限（这把尺解决"丰富 vs 干净"之争）

画面有两根**独立**的轴，别把它们手滑成一根：

- **细节密度**：稀疏 ←→ 丰富
- **焦点数**：单赢家 ←→ 多个东西同等尖叫

```
              稀疏细节            丰富细节
单焦点    死板 / 寡淡 ❌        ✅ 又抓人又清晰  ← 目标格
多焦点    平庸又分散           乱 / 画面打架 ❌
```

- 铁律①「视觉抓人、用流行梗、拒绝死板」= 防左上角（寡淡）。
- 注意力引导「单焦点」= 防右下角（打架）。
- **两个箭头都指向同一格：单焦点 + 高细节。** 它们是盟友，防的是相反的失败。
- 冲突只在你误把"加细节"做成"加赢家"时才发生。

## 3. 加料不加赢家 · 三机制

把细节加满、只让一个东西赢，靠这三招：

1. **分层** — 丰富藏在焦点的身后/周围。热梗、流行元素负责氛围与制作感（赢停划），但**压灰 + 虚化 + 不动**，退到余光当"环境"，繁而不争。
2. **分时** — 丰富和清晰**轮流**上，不必同帧。**抓人**=前 3s + 转场/二次钩子（没信息要读，尽管炸）；**看懂**=解释段（让清晰接管）。别逼每帧又抓人又好懂。
3. **梗当容器** — 让流行元素**本身就是焦点、就是主信息的载体**，而不是把真内容做好后往周围撒梗当装饰。梗当容器=丰富与焦点同体（零冲突）；梗当撒料=抢余光（右下角的乱）。

## 4. 三连问（每个"要不要加这个梗/特效"的争论，逐镜问）

1. 它会不会变成**第二个赢家**？会 → 压灰/调慢/推余光，或砍。
2. 这是**抓人时刻还是看懂时刻**？看懂时刻就别堆。
3. 这个梗能不能**当容器装主信息**，而不是飘在旁边？能就用它当主体。

> **炫技毙否测试（铁律⑦ 的可目视版）：** 一个 Three/GSAP/复杂动效镜的唯一合法性 = **它制造了一条清晰的单焦点视线路径，还是把注意力打散了？** 打散 → 不管多酷，毙。比"声明服务哪个指标"更硬，因为可逐帧目视检查。

## 5. 手法库 · 按时刻分型（A 层落地）

### 8 根杠杆（前注意特征 · 任一帧只许一个赢家）
对比隔离 · 运动（最强）· 尺寸跳变 · 颜色爆点 · 包裹/框选 · 人脸+视线 · 方向引导 · 变化/新异。

### 时刻 ①｜停划帧（前 3s · 服务 completion_3s）
**单焦点 + 拉满细节**，这帧没信息要读尽管炸。
- 一个赢家：大脸／大物件／超大钩子词，**三选一**。
- 钩子词占屏宽 ≥80%、粗体高对比描边、≤1.5 行。
- 整帧只许一处动。丰富全塞背景层（压暗+虚化+不动）。
- ❌ 三行字 + 一排图标 + 满天飞元素同时动 → 余光没赢家 → 划走。

### 时刻 ②｜解释帧（中段 · 服务 completion_rate）
**净到只剩正在被说的那一个。**
- 渐进高亮：整屏压灰，只点亮口播到的那个词/那块 UI，说到哪亮到哪。
- 圈选/放大/箭头一次只出一个，卡在口播词上出现、说完即收。
- 阅读顺序 = 入场顺序（替观众翻页）。
- 三层分诊：主标题/副信息/装饰，用明度差分诊。
- ❌ 整屏文字一次铺满、无高亮 → 不知从哪读 → 流失点。

### 时刻 ③｜交接（转场 · 反流失命门）
每个"眼睛丢失落点"= 一个流失点，必须搭桥：
- 运动路径（旧焦点飞向新焦点位置）／明度交接（A 暗 B 同时亮，别黑屏中转）／焦点跟随（zoom 推拉一镜内移动）／match cut（切前切后焦点同屏幕位置）。
- **铁律：切换压在 VO 重音词上**，视听同步。
- ❌ 硬切到全新布局、焦点跳到另一角 → 每次重新找位置 → 中段持续掉人。

### 时刻 ④｜收藏钩（服务 收藏）
引导眼睛看**结构本身**：可见编号 1/2/3、步骤连线、进度条、一张总览"地图"帧 → 传达"料多且被整理好了"。

### 时刻 ⑤｜评论钩（服务 评论）
把眼睛引向**制造缺口的元素**：被高亮的争议词/反常识数字、故意留白的问题（"你猜哪个？"）、投票式对比、可被挑刺的小点。

### 轮播专属（无运动、无时间 · 不同工具箱）
视频那套（运动/交接/卡 VO）失灵，只剩静态杠杆：每张一个赢家（尺寸/颜色/框/人脸视线）· 一张一主信息 · 阅读动线（Z/F 型）· 首图=停划帧 · 小红书走生活感图片当丰富背景层 + 大字当焦点。

## 6. 折进 form_strategy 的写法（逐镜追加 · 硬门必填）

在每个关键镜的逐镜分析里，除原有「镜头任务/候选表达/数据杠杆/推荐方案」外，**追加三行**：

```markdown
- **时刻类型：** 停划 / 看懂 / 交接 / 收藏钩 / 评论钩（本镜属哪一类）
- **单焦点：** 本镜唯一视线落点是「___」；其余元素压灰/虚化/不动，退背景层
- **加料不加赢家：** 本镜流行元素/特效 = ___，做成「容器/背景层」而非第二赢家，理由 ___
```

并在文末「门禁」勾选块补三项：

```markdown
- [ ] 每个关键镜声明时刻类型（停划/看懂/交接/收藏钩/评论钩 ≥2 类）
- [ ] 每个关键镜声明单焦点（唯一视线落点 ≥3 处）
- [ ] 高级视觉过「炫技毙否测试」：制造单焦点路径，未打散注意力
```

## 7. 门禁（fail-closed · `gate_check.check_form_strategy()`）

| 检查 | 通过标准 | 失败动作 |
|------|----------|----------|
| 必填字段 | form_strategy 含 `单焦点`、`时刻类型`、`加料不加赢家` 三个标签 | pre_render/approve FAIL |
| 时刻分型 | 出现 `停划/看懂/交接/收藏钩/评论钩` **≥2 类** | FAIL |
| 单焦点逐镜 | `单焦点` 字样出现 **≥3 处**（覆盖关键镜） | FAIL |
| 炫技毙否 | 触发高级动效时，须有"单焦点路径未打散"的声明（与 `motion_tech_plan` 联动） | FAIL |

> 执行力度：**直接硬门 fail-closed**（2026-06-26 决策）。W27 在途选题需逐条补齐上述字段方能过门。

## 8. 验收问句（形式门 · 注意力层）

> 暂停任一帧，能不能一秒指出"眼睛该看哪一个"？两个以上 → 多焦点，blocked。
> 关声音看转场，眼睛有没有一瞬间不知道该看哪 → 有则交接没搭桥。
> 这个热梗/特效，是在装信息（容器），还是飘在主信息旁边抢眼（撒料）？
> 解释段那帧，除了正在说的词，还有别的东西在动/在亮吗？

任一答"否/有" → **注意力层 blocked**，回形式策略官重做该镜。
