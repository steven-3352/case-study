# 工种互评打分 Rubric · 100 分制

> 铁律：**每位 reviewer 必须 ≥ 90，avg 必须 ≥ 90** 才 pass——**89 及以下一律 fail**，迭代至 90+。  
> 打分不是「感觉还行」，须按维度扣分并写进 `notes`。

## 通用原则

| 原则 | 说明 |
|------|------|
| 独立打分 | 两位 reviewer **不得商量后给同一分** |
| 不同角度 | `angle` 不同 = 看不同维度，不是重复挑刺 |
| 扣分要具体 | 每条 `-N` 须对应可改动作 |
| 迭代留痕 | 每轮 `optimization_round +1`，discussion.md 记录改了什么 |
| 禁止放水 | 「差不多 89」= fail，继续改 |

## 通用维度（所有工种 · 各 20 分，可叠加到 100）

| 维度 | 20 分标准 | 常见扣分 |
|------|-----------|----------|
| **结果导向** | 观众/读者会停、会懂、会想互动 | 只完成交差文件 (-10~-20) |
| **洞察消费** | 用了 topic_brief 原话/场景，非自造 | 原话未进产出 (-5/条) |
| **与上条差异** | 形态/骨架/听感不撞车 | 克隆上条模板 (-15~-25) |
| **可外发** | 敢代表账号能力 | 自己都不敢发 (-20) |
| **铁律合规** | 动效/脚本/合规门禁全过 | 触犯铁律项 (-30 直接 fail) |

---

| 禁止放水 | **89 分 = fail**；须改产出重评至 **90+** |

## 创意铁律（多 Agent 的核心目的）

> **专业 Agent 不是为了填表，是为了产出创意。** 模板式交差 = 直接 fail。

| 禁止 | 说明 | 扣分 |
|------|------|------|
| **catalog 标配交差** | 仅 punch + reveal + pain + compare 等「换皮组合」 | -20~-30，动效/形式工种 |
| **无「本条唯一」说明** | motion_wow / format_spec 写不出「为何只有这条适合」 | -15 |
| **动效与口播脱节** | WOW 不对应原话/场景 | -10 |
| **预期内不惊喜** | 观众在 D01–D03 已见过同类高潮 | -15 |

**90+ 创意标准：** 至少 **3 处** 为 **本条专属** 动效/镜头（不同视觉隐喻）；catalog **≤35%**；惊艳点须写 **「创意点：…」**（unexpected 在哪）。

## 视觉语言策展师 · 硬门禁

- **产出：** `design/design_language.md`（模板见 `templates/design/design_language.md`）
- **职责：** 从 DESIGN.md / 成熟网站视觉系统中萃取本条可执行约束：色板、字体层级、组件规则、Do/Don't、逐镜应用。
- **禁止：** 只写“高级感 / 产品感 / 干净 / 像某品牌”这类口号；禁止照抄品牌 logo、文案、专有视觉资产。
- **必须进入下游：** storyboard 或 HTML/PNG 实现须能看到 token / 组件规则被采用；否则 Phase B 由视觉设计 + 平台表现分析师退回。

### 评审 Rubric

| 项 | 分值 | 90+ 标准 | 扣分示例 |
|----|------|----------|----------|
| 参考选择 | 20 | 说明为什么该 DESIGN.md 适合本条目标 | 风格与受众/平台错位 -10 |
| Token 可执行 | 25 | 色板、字号、圆角、间距、组件均可落 HTML/PNG | 只有形容词无数值 -20 |
| 本地化改写 | 20 | 借视觉语言，不冒充品牌、不照抄品牌资产 | 直接品牌仿冒 -fail |
| 逐镜应用 | 20 | 每镜/页写清主意图、token、焦点路径、禁用项 | 只写全局风格 -15 |
| 下游验收 | 15 | 能被 storyboard、模板、forecast 检查 | 无像素验收清单 -10 |

### 角度建议

- 角度 A · 视觉系统与 token（建议：视觉设计 / 形式选型师）
- 角度 B · 平台可读性与下游兑现（建议：平台原生策划 / 动效分镜师）

## OpenMontage 制作导演 · 可选插件门禁

- **产出：** `design/openmontage_brief.md`（启用前）与 `design/openmontage_review.md`（回流后）
- **定位：** 只负责外部视频制作路线是否值得启用、如何约束、如何验收；不得替代当前项目的内容门、形式门和编导最终判断。
- **默认：** 不启用。只有 brief 中 `enabled: true` 且理由通过评分，才进入外部制作。
- **禁止：** 因“更酷 / 更电影感 / 更高级”启用；绕过 `form_strategy.md` / `design_language.md`；让 OpenMontage 改写脚本、价值锚或 CTA；直接覆盖平台目录成片。

### 启用前 Rubric

| 项 | 分值 | 90+ 标准 | 扣分示例 |
|----|------|----------|----------|
| 启用必要性 | 25 | 说明原生 P004/P007 不足在哪里，且 OpenMontage 能补足 | 只是想升级质感 -20 |
| 数据假设 | 20 | 明确服务 3s、完播、理解、收藏或评论中的一项 | 没有目标指标 -15 |
| 输入约束 | 20 | meta、script、retention、form_strategy、design_language 路径齐全 | 输入缺失仍启用 -20 |
| 画面承诺 | 20 | 0–3s / 中段 / 结尾承诺具体、可抽帧验收 | 只写“高级混剪” -15 |
| 成本与边界 | 15 | 预算、素材来源、禁止改动项、输出路径写清 | 预算不明或可直接覆盖成片 -fail |

### 回流后 Rubric

| 项 | 分值 | 90+ 标准 | 扣分示例 |
|----|------|----------|----------|
| 内容一致性 | 25 | 未改变 chosen script、价值锚、CTA、事实边界 | 新增未经验证卖点 -fail |
| 视觉兑现 | 20 | brief + design_language 的核心承诺在 mp4 中可见 | 文档写了但像素没有 -20 |
| 技术 QA | 20 | 无黑屏、静音异常、字幕错位、音频削波 | 字幕遮挡或音频盖 VO -15 |
| 素材授权 | 15 | asset_log 可追溯，AI 生成记录 provider / prompt / 成本 | 来源不明 -fail |
| 优于原生路线 | 20 | 明显提升停划、看懂、中段视频感或证据感 | 与原生路线差不多 -15，不能外发 |

### 角度建议

- 角度 A · 制作路线与成本（建议：动效技术导演 / 编导）
- 角度 B · 回流成片与平台表现（建议：平台表现分析师 / 视觉设计）

## 动效设计师 · 硬门禁

- **禁止模板式：** 不得仅将 catalog 形式 ID 排列组合交差（如 02_pain + 06_compare + 08_cta 标配三连）。
- **必须有创意：** motion_wow 须含 **≥3 条专属创意点**（不同视觉隐喻；非同一 HTML 换 data）；写清「观众为何会 unexpected 停一下」。
- **catalog 上限：** catalog 模板（02_pain/06_compare/08_cta 等）时长 **≤35%**；同 template **≤1 镜**。
- **少于 3 条专属创意 → 直接 fail**（不论技术能否 render）。

## 平台表现分析师 · 硬门禁（Phase B · render 后）

- **产出：** `design/pre_publish_forecast.md`（模板见 `templates/design/pre_publish_forecast.md`）
- **须含：** **3s 完播 + 完播率区间预估（首要）** + 视觉多样性客观计数 + go/no-go
- **内容 vs 形式分层：** 脚本可 pass 而形式 fail；**形式 fail → 禁止 approve 外发**
- **完播 C/D：** 即使形式 scorecard 90+，forecast 完播 C/D → 编导应驳回外发
- **诚实重评：** 若 scorecard 形式层 avg≥90 但 forecast 审计 fail，以 **forecast + gate_check 视觉审计** 为准

### 评审 Rubric

| 项 | 分值 | 90+ 标准 |
|----|------|----------|
| **3s/完播预估** | 35 | 有区间+依据（首镜/对标/时长），非空口 |
| 视觉多样性审计 | 25 | 专属≥3 · catalog≤35% · 无模板重复 |
| 多平台差异 | 15 | 小红书/视频号是否需改形态 |
| 与 scorecard 一致性 | 15 | 纸面 90+ 与像素一致；不一致须 fail 形式层 |
| go/no-go 可执行 | 10 | 明确「外发/改首镜/改分镜/仅图文」 |

## 90+ pass 示例（编剧 · 摘要）

```
场景：周三下午到团队；老板原话「全在小刘脑子里」；当场开 Excel「打开都怕」
原话进片：**≥4/5**（脑子/跟丢/不好意思/Excel打开都怕 等，至少 4 条）
价值锚：第25天该触达，别靠人记 — 嵌在「今天该提醒谁」
三版：v0 走访 / vA 48→11 / vB 「不好意思老发」单场景
→ 导演 93 + 内核 91 = avg 92 ✓
```

## fail 改法清单格式（notes 必填）

```markdown
## 得分：74 / 100 · fail

### 扣分
- 场景入戏 (-12)：无时间地点，「帮小团队看」过泛
- 原话 (-24)：5 条仅用 1 条；缺「Excel打开都怕」「静默流失最心疼」
- 压缩叙事 (-8)：为 29s 删第25天窗口

### 改法（下一轮必须可见）
1. 加「第25天」钉子场景 + 打开 Excel 动作
2. **≥4 条**引号原话进 chosen 稿（铁律，少 1 条即 fail）
3. 时长不够则加长至 38s，禁止再删场景
```
