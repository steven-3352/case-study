# 轻量生产模式 · lightweight_production_mode（2026-06-26 固化）

> **背景：** W27D03 一条 55s 演示型视频跑满全流程用了 ~2h、~16 个子 agent、~1.3M token。复盘发现：质量门（两道门 + 注意力硬门 + 真实性红线）该守的都守住了，但**重复功**占了三四成——从零搭渲染模板、第2轮把 15 工种全重评、决策分散多次打断。
>
> **本模式只砍重复功，不砍质量门。** 单条视频默认走轻量；遇触发条件升回全量。

## 1. 适用 / 升级触发

| | 条件 |
|---|---|
| **默认轻量** | 单条 ≤60s 视频或轮播 · 演示型/知识型 · 选题无重大争议 · 该形态已有可复用模板 |
| **升回全量** | 带货型 / 出镜型 / 形式 A/B 实验周 / 投后数据要求重做 / **新形态首条**（无模板可复用）/ 选题重大或强争议 / 用户点名要全量 |

## 2. 五条精简（逐条对应 W27D03 的浪费点）

1. **模板复用优先** — 同形态先 fork 已有 `dNN_` 场景改文案/数据/画面任务，**不从零搭**。渲染从"小前端项目"降到分钟级。仍守 `anti_homogeneity`：每镜画面任务不同、非克隆上一条（克隆即退稿）。
2. **互评增量化** — 第 1 轮全评（2 lens）；**第 2 轮只重评上轮 <90 的工种**，≥90 的沿用第 1 轮分（best-of-2 取最好），**不全员重跑**。
3. **默认单轮** — 1 轮互评即收；只有挑出硬伤（任一工种 <90 或踩红线）才开第 2 轮，**最多 2 轮，取最好往下继续**（W27D03 用户规则，固化为默认）。
4. **按需派 agent** — 洞察/留存/脚本/形式/分镜/声音/文档这类**可串行直写**，主线自己写；**只有这三类才派独立 agent**：①渲染 ②独立互评（独立性是硬要求，不能省）③需真联网的网络调研。
5. **决策批量化** — 需要用户拍板的点（标题 / 时长 / 风格 / 品牌 / 形式选型）**攒成一次 AskUserQuestion**，不分散多次打断；前期一次对齐胜过中途反复问。

## 3. 不动的（质量门全保留 · 轻量 ≠ 降标准）

- 两道门 `gate_check` fail-closed（pre_render + approve）照过。
- 洞察包 6 件、scorecard 双人独立 ≥90、注意力硬门、真实性红线、音画三件套、像素抽帧复验——**一个不少**。
- 形式门「不看仓库有什么、只看哪条更强」「炫技毙否测试」照判。

## 4. 预期效果

砍掉的是：从零搭模板、全员重评、分散提问、为省事派一堆 agent 写本可串行直写的文档。
保留的是：所有 fail-closed 门 + 真返工（互评挑出硬伤仍必须改）。
量级上：单条同形态视频应从 ~2h 压到显著更短，token 大头（渲染 + 互评）只在**真有增量**时才花。
