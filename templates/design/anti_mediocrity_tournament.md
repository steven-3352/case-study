## 一、抗平庸五步(装在"脚本/创意"这一环)

1. **不准交一稿** → N 个**不同角度**独立并行竞写(钩子先行 / 故事先行 / 反常识 / 自嘲 / 不同情绪主色…);角度必须真不同,不是同稿改字。
2. **裁判判"平不平庸"而非"好不好"**:**默认毙掉**,除非有"具体的、别人写不出的东西"。
3. **critic → 改** 循环,把地板往上顶。
4. **强 shortlist**(2–3 个都过关且不同)→ **逐拍/逐镜 best-of 合成** 或回流给人点峰值。
5. **按赌注分级**:核心脚本上全套锦标赛;边角料一稿过(对齐**轻量/全量模式**)。
   > 实装参考:ViMax"并行生成 N → 裁判选最优"。

**与 `anti_perfunctory_gates` 分工**:那道门判"够不够格/是否应付"(合规分);本门判"平不平庸/抓不抓人"(效果分)。**两道都要过**。

## 二、抓人 RUBRIC(裁判打分表 · 创作工种最低出工门槛)

### A · 前 3s 钩子(必须命中一种停划机制)
- [ ] 秘密/坦白 · 反常识/打脸 · 高风险悬念 · 冲突画面直给
- [ ] **必带**:①情绪(羞耻/脆弱/火/后怕,非中性)②好奇缺口(逼人想知道后续)
- **禁**:平铺直叙介绍背景

### B · 口播是"说话"不是"旁白"
- [ ] 短句、断句(关键处一字一顿)· 口语语气词 · 情绪落差(同条 ≥3 转折)· 每句可标"怎么念"
- **禁**:解释感受("最可怕的是…因为…")、长复合句、匀速平读、书面词

### C · 情绪曲线
- [ ] 全片有起伏图,**顶点(必炸)+ 落点(必凉/必戳)** 两锚点单独验收;不许中段一路平

### D · 传播性
- [ ] ≥2 句能被单独截成封面/评论区金句

### E · 停划裁判(出工种前必过 · 逐句盘,命中任一即打回)
1. 这句会让人划走吗? 2. 这句没情绪/是中性陈述吗? 3. 这句像旁白解说不像人在说话吗? 4. 顶点够炸吗?落点够凉吗?还是在"讲道理"?

> **达标线**:每句过 E 四问;A/B/C 全绿。不到线不准进下一工种。宁可重写,不出"合格但平"的稿。
