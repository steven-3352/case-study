# 素材库 · 真实内容原矿

给编导 / 编剧选材用:内容从**真实原矿**提炼,不从零脑补——这是治"内容敷衍 / 元叙事 / 出空气"的根。

## 什么进这里
- 真实经历、真实对话片段、真实金句、真实截图 / 场景
- **一条一个 md**,文件名 `YYYY-MM-DD-简述.md`
- **生矿即可**,别等"完美",趁新鲜就扔进来

## 什么不进(去 Hermes)
- "我是谁 / 我的方向 / 引领偏好 / 方法论" → Hermes `SELF.md` / `patterns/`
- 这里只放"能当**内容原矿**的真实片段",不放关于你的画像和通用方法

## 格式(轻量)
每条 = frontmatter(`date / source / type / status / hooks`)+ 原始材料正文。
`status`: `生矿` → `已提炼`。

## 编导怎么用
选题时**先翻这里**,优先从真材料提炼钩子 / 弧线;`material/` 里没料了,才允许脑暴新选题。

## 一句纪律
矿是矿,不是成片。提炼时挖**单个 30 秒钩子**,别把整段心路倒出来——给观众**一面镜子 + 一个真洞察**。
