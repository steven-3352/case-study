# 视频制作 19 维打分卡 · Video 19-Dimension Scorecard

> **元规则：先读 QG-RAISE-3 再用本表。**
> 每一维的「基准」都是地板（最低及格），「提升 3 档目标」才是真正的验收目标。
> 参考 `skill/quality/quality_registry.md §0 QG-RAISE-3`。

本表来源：语音厅参考视频 4 条样片逆向拆解（`docs/design/语音厅参考视频拆解分析.md`），
提炼为可复用的「任意视频」评估框架。**任何形态视频制作前先填一遍，验收时对照核查。**

---

## 使用方式

1. 制作前：逐维填写「本镜计划」，标出每维的目标档位
2. 验收时：逐维对照「提升 3 档目标」打 pass/fail，不按「能过基准吗」打
3. fail 的维度走对应工种返工，不是在成片里凑数 fix
4. 登记总得分前先跑 `QG-RAISE-3` 校准：「过了」的感觉 = 标准定低了的信号

## 19 维评估表

### D01 · 运镜 Camera Movement

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 镜头运动存在且已命名（推/拉/摇/跟/环绕） |
| **提升 3 档目标** | 每个运动量化（速度 ft/s + 持续帧数 + 起止关键帧），与情绪锚点或留存节拍绑定，无「默认运动」 |
| **常见踩雷** | 写了「Ken Burns」效果名但渲染后人物位移 <4% 画面宽，肉眼判断为静止（PPT 感）；效果名≠已实现 |
| **工种归口** | 动画导演 → motion_storyboard.md `camera_motion` 字段 |

---

### D02 · 动效 Animation / Motion

| 层级 | 描述 |
|---|---|
| **基准（地板）** | UI/图形元素有入场/出场动画 |
| **提升 3 档目标** | 每 2–4s 必有一次明确视觉变化；缓动曲线与情绪匹配（紧张→ease-in，释放→ease-out）；每个动效声明服务哪项留存指标（停划/理解/收藏） |
| **常见踩雷** | 动效存在但从静止角度看不出变化；opacity fade 充当「有动效」 |
| **工种归口** | 动画导演 + 动效技术导演 → motion_storyboard.md + motion_tech_plan.md |

---

### D03 · 特效 VFX / Visual Effects

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 指定特效已应用 |
| **提升 3 档目标** | 每个特效标注数据杠杆（停划/理解/情绪中的哪一项）；特效与光照一致；无 AI 生成伪影/接缝 |
| **常见踩雷** | 装饰性特效无目的声明；生成视频接缝闪烁未做 gate_check 拦截 |
| **工种归口** | 动效技术导演 → motion_tech_plan.md |

---

### D04 · 包装 Motion Graphics / Packaging

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 标题卡、字幕条、品牌标识存在 |
| **提升 3 档目标** | 包装出现/退场时机与节拍表同步；无纯装饰元素；视觉层级清晰（主信息/副信息/标识不争抢） |
| **常见踩雷** | 全屏白字+暗色背景 = AI 视觉套路；禁霓虹色表未检查 |
| **工种归口** | 视觉设计 + 视觉语言策展师 → design_language.md |

---

### D05 · 转场 Transitions

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 片段间有转场，不是硬切 raw |
| **提升 3 档目标** | 每种转场类型服务一个目的（L-cut→连续感；match-cut→视觉押韵；jump-cut→紧迫感）；无「默认统一 fade」；相邻 clip 真实渲染帧接缝（禁用原始静帧） |
| **常见踩雷** | 不分情绪一律淡入淡出；clip 拼接接缝用原始静帧而非相邻渲染帧（帧锁接缝铁律） |
| **工种归口** | 剪辑 + 动效技术导演 |

---

### D06 · 卡点 Beat Sync / Timing

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 肉眼大致与音乐节拍对齐 |
| **提升 3 档目标** | 帧级精准对齐（±1 帧内）；通过 beat 检测（librosa/aubio）量化；视觉变化时刻与音乐 transient 同帧 |
| **常见踩雷** | 目测同步，实际偏差 100–300ms，冲击感消失；BGM 切换未在换场瞬间 |
| **工种归口** | 声音设计师 + 剪辑 → audio_plan.yaml |
| **待建** | beat 检测模块尚未实现（librosa 集成列为 next sprint） |

---

### D07 · 音频设计 Audio Design

| 层级 | 描述 |
|---|---|
| **基准（地板）** | VO + BGM/SFX 存在；QG-MEDIA-HEAD-RMS 通过（前 6s RMS ≥ -25dB） |
| **提升 3 档目标** | SFX 密度 ≥ 画面变化密度（每次切换/金句/CTA 配 SFX）；无死区 >1.5s；音频情绪弧线镜像视觉弧线；VO 全程覆盖（密 VO 无 BGM 模式下 ≥85% 覆盖） |
| **常见踩雷** | 视觉精良但转场静音 = PPT 感；BGM 有但 SFX 全无；死区超 3s 拖走观众 |
| **工种归口** | 声音设计师 → audio_plan.yaml |

---

### D08 · 节奏与信息密度 Pacing & Info Density

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 内容前进，无明显死板 |
| **提升 3 档目标** | 信息密度匹配平台（抖音 = 每 2–4s 一条关键信息）；每个「空」秒有功能（呼吸/情绪沉淀/CTA 铺垫）；retention_beat_sheet 作严格时基 |
| **常见踩雷** | B-roll 铺10s 无新信息；信息密度平台统一不做适配 |
| **工种归口** | 留存与互动设计师 → retention_beat_sheet.md |

---

### D09 · 排版与图形 Typography & Graphics

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 文字可读，无遮挡 |
| **提升 3 档目标** | 单屏单一主信息；字体层级对比 ≥ 3× 大小/粗细差；出图后目视检查叠层遮挡；大字完整可见，标题/拟声/CTA 互斥布局 |
| **常见踩雷** | 字幕+CTA+标题同时出现在底部；文字跑出安全区被平台 UI 遮盖 |
| **工种归口** | 视觉设计 + 视觉语言策展师 |

---

### D10 · 色彩与影调 Color & Tone

| 层级 | 描述 |
|---|---|
| **基准（地板）** | QG-PALETTE-NEON 通过（禁霓虹色/蓝紫占比 ≤5%） |
| **提升 3 档目标** | 色板在 design_language.md 声明；镜间色彩一致（HSL H 偏差 ≤10°）；色彩服务情绪弧（暖色=信任/活力，冷色=冷静/分析） |
| **常见踩雷** | AI 默认深色画布 + 冷蓝配色 = AI 视觉套路（禁 AI 味深色开发者风）；镜间白平衡不一致 |
| **工种归口** | 视觉语言策展师 → design_language.md |

---

### D11 · 光影 Lighting

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 内容可见，无死黑/过曝 |
| **提升 3 档目标** | video prompt 中声明光线 K 值（3200K=暖、5600K=自然、8000K=冷）；阴影有意为之（赋予立体感）；跨镜头光源一致 |
| **常见踩雷** | K 值未指定 → 模型随机 → 镜间色温漂移；逆光人脸无细节 |
| **工种归口** | 动画导演 → motion_storyboard.md `lighting_k` 字段 |

---

### D12 · 景别与构图 Shot Size & Composition

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 9:16 画布填满 |
| **提升 3 档目标** | 景别多样（特写/中景/全景轮换）；三分法构图；角色 anchor 声明（中/左/右）并跨镜维持；动态再取景与节拍绑定 |
| **常见踩雷** | 全片同一景别同一构图 = 静止感；9:16 上下留黑边 |
| **工种归口** | 摄像/视觉 + 动画导演 |

---

### D13 · 一致性 Character / Visual Consistency

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 跨镜同一角色 |
| **提升 3 档目标** | 参考图驱动生成（角色设定图 → images.edit 逐镜改姿态，禁盲 t2i）；服装/场景跨镜一致（故事需要的变化须标注）；无 face morphing |
| **常见踩雷** | 每镜独立 t2i → 脸型/服装每镜漂移；没有角色设定图就进入生成 |
| **工种归口** | cap-image-gen `--ref` 模式；动画导演声明 anchor |

---

### D14 · 剪辑逻辑 Editing Logic

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 剪辑不让观众困惑 |
| **提升 3 档目标** | 每个剪切点来自 retention_beat_sheet，不是「有素材就剪」；跨接缝方向不反向（帧锁铁律）；连续性错误验收前标记清零 |
| **常见踩雷** | 因「有 clip 可用」而剪，不是因叙事需要；接缝两侧帧不是相邻渲染帧 |
| **工种归口** | 剪辑工种 + 动效技术导演 |

---

### D15 · 视线引导 Visual Attention / Eye Tracking

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 关键信息可见 |
| **提升 3 档目标** | 每镜声明视线入口；Z/F 型注意力路径应用；无竞争热区（同时多处吸引注意力）；发布前「眼球测试」（关键点是眼睛想去的地方吗？） |
| **常见踩雷** | 字幕在底 + 图形在顶 + 运动在中 → 注意力分裂，观众什么都没记住 |
| **工种归口** | 视觉设计 + 留存与互动设计师 |

---

### D16 · 平台适配 Platform Adaptation

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 9:16，时长在平台上限内 |
| **提升 3 档目标** | 平台原生钩子风格（抖音=大字冲击+运动，小红书=生活质感纹理）；安全区检查（字幕高出底边 180px+）；时长为算法优化（抖音 45–60s，小红书 ≤60s，视频号 60–90s） |
| **常见踩雷** | 单视频不做适配直接三平台发；字幕被底部 UI 遮盖 |
| **工种归口** | 剪辑 + 运营/增长 |

---

### D17 · 无障碍 Accessibility

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 字幕存在 |
| **提升 3 档目标** | 字幕时间偏差 ≤200ms；对比度 ≥4.5:1；VO 100% 覆盖；无关键信息「仅凭音频」传达 |
| **常见踩雷** | 自动字幕 +800ms 滞后；情绪高潮字幕缺失；低对比度白字叠白底 |
| **工种归口** | 剪辑 |

---

### D18 · 工程规范 Engineering Standards

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 无报错渲染完成 |
| **提升 3 档目标** | SHA-256 记录于 scorecard（MP4 变化即失效重审）；Phase B 前跑 ffprobe 机器 QC（冻帧/黑帧/异常静音/规格/音轨）；输出路径按 content_id/scene_id 隔离；临时文件清理 |
| **常见踩雷** | 共享输出目录 → 并行项目互覆；无 SHA-256 → scorecard 静默失效；先出成片后跑 QC（应反过来） |
| **工种归口** | 动效技术导演；cap-* 技能层 |

---

### D19 · 情绪曲线 Emotional Arc

| 层级 | 描述 |
|---|---|
| **基准（地板）** | 视频有开头/中间/结尾结构 |
| **提升 3 档目标** | 情绪弧映射至 retention_beat_sheet（入场紧张→累积→释放→CTA）；VO 情绪标记量化（urgency/relief/curiosity）；与 hook_benchmark.md 参考视频对标验证 |
| **常见踩雷** | VO 语气平铺如产品说明书；情绪峰值在中段消失，观众后半段滑走 |
| **工种归口** | 编剧 + 留存与互动设计师 + 声音设计师 |
