# 开发卡 02 · 关键帧生成（N10）

> 只读本卡。你要交付「每镜出一张关键帧」：展示镜=产品原图保真合成，生成镜=AI 首帧。**脚本已经写好，你多半只是调用 + 补边角**。

## 目标

按分镜 `shot.type` 逐镜出关键帧 PNG，写进 `keyframes_index.yaml`，支持单镜/子集增量重出。

## 直接用这些脚本（已存在，别重写）

- 主函数：`ad-agent/conductor/tools.py::gen_keyframe(inputs, out_dir, params, prompt_file)`（`pipeline.py` 的 `03_keyframes` 已连线）。**它已经实现了下面两条链路**，你先跑它，不要另写。
- 图像 provider：`tools.py::_image_provider()` → `mvstudio.providers.image_openai.OpenAICompatibleImageProvider`（模型 `gpt-image-2`，强制 HTTPS）。调用 `provider.generate(prompt, references=[], size, quality)`。
- 两条合成链路（都在 `ad-agent/conductor/media.py`，底层复用 `mvstudio.media`）：
  - `compose_product_on_background(bg_bytes, product_path, canvas, margin_ratio=0.12)` → **display 镜**：AI 只画纯背景，产品原图 `paste` 上去，**像素不重绘**。
  - `fit_image_to_canvas(src_bytes, canvas)` → **generated 镜**：AI 首帧 cover 到画布。
- 画幅：`media.aspect_spec(aspect)` 给 `image_size`（如 `1024x1536`）与 `canvas`（如 `(720,1280)`）。
- 摘要：`media.sha256_bytes(data)`。

## 两条链路（`gen_keyframe` 已按 `shot.type` 分流）

| shot.type | 做法 | 商品保真 |
|---|---|---|
| `display` | `provider.generate(纯背景提示)` → `compose_product_on_background` | **构造级 100%**（产品区=原始字节） |
| `generated` | `provider.generate(首帧提示, references=可选产品图)` → `fit_image_to_canvas` | 中（人物/场景/过渡，非关键商品面） |

## 铁律

- **关键商品面 / Logo / 包装文字**：一律走 `display` 合成路径，**禁止**靠 `generated` 逐帧生成（会漂移）。
- 每张关键帧写 `digest = sha256_bytes(data)`；`params["only"]` 给镜号集合时只出那几张、增量并进 `keyframes_index.yaml`。
- provider 只从 `_image_provider()` 拿，别在别处 new。

## 输入 / 输出

- 输入：`02_storyboard/shots.yaml`（每镜含 `type`/`motion`/`image_prompt`/`product_ref`）、`00_intake/manifest.yaml`（图片 + `aspect_ratio`）。
- 输出：`03_keyframes/<镜号>_keyframe.png` + `keyframes_index.yaml`。

## 完成判据（Done）
