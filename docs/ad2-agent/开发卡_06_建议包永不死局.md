# 开发卡 06 · 建议包 · 永不死局（横切所有工具）

> 只读本卡。你要交付「任何走不下去的地方，都返回结构化建议包，而不是一个 error 字符串」。这是横切规范，写工具时都照它。

## 目标

任一节点无法继续 → 返回 `blocked_with_recommendations`：说清原因、至少两个可选项（或说明为什么只有一个）、推荐项、各自影响与失效范围、从哪个节点恢复。

## 直接用这些脚本（已存在）

- 统一返回：`ad-agent/conductor/contracts.py::ToolResult(ok, outputs, error, meta)`；错误用 `error={code,message,hint}`。
- 生成错误壳：`from mvstudio.media import err`；`media.err(code, message, hint)` 直接给 `ToolResult(ok=False, error=...)`。
- 状态：`contracts` 里新增/复用 `blocked_with_recommendations`（若没有就加常量，别散落字符串）。

## 建议包结构（写进节点产物，如 `qa/shot-XX.yaml` 或步骤 `_meta`）

```yaml
status: blocked_with_recommendations
node: N12
reason_code: PRODUCT_IDENTITY_DRIFT
plain_reason: 商品包装文字连续三次漂移
evidence: [qa/shot-04-attempt-3.yaml]
options:
  - id: O1
    action: 改为受控商品图层合成（display 路径）
    expected_visual_quality: high
    product_fidelity: high
    cost_delta: medium
    invalidates: [N11_SHOT04, N13, N14]
  - id: O2
    action: 限制商品为正面定帧展示
    expected_visual_quality: medium
    product_fidelity: high
    cost_delta: low
recommended_option: O1
recommendation_reason: 保住包装准确性且不降整片完成度
resume_from: N11_SHOT04
```

## 触发点（常见）

物料不完整 / 商品无法自然植入 / 风格·时长·预算冲突 / Seedance 生成失败 / 单镜三次仍不过 / provider 不可用 / 内容合规或商品准确性不过 / 骨架路线覆盖率不达标（`开发卡_04`）/ 成本触顶（`开发卡_07`）。

## 铁律

- **禁止只返回 error 字符串**，也禁止「再生成一次试试」这种无效建议。
- 每个 option 必须带效果、商品保真、成本、时间、失效范围。
- 没有高质量路线时，可以诚实推荐「换参考 / 换商品 / 换故事 / 终止」——这也是合法建议。
- 不把所有失败自动降级到低质量成片（违反 PRD §4.6）。

## 完成判据（Done）

- [ ] 每个可能阻塞的工具，失败路径都产出上面结构（≥2 option 或注明为何只有 1）。
- [ ] `recommended_option`、`resume_from` 必填且指向真实可恢复节点。
- [ ] 建议被采纳后能从 `resume_from` 正确续跑（与 `开发卡_05` 联调）。

## 自测

构造一个必失败输入（如缺产品图的 display 镜），断言 `ToolResult.ok is False` 且 `error` 含 `code/message/hint`，产物里有 `options`（≥2）与 `resume_from`。
