## 铁律

- **State 是状态唯一写入者**：LLM/工具都不得直接改 `state.json`、伪造批准、跳过拍板、把「生成成功」当验收。
- 局部变化只失效受影响节点，不整盘重跑；也不得沿用已失效的下游产物。
- 单项目默认单写会话；第二个会话只读或需显式接管。
- 每次对话与状态变更写追加式事件日志（`conversation.jsonl` / 事件流）。
