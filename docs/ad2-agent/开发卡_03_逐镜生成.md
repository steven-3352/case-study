# 开发卡 03 · 逐镜视频生成（N11）

> 只读本卡。你要交付「每镜关键帧 → mp4」：i2v 镜走 Seedance（可带多模态参考），静态/推拉镜走本地 ffmpeg（免费）。**脚本已写好，含多模态参考已接线**。

## 目标

按 `motion` 逐镜出 mp4，写进 `shots_index.yaml`，支持单镜/子集增量重跑。纯本地镜不碰付费服务。

## 直接用这些脚本（已存在）

- 主函数：`ad-agent/conductor/tools.py::gen_video(inputs, out_dir, params, prompt_file)`（`pipeline.py` 的 `04_shots` 已连线）。
- i2v provider：`from mvstudio.providers.seedance import SeedancePort, SeedanceTask, SeedanceFrame`。
  - `provider = SeedancePort.from_env()`；`result = provider.generate(task)`；`result.video_bytes` 写盘。
- 本地免费镜（`ad-agent/conductor/media.py`）：`still_to_mp4(png, out, seconds, canvas)`（static 定格）、`ken_burns_to_mp4(...)`（缓慢推近）。
- 画幅：`media.aspect_spec(aspect)["canvas"]` / `["video_ratio"]`。

## `motion` 分流（`gen_video` 已实现）

| motion | 路径 | 花钱？ |
|---|---|---|
| `static` | `media.still_to_mp4` | 否（本地 ffmpeg） |
| `ken_burns` | `media.ken_burns_to_mp4` | 否 |
| `i2v`（默认 / generated 镜） | `SeedancePort.generate(SeedanceTask)` | 是（Seedance） |

> 只要有一镜是 i2v/generated 才初始化 Seedance；纯本地镜不 new provider、不扣费。

## 多模态参考（Seedance 2.0，已接线）

`SeedanceTask` 已支持（`gen_video` 从关键帧条目透传）：

```python
task = SeedanceTask(
    shot_id=kf["id"], model=model, prompt=prompt,
    duration_seconds=max(4, min(15, dur)),
    first_frame=SeedanceFrame(content=data, sha256=media.sha256_bytes(data)),
    aspect_ratio=video_ratio, resolution="720p",
    reference_video_url=kf.get("reference_video_url", ""),   # 运镜参考（先去身份化，见 开发卡_04）
    reference_audio_url=kf.get("reference_audio_url", ""),   # 背景音；provider 侧有 audio 时自动开 generate_audio
    reference_image_urls=tuple(kf.get("reference_image_urls") or ()))  # 首/尾帧等参考，≤4 张
```

- `ad2-agent` 的参考媒体可使用服务器 Nginx 提供的 HTTP(S) URL；该许可由任务字段 `allow_http_reference_urls=true` 显式开启，不改变 `ad-agent` 的 HTTPS 默认门禁。
- provider 自动把 `content[]` 按「images → video → audio」顺序拼装（与实测 curl 一致），首帧仍走顶层 `image`。

## 铁律

- Seedance 服务端 API URL 必须 HTTPS。`ad2-agent` 参考媒体可用 HTTP(S)；`ad-agent` 仍默认要求 HTTPS。两个入口不得互相继承该约束。
- `reference_video_url` 默认应是**去身份化后的骨架视频**（`开发卡_04`），不是原片直传。
- `duration_seconds` 夹在 4–15s。
