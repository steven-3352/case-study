# 开发卡 07 · 成本记录与触顶（§17.4）

> 只读本卡。你要交付「每个付费任务记成本、估不准要知情确认、预算触顶暂停不丢产物」。

## 目标

Seedance 付费任务留成本轨迹；无法精确估算时先让用户知情确认；`hard_limit` 命中时暂停后续、保留已成片、给三选一建议。

## 直接用这些脚本 / 数据（已存在）

- 省钱封顶：`from mvstudio.media import max_shots`；`max_shots("AD_MAX_SHOTS")`（环境变量 `AD_MAX_SHOTS=2` → 镜头数封顶，贯穿 03/04/05）。
- 付费入口：`ad-agent/conductor/tools.py::gen_video`（只有 i2v/generated 镜初始化 Seedance）。成本记录挂在这里。
- provider 结果：`SeedanceResult`（`开发卡_03`）——把 `actual_cost`（若返回）写进 jobs 记录。
- 预算字段：`project.yaml.budget: {currency, hard_limit, spent}`。

## 数据结构（jobs 记录，写进 `.adfilm/jobs/` 或步骤 `_meta`）

```yaml
job_id: job-001
node: N11
shot_id: SH04
provider_id: seedance-2.0
idempotency_key: ""        # 退出重进不重复扣费（与 开发卡_05 联动）
status: queued|running|done|failed
estimated_cost: null       # 估不准时为 null
actual_cost: null
submitted_at: ""
```

## 三种处理

1. **估不准 → 知情确认**：`estimated_cost` 拿不到时，展示历史同类镜 `actual_cost` 区间（从既有 jobs 汇总）+「无法精确估算」，等用户确认（退出码 2）再提交。确认粒度：逐镜确认 / 整批一次确认触顶即停。
2. **批中触顶**：`spent + 本镜估算 > hard_limit` 时，当前镜跑完即暂停后续，进 `blocked_with_recommendations`（`开发卡_06`），给：
   - 保留继续（提额后从暂停镜续跑，不重复扣费）
   - 保留降档（剩余 i2v 镜改 `static`/`ken_burns` 本地免费路径）
   - 保留终止（存已产出镜 + jobs，标记暂停）
3. **随时可查**：`/cost` 显示已花费 / 预估 / 余额。

## 铁律

- 触顶暂停**不取消**已提交的远程任务；保留幂等键与已下载产物。
- 触顶**不得**自动降到低质量成片（违反 PRD §4.6 / §3）。
- 成本轨迹不泄漏密钥/签名 URL（脱敏）。
