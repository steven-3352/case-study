# 开发卡 04 · 参考视频去身份化（喂给 Seedance 的运镜参考）

> 只读本卡。你要交付「把任意人物视频 → 无脸骨架视频」，用作 Seedance 的运镜/动势参考。**底层函数已存在，你只是调用 + 接一道覆盖率门**。

## 目标

当镜头只需要动作轨迹时，可把参考视频转成骨架视频；需要完整人物、场景或动作细节时可直接使用原片。路线仅由制作效果和模型适配决定。

## 直接用这些脚本（已存在，别重写 CV 逻辑）

- 薄封装：`ad-agent/conductor/media.py::pose_reference_from_video(source, out_path, model=None, label=True)` → 返回 `{"output","frames","detected","coverage","fps"}`。
- 底层：`mvstudio.media.generate_pose_reference(source, out_path, min_coverage=0.65, label=True)`（MediaPipe 只渲染躯干/四肢骨架，索引 11–32，**不含面部**）。返回 `PoseReferenceResult(output, frames, detected, fps, width, height)`，`.coverage = detected/frames`。
- 失败类型：`from mvstudio.media import`（惰性）`PoseReferenceError`——覆盖率低于 `min_coverage` 或没检测到主体时抛。

## 流程（你要接的那道门）

1. 调 `pose_reference_from_video(参考视频, 骨架out.mp4)`。
2. `PoseReferenceError` → **不要**继续，返回建议包（`开发卡_06`）：换参考片段 / 改镜头设计 / 放弃运镜复制。
3. 成功 → 把 `output` 骨架视频放到服务器 nginx 公网目录，得到 https URL，作为 `reference_video_url` 传给 `gen_video`（`开发卡_03`）。

## 铁律

- **按制作需求选择**：骨架参考与原片直传都是合法路线；骨架用于只保留动作轨迹，原片用于需要完整人物、场景或动作细节的镜头。
- 用户要求复刻原视频人物、服装、场景或内容时，骨架路线不等价，禁止自动切换。原片被 provider 拒绝后必须暂停并由用户确认；只有用户明确接受“仅保留动作轨迹”时才可使用骨架。
- 覆盖率门 `min_coverage=0.65` 不达标即判「素材缺清晰全身主体」，进建议包。
- 绑定原创性（PRD AC-05）：骨架天然剥离长相，降低「仅换像素」的复刻风险；人物/事件/台词/镜头仍不得与参考连续一一映射。
- CV 依赖（cv2/mediapipe）是惰性导入：缺依赖时**只有真正调用**才报友好错误，别在 import 期崩。

## 输入 / 输出

- 输入：一段人物视频（本地路径）。
- 输出：骨架 mp4（无脸）+ `{coverage, frames, detected, fps}` 元数据；覆盖率不足则结构化错误。
