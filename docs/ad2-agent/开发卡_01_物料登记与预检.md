# 开发卡 01 · 物料登记与预检（N00–N01）

> 只读本卡。你要交付的是「收下物料 → 哈希登记 → 三级问题分级 → 输出预检报告」，**不要**读整份 PRD。

## 目标

用户给 `参考视频 + 多张商品图 + 商品文本 + 新视频要求` 后：登记为清单、算哈希、按 `blocking/fixable/advisory` 分级出预检报告，缺关键物料时**不许进入制作**。

## 直接用这些脚本（已存在，改/接即可）

- 步骤实现：`ad-agent/conductor/tools.py::intake_validate(inputs, out_dir, params, prompt_file)`（`pipeline.py` 的 `00_intake` 已连线）。当前它已做：收产品图/文本、读图片尺寸、出 `manifest.yaml` + `validation_report.md` + `brief.md`。
- 哈希：`from mvstudio.media import sha256_file, sha256_bytes`（**别自己写 hashlib**）。
- 图片尺寸/校验：`ad-agent/conductor/media.py::image_size(path)`、`IMAGE_EXT`、`normalize_aspect`。
- 目录骨架：`ad-agent/conductor/layout.py`（`_input/`、`_meta/` 已自动建）。
- 返回结构：`from conductor.contracts import ToolResult`。

## 你要新增的 delta（在 `intake_validate` 内补）

1. **参考视频登记**：把参考视频路径、时长（`media.video_duration_seconds`）、分辨率写进 `manifest.yaml`，记 `sha256_file`。
2. **SKU 一致性 / 视角覆盖**：多张商品图缺背面/侧面 → `fixable`（示例见下）。
3. **三级问题分级**输出到 `preflight-report.yaml`：

```yaml
result: conditional_pass          # pass | conditional_pass | blocked
blocking_issues: []               # 关键文件不可读 / SKU 冲突 / 必填缺失
fixable_issues:
  - id: MAT-004
    issue: 缺少商品背面图
    impact: 无法可信展示超过正面 60 度旋转
advisory_issues: []
recommended_option: 补充背面图片
resume_from: N01_material_preflight
```

## 输入 / 输出

- 输入：项目根下 `reference/`、`product/`、`brief/` 里的原始文件（**只读**，默认不可覆盖）。
- 输出（写进 `00_intake/`）：`manifest.yaml`、`validation_report.md`、`brief.md`、`preflight-report.yaml`。

## 铁律

- 原始文件只读 + 记哈希；一切派生产物写步骤目录，**不得覆盖原件**。
- `blocking` 未清零，工具 `ToolResult.ok=False` 并给建议包（见 `开发卡_06`），控制器不会放行下一步。
- 底层功能一律 import，不复制。

## 完成判据（Done）

- [ ] 参考视频 + 商品图 + 文本都登记进 `manifest.yaml` 且带 `sha256`。
- [ ] 关键文件不可读 → `result: blocked` 且工具返回 `ok=False`。
- [ ] 缺背面图这类 → 进 `fixable_issues`，流程可在用户确认风险后继续。
- [ ] `preflight-report.yaml` 三级分级齐全、含 `resume_from`。
