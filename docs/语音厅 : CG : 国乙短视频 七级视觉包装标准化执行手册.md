# 一、全局强制通用规范（所有等级必须遵守，违规直接判定成片不合格）
## 1.1 图层固定排序（自上而下不可调换）
1. 字幕信息层
2. 光影层：轮廓光、扫光、局部提亮、光晕
3. 主体层：人物CG、角色立绘【最高保护级，严禁长期遮挡五官】
4. 氛围动态层：粒子、流体、薄雾、光斑
5. 衍生背景层：原图模糊副本、渐变叠加层
6. 底层：原始背景图片

## 1.2 素材基础规范
1. 背景图分辨率≥1080P，比例严格9:16，无水印
2. 背景三大基础类型
- A类【具象远景CG】：星空、街道、海面、建筑、风景；物体轮廓清晰，自带景深
- B类【抽象氛围图】：渐变、星云、雾面肌理、流体色块；无清晰实体，留白充足
- C类【人物插画背景】：画面内置角色、特写构图；画面元素密集，留白偏少

## 1.3 BGM卡点分级定义
1. 重鼓点：允许触发波纹、闪光、镜头推进、光影爆发（仅限L3/L4/L6/L7）
2. 弱节拍：适配持续动态：雾气流动、缓慢扫光、呼吸缩放（L1/L2/L5持续运行）
3. 人声重音/停顿：仅允许局部光影微调，禁止剧烈镜头运动（语音MV硬性要求，保障字幕可读）
4. 乐句分割线：所有镜头转场、画面大变化，优先对齐乐句结尾

## 1.4 防「效果添加但肉眼无感」强制校验工序（成片必检）
1. 开关对比测试：开启/关闭全部动效，肉眼必须清晰识别差异；无差异→上调参数强度20%
2. 双端预览：电脑预览合格后必须手机终审；电脑可见、手机失效，参数+20%
3. 动态基准要求：所有动画必须具备【静态基准态+激活变化态】，禁止全程恒定参数
4. 禁止重复叠加同类效果（多层薄雾、多层柔光互相抵消，浪费渲染资源）

## 1.5 全局禁止清单
❌ 禁止全屏长时间闪白、高频频闪
❌ 禁止多层柔光、雾效重复叠加
❌ 禁止密集鼓点连续触发强特效（廉价短视频观感）
❌ 禁止特效大面积覆盖人物面部与字幕区域

# 二、分级完整执行标准（等级+情绪支线｜背景选型+固定参数+卡点规则+无感修正方案）
## L1 弱包装｜流水线保底级
定位：铺垫段落、长叙事片段，低视觉冲击，优先保障字幕可读
### L1-A 舒缓治愈｜温柔独白、轻声对话
1. 推荐背景：A类柔和风景CG / B类浅色系低饱和抽象图
2. 背景处理：原图复制一层高斯模糊8；叠加低饱和渐变，透明度12%
3. 固定动效参数
- 全局呼吸缩放：±1.5%，周期6s，缓入缓出
- 字幕：2px黑色描边，淡入动画0.6s
4. BGM卡点规则
持续动画匀速运行，不绑定单节拍；镜头转场对齐乐句末尾
5. 无感故障修正
看不出镜头运动→缩放调整至±1.8%；氛围感不足→渐变透明度提升至15%

### L1-B 平稳叙事｜旁白、信息量密集对话
1. 推荐背景：A类清晰场景原画，优先保留画面细节
2. 背景处理：高斯模糊5，不叠加渐变底色
3. 固定动效参数
- 无全局缩放；静态柔边暗角10%
- 字幕：半透白底衬底+2px黑描边，无入场动画
4. BGM卡点规则：无动态特效，转场使用硬切+0.3s微叠化
5. 无感故障修正：画面单调，增加固定暗角

### L1-C 清冷压抑｜虐向前期铺垫、低沉情绪片段
1. 推荐背景：B类冷色暗调渐变、雾感深色背景
2. 背景处理：原图副本模糊12；冷色调渐变叠加，透明度18%
3. 固定动效参数
- 单向缓慢平移镜头，不启用缩放
- 字幕：深灰色2px描边
- 转场：叠化0.8s
4. BGM卡点规则：长周期缓慢运动，不绑定鼓点
5. 无感故障修正：氛围偏弱，渐变透明度上调至20%

## L2 中等包装｜主流常规成片标准
定位：情绪缓慢爬升，短视频主体叙事段落
### L2-A 温柔甜感｜告白片段、抒情MV日常段落
1. 推荐背景：A类黄昏、花海远景 / B类暖调柔光星云
2. 背景处理：模糊副本正常启用，不大幅改动原图色调
3. 固定动效参数
- 双尺寸星光粒子，透明度18%匀速漂浮
- 镜头：横向平移 + ±3%呼吸缩放，周期3s
- 横向扫光单次时长4s，透明度13%
- 字幕：微弱外发光，鼓点弹跳幅度≤4%
4. BGM卡点规则
扫光按照4小节循环移动；字幕弹跳绑定弱节拍；镜头起点对齐乐句开端
5. 无感故障修正
扫光不可见→透明度上调至16%；粒子不明显→透明度22%

### L2-B 平稳剧情｜CG主线推进、中等情绪切片
1. 推荐背景：A类中远景场景CG
2. 背景处理：轻度模糊，不添加高密度氛围素材
3. 固定动效参数
- 薄雾透明度12%，无粒子
- 3s一次缓慢推拉镜头
- 仅镜头切换瞬间添加一次柔光提亮
- 字幕静态，无动画
4. BGM卡点规则：运镜横跨多个节拍，拒绝一拍一动
5. 无感故障修正：画面静态感过重，每5s增加一次慢速扫光

### L2-C 克制伤感｜遗憾、隐忍情绪片段
1. 推荐背景：B类灰调雾面抽象图、朦胧雨夜远景
2. 背景处理：模糊图层正常开启
3. 固定动效参数
- 下落细碎光斑，透明度15%
- 持续慢速向内推镜
- 单侧轮廓光透明度8%
- 字幕淡入0.5s；转场长叠化0.7s
4. BGM卡点规则：动态缓慢变化，不跟随密集节拍
5. 无感故障修正：氛围感不足，轮廓光上调至11%

## L3 较强包装｜段落高潮（全片时长占比≤20%）
定位：台词高潮、歌曲副歌，可控强视觉冲击
### L3-A 甜向高光｜告白心动名场面
1. 推荐背景：优先B类流体柔光抽象背景（留白充足）
⚠️ 若选用C类人物插画背景：波纹特效仅允许放置画面边缘
2. 背景处理：双层背景架构，底层重度模糊，上层保留原图主体；背景原图禁止亮度过高
3. 固定动效参数
- 卡点波纹扩散强度25
- 人物局部提亮15%（禁止全屏提亮）
- 动态暗角：10%缓慢收缩至5%
- 字幕双层描边、低速柔和流光
- 转场：涟漪过渡 / 弱闪白峰值0.15s
4. BGM卡点硬性规则：波纹、局部提亮精准绑定人声重音、重鼓点
5. 无感故障修正：波纹不清晰→强度调整至30

### L3-B 燃向高光｜CG战斗、激昂台词
1. 推荐背景：A类宏大全景远景（夜空、建筑群、旷野）
2. 背景处理：双层背景；底层添加低透明度放射光纹12%
3. 固定动效参数
- 间歇闪光0.2s，仅在画面空白区域触发，避开人物
- 呼吸缩放±3.5%
- 字幕弹性淡入；转场径向缩放
4. BGM卡点：闪光绑定重鼓点
5. 无感故障修正：冲击力不足，光纹透明度上调至16%

### L3-C 虐向爆发｜哭腔独白、情绪崩溃片段
1. 推荐背景：B类深色浓雾、低亮度渐变背景
2. 背景处理：原图副本模糊18，叠加流动雾层透明度15%
3. 固定动效参数
- 光晕向内收缩动画
- 动态暗角5%放大至12%
- 字幕透明度80%↔100%呼吸变化
- 转场色彩溶解
4. BGM卡点：明暗变化跨完整乐句缓慢过渡
5. 无感故障修正：压抑感不足，雾层透明度上调至18%

## L4 极强包装｜黄金3秒开场钩子（单次持续时长≤6s）
定位：视频开头引流，短时爆发，禁止长时间持续使用
### L4-A 温柔引流钩子｜国乙种草、情感MV开篇
1. 推荐背景：B类浅色系流动色雾、柔和星云背景
2. 背景处理：开场由模糊底层缓慢清晰，虚实过渡
3. 固定动效参数
- 流动色雾透明度16% + 扩散星光粒子
- 呼吸缩放±5%；低频缓震强度8
- 环形柔光单次向外扩散
- 转场放射缩放
4. BGM卡点：视频0秒同步触发全部动效，对齐第一处重音
5. 无感故障修正：冲击力偏弱，缓震强度调整至12

### L4-B 强冲突钩子｜悬念剧情、炸裂开篇
1. 推荐背景：A类暗调远景、剪影场景
2. 背景处理：虚实过渡双层背景
3. 固定动效参数
- 粒子完整生命周期0.8s（生成→扩散→消散）
- 快速向内推镜；十字闪光0.2s
- 高对比度字幕；强光转场峰值0.2s
4. BGM卡点：开篇第一拍同步爆发
5. 无感故障修正：粒子不明显，透明度上调至25%

### L4-C 清冷悬念钩子｜虐向短视频开头
1. 推荐背景：B类低饱和暗蓝、灰紫色抽象背景
2. 背景处理：暗调雾层打底
3. 固定动效参数
- 微环绕运镜；轮廓光瞬间提亮20%缓慢回落
- 字幕延迟0.3s渐入；转场虚实模糊切换
4. BGM卡点：轮廓光峰值对齐开篇重音
5. 无感故障修正：光影变化感知弱，峰值提亮调整至25%

## L5 院线质感级｜高阶成片主体基底
定位：精品视频主力层级，脱离网红廉价特效，营造空气景深
### L5-A 治愈院线｜温柔回忆、风景向MV
1. 推荐背景：A类开阔远景（海面、云端、晨光）
2. 背景处理：双层景深架构；远景图层高斯模糊30，图层错位位移9px
> 硬性约束：错位位移低于8px，景深层次直接失效
3. 固定动效参数
- 单向流动空气薄雾透明度10%
- 镜头4~6s匀速推拉，缓入缓出
- 人物轮廓光透明度8%
- 字幕字间距±3缓慢呼吸
- 转场景深推拉衔接
4. BGM卡点策略：长周期运镜横跨多个节拍，仅乐句转折点微调光影
5. 无感故障修正：轮廓光看不见，最低锁定8%，不可下调

### L5-B 叙事院线｜完整CG长剧情片段
1. 推荐背景：A类自带原生光影电影场景CG
2. 背景处理：双层景深，模糊22，图层错位6px
3. 固定动效参数
- 无持续薄雾，仅转场添加短暂雾效过渡
- 长镜头缓慢横移；尽量减少剪辑切换
- 极少额外光影干预，优先保留原图光影
- 极简静态字幕
4. BGM卡点：依靠镜头运动营造氛围，减少瞬时特效触发

### L5-C 暗调院线｜压抑、遗憾文艺片段
1. 推荐背景：B类分层雾景暗调背景
2. 背景处理：远景模糊35，图层错位10px
3. 固定动效参数
- 下沉雾流透明度13%；极慢向内推镜
- 单侧轮廓光透明度10%；动态暗角持续扩张
4. BGM卡点：画面明暗缓慢变化，不跟随鼓点频繁跳动
5. 无感故障修正：轮廓光底线10%，低于阈值直接融入画面

# 三、背景、光影、特效联动自适应规则（核心升级模块）
1. 亮色系背景 → 所有光效、粒子透明度统一+20%（亮色容易吞噬光效）
2. 深色暗调背景 → 所有光效透明度统一-15%（防止画面发白、丢失层次）
3. 背景线条繁杂、元素密集（花草、城市、人群）
方案：删除多层粒子流体，仅保留局部光影效果
4. 背景干净、大面积留白（渐变、云雾、天空）
方案：完整启用全套氛围动效
5. 语音厅MV专属特殊约束（人声优先）
- 禁止高饱和、高对比度背景，避免干扰居中字幕
- 所有强卡点特效放置画面上下边缘，避开字幕区域
6. 色系统一硬性要求：单条视频背景色系统一；频繁冷暖切换，成片割裂无高级感

# 四、流水线完整执行SOP（人工剪辑 / AI自动化通用）
1. 素材判定：读取画面情绪标签（甜/虐/燃）
2. 段落分级：铺垫=L1/L2｜常规高潮=L3｜视频开头=L4｜精品长片基底=L5｜情绪核心=L6｜标杆代表作=L7
3. 匹配对应等级情绪支线，直接使用文档固定参数
4. 依据背景明暗、繁杂程度，自适应微调光效透明度
5. 对齐BGM卡点规范添加瞬时特效
6. 执行【防无感开关对比测试】
7. 手机端预览终审
8. 导出成片

# 五、成片快速故障诊断库
## 故障1：特效添加，肉眼几乎看不见
排查顺序：图层错位距离 → 透明度参数 → 是否全屏叠加 → 动画持续时长
通用修复公式：透明度+20% / 运动幅度+30%

## 故障2：画面廉价、网红感过重
排查顺序：是否频繁闪光、多层粒子叠加、一拍一动频繁卡点
修复方案：删除频闪特效；增加镜头时长；把节拍卡点改为乐句卡点

## 故障3：画面脏乱、发灰、层次感消失
排查顺序：多层柔光/雾效叠加、光效铺满全屏、背景与特效线条重叠
修复方案：只保留【1层氛围层+1层光影层】，删除重复滤镜

## 故障4：高级感缺失，画面扁平
核心根源：缺少【空间速度差、明暗差、虚实差】；不是特效数量不够，是缺少强弱对比
