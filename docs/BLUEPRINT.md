# AI 小系统获客引擎 · 总蓝图

> 指定选题 · 多 Agent 编排 · 可发布成品 · 三平台 · 最终只负责选题和方向

## 1. 核心用途（系统定义）

**针对指定选题，自动收集资料、整理内容，通过多 Agent 专业化编排，最终形成可直接发布的自媒体内容。**

主链路：

```
queue/topics.yaml（选题）
  → 资料收集（证据 / 消费者声音 / B-roll / 项目画面）
  → 多 Agent 工种编排（编导、记者、编剧、导演、合规、运营…，见 CLAUDE.md）
  → pipeline/ 流水线（脚本 → 画面 → 配音 → 成片/图文）
  → publish/ 发布包（成品 + 三平台文案 + CHECKLIST）
```

引擎与内容皮肤分离：

| 层次 | 定义 | 可替换性 |
|------|------|----------|
| **引擎** | 选题驱动的多 Agent 内容生产系统 | 固定架构，持续自动化 |
| **内容皮肤** | 成品对外讲什么故事、什么人设 | 可换垂直/选题，引擎不变 |

| 项 | 定义 |

## 1.2 当前内容皮肤（账号定位）

「小老板烦事 → 能跑的小系统」是**现阶段验证流水线的垂直选题**，不是系统边界。

账号主线不是 AI 教程，也不是「分享遗忘的经验」。当前对外一句话：

> 我用 AI 把小老板每天烦、重复、没人管的事，做成能跑的小系统。

每条内容都要尽量回答一个获客问题：

- 这个项目解决了哪类小老板的具体麻烦？
- 原来靠什么笨办法处理？
- AI 改造后变成什么样？
- 有没有真实项目画面：截图、录屏、表单、后台、流程？
- 看完的人会不会觉得「这东西我也想要」？

## 2. 系统分层

```
Layer 0  你          指定选题(queue/topics.yaml) + 方向(月度一句话)
Layer 1  选题引擎     读历史 metrics + 规则 → 推荐选题（Phase 2+）
Layer 2  多 Agent 编排  工种并行：采料 → 脚本/分镜/合规/文案 → 汇入 pipeline
Layer 3  生产流水线   脚本 → 画面 → 配音 → B-roll 拼接 → 三平台导出
Layer 4  发布采集     发布 → 48h/7d 指标 → metrics.csv
Layer 5  反馈修正     rules.yaml → 周度报告 → 下批方向
```

## 3. 项目模块

| 模块 | 路径 | 职责 | 自动化阶段 |
|------|------|------|-----------|
| **编排规则** | `CLAUDE.md` | 多 Agent 工种清单与协作流程 v2（Layer 2） | Phase 0 人工串行 → Phase 2+ Agent 并行 |
| **洞察模板** | `templates/insights/` | topic_brief · core_message · domain_notes · fact_check | 每条选题必产出 |
| **留存/音画模板** | `templates/retention_beat_sheet.md`、`templates/audio_plan.yaml` | 完播节拍 + 配音/BGM/字幕方案 | 视频必跑 |
| **形式库** | `assets/formats/catalog.yaml` | 分镜可选表现形式（≥3 种） | Phase 0 登记 → 分镜引用 |
| **IP 配置** | `persona/` | 人设、禁用词、标签策略（随内容皮肤） | Phase 0 定稿 |
| **选题队列** | `queue/` | **引擎输入**：指定选题、形态、状态 | Phase 0 人工 → Phase 3 半自动 |
| **内容模板** | `templates/` | 脚本/发布模板；工种产出格式 | Phase 0 人工填 → Phase 1 AI 辅助 |
| **素材库** | `assets/` | 项目截图、录屏、B-roll | Phase 0 人工拍 → 持续积累 |
| **生产流水线** | `pipeline/` | 脚本→画面→配音→导出（Layer 3） | Phase 0 全人工 → Phase 1 半自动 |
| **运营反馈** | `ops/` | 指标、规则、数据规范 | Phase 1 人工填表 → Phase 2 脚本 |
| **发布包** | `publish/` | 可发布成品+文案（引擎输出） | Phase 1 人工发 → Phase 2 定时 |
| **遗留工具** | `legacy/` | 旧 slides/TTS 生成器 | 仅作素材库，不作首发默认 |
