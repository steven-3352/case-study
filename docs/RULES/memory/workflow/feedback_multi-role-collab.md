# 新选题处理：多工种协作模式

## 规则

每当 case-study 项目出现**新选题**（queue/topics.yaml 新增、用户口头抛一个小老板场景、或要为某个项目做内容落地），不能直接跳到"写脚本→出图→剪视频"。必须先以**内容生产团队**的视角跑一遍多工种协作，再进入实操。

**Why**：用户做的不是 AI 教程号，是"用 AI 改造小老板烦事"的获客内容引擎。同一个选题在不同工种眼里看到的东西完全不同 —— 编剧只盯钩子，摄像只盯画面可拍性，记者会问"真实性证据在哪"，纪录片视角会问"故事弧线"。少了任何一个工种，内容就会塌成"AI 教程号"或"自说自话"，违背 [docs/BLUEPRINT.md](docs/BLUEPRINT.md) 的 1.1 内容定位。

**How to apply**：碰到新选题时，按下面的流程跑。可以全部由我串行扮演，也可以调 Agent 工具并行（参考 ~/.claude/rules/agents.md 的并行原则）。不要省略工种，但允许某个工种"本选题不输出"——必须显式说明为什么。

## 工种清单与各自职责

| 工种 | 看什么 | 输出 | 对应可用 Agent（参考） |
|------|--------|------|------------------------|
| **编导（总导）** | 选题是否符合主线、四形态如何拆 | 选题立项单：主线钩子 + 4 形态分工 + 验收标准 | Content Creator |
| **记者** | 真实性、数据、证据链 | 调研笔记：小老板原话、痛点佐证、数据点、可引用源 | Analytics Reporter / Anthropologist |
| **纪录片导演** | 故事弧线、改造前后对比、人物视角 | 叙事大纲：起承转合 + 关键时刻 + 情绪锚点 | Book Co-Author |
| **导演（执行）** | 镜头语言、节奏、信息密度 | 分镜表：每一镜的画面/口播/字幕/时长 | Content Creator |
| **摄像/视觉** | 画面可拍性、构图、可复用素材 | 画面清单：B-roll 列表、截图清单、是否需新拍/新生成 | Brand Guardian / 配合 [[gpt-image-2-api]] |
| **编剧** | 钩子、口播逐字稿、字幕节奏 | 脚本三版（v0/vA/vB）+ 前 3s 大字钩子 | Ad Creative Strategist / Book Co-Author |
| **视觉设计** | 版面、色彩、字体、品牌一致性 | 视觉指南：用报纸风(P002)还是真实截图风(P001)、配色、版面参考 | Brand Guardian |
| **剪辑** | 时长卡控、三平台规格、字幕样式 | 剪辑说明：抖音 45-60s / 小红书 ≤60s / 视频号 60-90s 的取舍 | — |
| **运营/增长** | 平台分发、私信转化承接 | 三平台发布文案 + 评论区埋点 + 私信路径 | Carousel Growth Engine |

## 标准动作

1. **立项**：编导先给一句话选题，确认是否进 [queue/topics.yaml](queue/topics.yaml)
2. **平行调研**：记者 + 纪录片导演并行 —— 一个挖证据，一个找故事
3. **脚本三版**：编剧产出 v0/vA/vB（与 [[gpt-image-2-api]] 中 P002 三版报纸风对应）
4. **视觉路线选择**：视觉设计决定走 P001 真实截图、P002 报纸风、还是新路线（必要时启用 [[gsap-skills-available]] 做网页动效）
5. **分镜与画面清单**：导演 + 摄像确认每一镜素材是否就绪（参考 `assets/broll/catalog.yaml`）
6. **剪辑/出图**：进入 `pipeline/render_p001.py` 或 `pipeline/p002_carousel_gen.py`
7. **发布包**：运营出三平台文案，套 `templates/publish_三平台.md`
8. **验收**：跑 `pipeline/CHECKLIST.md`，过不了就回到对应工种返工

## 与现有流水线的衔接

不替代 [pipeline/README.md](pipeline/README.md) 的 9 步流程，而是把第 ① 步"脚本"前置成一个"立项+多工种调研"的扩展层。Phase 0 全人工时由我串行扮演各工种；Phase 2+ 半自动后，可以让多个 Agent 并行产出再由我合并。

## 反例（不要这么做）

- ❌ 用户抛一个选题，立刻跳进 `p002_carousel_gen.py` 写 prompt
- ❌ 只用编剧视角，跳过记者 → 内容像编出来的，没真实感
- ❌ 跳过视觉设计 → 同质化报纸风看腻了还在出报纸风
- ❌ 工种全部我自己扮演但只产出一份"四不像"文档 —— 必须每个工种产出独立、可审阅的小段
