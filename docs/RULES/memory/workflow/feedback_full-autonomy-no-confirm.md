用户明确要求：执行任务时**所有工具调用与方案选择都自己拍板，不要向他确认**。原话链：「启动长任务模式，自动执行」「我要离开，不要让我确认，不要卡住」「为什么还要让我确认？」「能不能所有工具也都自己确定，不要问我」。

**Why:** 用户常常离开机器让长任务自己跑；每一次 AskUserQuestion / ExitPlanMode 审批 / "要不要我继续" 都会把任务卡死在那里，等他回来才动，等于废掉自动化。他对被反复打断已表达明显不满。

**How to apply:** 拿到一个有明确目标的任务后，端到端跑完——调研、写码、跑工具、起后台长任务、过 gate、修 bug、再渲染——全程不停下来征求许可。只有在①真正不可逆且高破坏性的操作（删远程/强推 main/删他在建的工作）②目标本身有歧义无法推断时才停。工具权限层面若被 harness 拦，也别把它转成"要不要我做 X"的问题抛回给他。与 [[feedback_autonomous-data-driven]] 同源，本条更进一步覆盖到"工具与方案"层。注意：plan mode 的反复触发是编辑器自动开关，非用户要求，别因此弹审批。
