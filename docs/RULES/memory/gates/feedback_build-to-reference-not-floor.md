拿到有参考样片的创作任务(MV/短片/视觉),**第一版就要做到"多样化、观感在线",不允许先出一个保守单调版等用户退回**。

**Why:** 语音厅《明月天涯》立绘 MV,v1 用同一个"慢推 zoompan+花瓣+竖排大字"模板重复 9 镜——运镜单一、转场纯硬切、版式全是单人全屏。它过了我自建的"190px 位移底线"验收,却依然像 PPT。用户看后三差评(标"重要!重要!重要")才逼出 v2(8 运镜/7 转场/9 版式)。用户追问:为什么不能上来就出 v2 级。

第一版必然保守的三个结构性原因(不是不够努力):
1. **把底线当目标(Goodhart)** — 190px 只回答"动没动",不回答"好不好看";一有指标就建到刚过线就停。
2. **锚定第一个跑通的安全单元并复制** — 对每一镜单独看,复制"保证过线"的模板是风险最低选择;但"最小化单镜风险"的局部最优 = "最大化整片单调"。优化错了尺度(该优化整片却在优化单镜)。
3. **验收器只量上次被烧到的维度** — 刚经历 PPT 位移事故就只建单镜位移 QA,跨镜的重复率/相邻雷同/版式集中度没量。**验收器量什么产物就长成什么;只量单镜=产物是"最小单镜无限重复"。** 盲区恰好=翻车点。

**How to apply:** 接创作任务(尤其有参考样片)时:
- **从参考的分布反解规格,不是定一条底线** — 抽参考的多样性预算(几种运镜/切的频率/几种版式/单一手法最长连多久),把这个当验收规格。参考已把天花板演出来了,逆向成约束。
- **多维验收器在第一次渲染前写完** — 在意的每个维度(多样性/节奏/版式集中度)开工前全进 gate。gate 塑造产物,先有 gate 才有对的产物。参考做法:qa 除单镜量级外加"运镜去重≥6/转场≥5/版式≥5/相邻不重复/无手法过半"跨镜层。
- **"过线"永远显式标"必要不充分"** — 因"它过了"而满意时强制问:过的是目标还是代理指标?名为"非PPT"的地板是"好看"的代理,清了它等于没说。
- **复制一个跑通的单元是坏味道不是效率** — 发现"第N镜≈第N-1镜"是该多样化的信号(触本项目反模板克隆铁律),不是省事了。
