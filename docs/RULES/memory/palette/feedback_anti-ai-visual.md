用户最核心的视觉反馈词是"AI 味"。任何看起来像"AI 默认输出"的内容都会被驳回,即使在执行带货等紧急生产任务的中途也要停下来重做。

**Why:** 用户做 AI 改造小老板系统的获客内容,如果视觉本身一眼看出"AI 做的",会反向损害品牌(用户/客户会觉得"你这做内容自己都偷懒,凭啥让我信你能帮我做小系统")。AI 味成本极高,而反 AI 味是核心竞争壁垒。

**AI 味的 5 个症状(用户/我共识)**:
1. 过度对齐(GSAP 居中 + 栅格 + 对称)
2. 饱和色块(黑底 + 高饱和橙绿/纯白底 + 单色 accent)
3. 字体单调(全 PingFang SC,1-2 字重)
4. 零瑕疵(没有手写痕迹/折痕/错位/油渍)
5. 节奏规律(等长 scene + 元素匀速浮入)

**已验证的反 AI 路线** (按反 AI 浓度排):
- P005 杂志拼贴 (米黄纸 + 噪点 + 衬线 + 印刷红蓝 + 5 字体 mix + ±2-3° 偏轴 + 黄便签 + 红印章) ★★★★
- P006 手绘漫画 (方格纸 + 简笔画 SVG 7 表情库 + 拟声词 + 对话气泡 + 漫画分镜框) ★★★★★

**How to apply:** 任何新的视觉模板/落地页/出图任务,默认假设 P004 黑底霓虹风/报纸风/GSAP 居中布局 都是错的起点。要么参考 [[gpt-image-2-api]] 的报纸风(限定品类),要么走 P005/P006 风,要么主动提议新方向。不要默认走"最简单的 HTML+GSAP 中央对齐"。

**相关:** 涉及多工种协作时,这条反馈优先于"视觉设计"工种的默认选择(报纸风/截图风);视觉设计先决定"反 AI 路线",再决定具体表现形式。
