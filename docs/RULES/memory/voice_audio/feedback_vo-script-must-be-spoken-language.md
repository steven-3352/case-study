配音稿（VO script）必须写成真人开口能说的话，不是书面语堆砌。判据：让作者/别人**朗读一遍**，卡壳/别扭/绕口/换气不了 → 回炉。

**Why:** 2026-07-12 W29 连载「把 AI 调教成我的助理」EP01-EP07 用户亲自实录时反馈："配音脚本写的很垃圾，完全不是人说的话"。当前策略：先按现稿剪出成片看效果，不行整体重出配音稿。根源：编剧写稿时脑子里没有"张口念一遍"的动作，写成了文字稿/推文的语感（长句、书面连接词、密集术语、无停顿气口）。

**How to apply:**

- 编剧交稿前必须**自己朗读一遍**每一集，卡壳的句子当场改。不朗读交上来的稿默认打回。
- 口语稿三个硬指标：
  1. **单句 ≤ 15 字**（超长句拆成两三句，气口给自然停顿）
  2. **禁书面连接词**："因此/然而/综上所述/众所周知/值得注意的是" → 换成"所以/但是/一句话/你知道吗/有意思的是"
  3. **允许口头词/语气词**："嗯/对/其实/说白了/你想想/我跟你讲"，别怕不"精炼"，口语就是要有余温
- 术语要**先说人话再补术语**："让 AI 帮我记事儿——就是那个 memory 功能"，不是"利用 AI 的 memory 系统进行结构化信息存储"
- 数据/引用**说人话**："三个人里有俩" > "66.7% 的用户"；"我上周试了" > "根据近期实测"
- 参考已有的 memory `feedback_dense-vo-no-dead-air`（密 VO 无死区）和 `feedback_ai-voice-known-gap`（AI 声破绽已识别）——本条讲**文字端**的口语化，前两条讲**声音端**的密度和音色。
- 与 [[feedback_multi-role-collab]] 联动：编剧交稿到留存/形式策略前，加一道"朗读通读"门。
- 触发条件：任何配音稿（TTS 或真人录）交付前；EP01-EP07 若成片播放效果不佳 → 整体重出配音稿时对齐本条。
