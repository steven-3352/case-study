# AI 视频「拍同款」控制手册（2026 版）｜闭源 API 能力矩阵 × 控制意图决策 × 开源深控兜底

> **本文 2026-08 重写。** 原「20 套底层引导模态 + 两位小数权重配方 + 批量流水线」是 SD1.5 / AnimateDiff / ComfyUI 时代的打法——**跑闭源 API 几乎用不上,跑开源本地也已被 VACE 统一控制取代**。旧版全文见 `archived/` 段(本文末)。
>
> **本文定位**:服务「用户拍同款 → agent 一次调用出片、砍掉中间流程」的主线。20 模态不再是用户旋钮,而是下沉为 agent 内部的**控制意图 → 预处理**决策矩阵。
>
> （注:模型能力随厂商版本快速变动,权重/参数当经验起点,不当普适常数。)

## 第零部分:一句话认知升级

**2024 的心智**:抽 20 条底层 MP4(骨骼/深度/边缘/光流…)→ 各配两位小数权重 → 叠进 ControlNet 重绘。

**2026 的现实,分两条路线:**

| | 闭源 API(你在用的 Seedance,及 Kling/Veo/Runway) | 开源本地(Wan VACE / Wan2.2 Fun / LTX-2) |
|---|---|---|
| ControlNet 20 通道 | ❌ 厂商吃进模型内部,不暴露 | ✅ 全支持 |
| 你实际能拿到的手柄 | 首帧图 / 参考视频 / 运镜预设 / 动作迁移 | pose/depth/光流/线稿/mask/参考图,**统一到一个控制单元** |
| 「拍同款」怎么做 | **一个 `reference_video_url` 参数** | 抽控制信号 → 喂 VACE VCU |
| 中间流程 | 极少(≤2 步预处理) | 多(GPU + ComfyUI + 逐镜调参) |
| 适合你 | ✅ 主线 | 仅极少数「必须帧级锁结构」的镜头 |

**结论:对「拍同款、减流程」,闭源 API 已经把整条 20 模态流水线压成了「一个参考参数」。20 模态的价值不在于让用户去拼权重,而在于 agent 内部判断「这条同款需求要不要做骨架/深度预处理」。**

# 第一部分:核心通识(仍然成立的部分)

## 1.1 什么是「底层引导」

原始视频 = 彩色真实画面(RGB)。
底层引导 = **从原图推理出的结构化信息序列**(动作、轮廓、空间、运动、分区、光影),不含色彩内容。

AI 重绘本质:**结构由引导锁定,风格由大模型自由生成。**

> 但在闭源 API 上,你**看不到也调不到**这层结构——你交给它「参考视频/参考图」,它自己在内部抽结构。所以下面 1.2–1.4 只在**开源本地路径**成立。

## 1.2 生成逻辑(开源路径)

原始视频 → 抽帧 → 逐帧推理结构 → 时序平滑 → 合成引导 MP4 →(VACE/ControlNet)重绘。

## 1.3 两类结构生成方式(开源路径)

1. **AI 深度模型**(高精度):DWPose、DepthAnythingV3、光流(RAFT)、分割(SAM2)、线稿、FaceMesh。
2. **传统算法**(极速轻量):Canny、MLSD、Tile、阴影、视差。

## 1.4 唯一没过时的工程真理:时序平滑

逐帧独立推理 → 帧间结构跳动 → 成片频闪/抖动。
**开源路径必须加**:相邻 3 帧均值滤波 + 光流运动约束 + 镜头切帧处自动断开平滑防拖影。
> 闭源 API 的时序稳定由模型自己负责,你无需处理。

# 第二部分:闭源 API 能力矩阵(2026-08 · 本文主线)

> 前提变化:**Sora(OpenAI)已于 2026-04-26 永久关停。** 当前主导三家:Seedance 2.x(字节)、Kling 3.0(快手)、Runway Gen-4.5;Veo 3.1(谷歌)画质领先。

| 模型 | 「拍同款」能拿到的手柄 | 强项 | 拿不到的 |
|---|---|---|---|
| **Seedance 2.0/2.5** | 首帧图、`reference_video_url`(**多模态参考融合**:动作/运镜方向)、导演级运镜、≤15s | 参考驱动的「照着这么演/这么运镜」;你现有栈 | 逐帧 pose/depth 权重 |
| **Kling 3.0 / 2.6 Pro** | **Motion Control**:把参考视频的动作/走位迁移到你的目标角色;参考静图驱动复杂人体运动 | 人体动作迁移最稳 | 结构通道权重 |
| **Runway Gen-4.5** | Camera Director + Motion Brush 2.0(pan/zoom/tracking) | 运镜/合成控制最强 | 画质略低于 Seedance |
| **Veo 3.1** | 首尾帧、原生 48kHz 音、4K | 综合画质最高 | 结构控制最弱 |

**选型口诀(闭源)**:
- 动作/舞蹈同款 → **Kling Motion Control** 或 **Seedance 参考视频**
- 运镜同款 → **Runway Camera Director**(或 Seedance 导演运镜)
- 画质优先、结构随意 → **Veo 3.1**
- 你现有一体化栈内 → **Seedance**(`reference_video_url` 已打通)

**关键事实(纠正旧版)**:以上任何一家**都不接受** `DWPose0.75 + Depth0.6` 这类权重堆叠。旧版第五部分那 20 套两位小数配方,**只在开源路径成立**,已移至第五部分并明确标注。

# 第三部分:控制意图 → 预处理 决策矩阵(agent 内部,不暴露给用户)

**用户只说意图,agent 内部映射。** 这张表取代旧版「让用户拼 20 模态」——它是 agent 的判断依据,不是用户旋钮。

| 用户说的话(意图) | agent 判定 | 预处理动作 | 喂给 API 的入参 |
|---|---|---|---|
| 「照这个动作/舞蹈拍」 | 动作同款 | 抽骨架去身份化(`pose_reference_from_video`) | `reference_video_url` = 骨架 mp4 |
| 「复刻这个人物/服装/场景」 | 内容同款 | **不抽骨架**(骨架会丢长相),直传原片或参考图 | 参考视频/图原片 |
| 「照这个运镜拍」 | 运镜同款 | 可选深度参考;或直接用模型运镜预设 | 首帧图 + 运镜描述 |
| 「照这个风格/氛围」 | 风格同款 | 参考图 + prompt,不做结构预处理 | 参考图 + 文本 |

**决策要点(硬规则)**:
- **动作同款默认抽骨架**——天然剥离长相,降低「仅换像素复刻」的版权/原创风险(对齐 ad2 PRD AC-05)。
- **内容同款禁止自动切骨架**——用户要复刻人物/服装/场景时,骨架路线不等价;原片被 provider 拒绝须暂停问用户,只有用户明确接受「仅保留动作轨迹」才可切骨架。
- **能一次调用就不做预处理**——预处理只在「原创性需要」或「provider 不吃原片」时才加。这就是「减少中间流程」。

# 第四部分:20 模态附录(去重版 · 仅开源路径 / agent 内部参考)

> 旧版「20 套」含大量变体与淘汰项。去重后**真正独立常用的约 8 个**,其余标注归属。**这些名词只在你走开源 VACE/ControlNet 时才会碰到;闭源 API 用不到。**

## 常用(开源深控真会用)

| 模态 | 模型 | 管什么 | 开源权重经验值 |
|---|---|---|---|
| **DWPose** 全身骨骼 | DWPose | 动作/关节/手部(抗遮挡抗暗场) | 0.65–0.8 |
| **Depth** 深度 | DepthAnything V3 | 远近/运镜/防穿墙(**运镜复刻唯一解**) | 0.6–0.7 |
| **SoftEdge/HED** 软轮廓 | HED | 外形/剪影(高速运动不碎边,打斗首选) | 0.65–0.75 |
| **光流** RAFT | RAFT | 时序稳定(>4s 动态不加必频闪) | 0.25–0.35 |
| **FaceMesh** 468 点 | MediaPipe | 人脸/口型(侧脸>60°失效) | 0.4–0.5 |
| **Normal** 法线 | 深度转法线 | 曲面质感(修塑料脸,配 Depth) | 0.4–0.5 |
| **分割 / SAM2** | OneFormer/SAM2 | 前后景分离、局部重绘、动态蒙版 | 按需 |
| **Canny** 硬轮廓 | OpenCV | 静态构图精准(**动态必频闪,禁用于打斗**) | 0.5–0.6 |

## 变体 / 淘汰(不必单列)

- **OpenPose** → 已被 DWPose 全面取代,仅旧工作流兼容。
- **WholeBody** → 就是完整版 DWPose(含足部)。
- **Lineart / Lineart-Anime / MLSD** → 线稿家族,分别对应写实/二次元/建筑直线,按风格选一。
- **Disparity** → Depth 数学换算,VR 双目才用。
- **Forward/Backward 双向光流、MotionMask** → 光流的补帧/掩码变体。
- **Tile** → 超分保细节;**Shading** → 复刻原图光影。

## 冲突禁忌(开源路径,仍成立)

1. Canny + SoftEdge 高权重叠加 → 画面僵硬。
2. 全模态拉满 0.7+ → AI 无创作空间,塑料假人。
3. 光流 >0.4 → 拉扯变形。
4. 只用轮廓不用深度 → 穿模;只用骨骼不用轮廓 → 武器/衣物崩坏。

# 第五部分:开源深控路径(VACE / LTX-2 · 兜底)

**什么时候才走这条**:闭源 API 的参考手柄不够、必须**帧级锁定结构**(如精确复刻某段武打的每一帧骨架 + 深度)。代价是 GPU + ComfyUI + 逐镜调参,**与「减流程」相反,非必要不上**。

## 5.1 现代形态:VACE 统一控制(取代「20 条 MP4 + 20 权重」)

**Wan2.1 VACE(Video All-in-one Creation and Editing)**:一个模型的一个 **VCU(Video Condition Unit)**统一吃 text/image/video/mask/控制信号,支持 pose、depth、光流、线稿、灰度、layout、参考图,涵盖 R2V(参考生视频)/ V2V / MV2V。**这就是旧版「20 模态并联」的现代替代**——不再抽 20 条 MP4 各配权重,而是把控制信号丢进一个统一单元。

- **Wan2.2 Fun Control**:DWPose/OpenPose/depth/canny + 高噪/低噪双模型,运镜驱动 i2v,但人物/服装一致性弱于 VACE。
- **LTX-2 ControlNet(API 化)**:v2v,pose/depth/canny 引导,≤20s,支持音画同步——想要 ControlNet 又不想搭 ComfyUI 时的折中。
- **DreamActor V2**:参考视频动作 → 迁移到静图角色(非人/多角色也稳)。

## 5.2 开源权重配方(仅此路径成立 · 从旧版迁移至此)

> 以下两位小数权重**只对开源 ControlNet/VACE 有意义**,闭源 API 无视。

- 单人精细武打:DWPose0.75 + SoftEdge0.45 + 光流0.3
- 多人刀剑混战:SoftEdge0.7 + Depth0.55 + 光流0.3
- 影视运镜复刻:Depth0.7 + Lineart0.4 + 光流0.3
- 人物特写 MV(人脸不崩):DWPose0.65 + FaceMesh0.45 + Depth0.5 + 光流0.3
- 写实 CG 质感:Depth0.6 + Normal0.5 + Tile0.4
- 实拍转动漫:LineartAnime0.6 + SoftEdge0.4 + Depth0.5
- 口播短视频:DWPose0.6 + FaceMesh0.5 + Depth0.4
- 局部重绘保背景:SAM2 蒙版 + Segmentation0.5 + Depth0.4
- 长视频根治闪烁:任意主控 + 光流0.3 + Tile0.3

(其余旧版配方为上述变体,不再罗列;完整旧表见文末 archived。)

# 第六部分:接入 agent「拍同款」的落地路线(对接 ad2 翻拍线)

**你已经有 80%。** 现有件:

- `ad-agent/conductor/media.py::pose_reference_from_video(source, out_path)` → 骨架 mp4 + `{coverage, frames, detected, fps}`。
- 底层 `mvstudio.media.generate_pose_reference`(MediaPipe,索引 11–32,**无脸**,`min_coverage=0.65`)。
- 骨架 URL → `gen_video` 的 `reference_video_url`(Seedance)。
- 覆盖率不足 / provider 拒绝 → **建议包**(`开发卡_06`)不进死局。

**「拍同款」最短链路(agent 内部,用户零感知)**:

```
用户给参考片 + 说意图
   │
   ├─ 意图=动作同款 ──► pose_reference_from_video ──► coverage≥0.65 ?
   │                                                  ├ 是 → reference_video_url=骨架 → gen_video(一次调用)
   │                                                  └ 否 → 建议包(换片段/改镜头/放弃运镜复制)
   │
   ├─ 意图=内容同款 ──► 原片/参考图直传 gen_video(禁自动抽骨架)
   │                     └ provider 拒绝 → 暂停问用户,不自动降级
   │
   └─ 意图=风格/运镜 ──► 参考图/首帧 + prompt/运镜描述 → gen_video
```

**减流程的三条硬规则**:
1. 能一次调用就别做预处理——预处理只为原创性或 provider 兼容而加。
2. 20 模态、权重、VACE **一律不进用户对话**;用户只表达意图。
3. 需要开源深控的镜头是例外分支,不是默认;默认永远是 API 一次调用。

# 第七部分:终极口诀 & 故障速修

## 一秒选型(闭源优先)

- 动作/舞蹈同款 → Kling Motion Control / Seedance 参考视频(+ 视原创性需求抽骨架)
- 运镜同款 → Runway Camera Director / Seedance 导演运镜
- 人物/服装/场景复刻 → 参考图/原片直传,**不抽骨架**
- 画质优先 → Veo 3.1
- 必须帧级锁结构 → 才上开源 VACE / LTX-2

## 故障速修

| 现象 | 闭源 API 侧处理 | 开源路径处理 |
|---|---|---|
| 复刻不像原人物 | 别用骨架,改传原片/参考图 | 加参考图到 VACE VCU |
| 只想要动作不要长相 | 抽骨架去身份化 | DWPose,降轮廓权重 |
| 运镜跑偏 | 首帧 + 明确运镜描述 / Runway Camera | 加高 Depth 权重 |
| 画面频闪 | 换模型/缩短时长,模型内部管稳定 | 加光流 + 时序平滑 |
| provider 拒绝原片 | **暂停问用户**,不自动降级骨架 | — |
