## 受众画像（谁会停下看「一个人用 AI 自动获客」）

- **行业/角色:** 想做出海/独立开发/一人公司的人；已有产品或想法、卡在「有流量没沉淀、跟进总拖」的小老板；做副业但缺一套能 24/7 自己跑的获客系统的人。
- **规模/场景:** 一个人或极小团队，**既要拉客又要跟进**，最怕「留了线索没空跟、一忙就忘」；预算极紧，不可能养团队、买贵 CRM。
- **当前解法:** 手动发帖引流 + 手动回邮件/手动跟进；或买现成 CRM/EDM 工具（贵、配置重、还得天天盯）。痛点是**人一停，链路就断**。
- **为什么会停在这条:** 钩子是「一周的活干成一天」+「它自己在帮我赚钱」——同时戳「提效」和「被动积累」两个痒点；演示型全屏看真实落地页/真实自动邮件，比口播更可信。

## 钉子场景（一句话）

> 我一个人，给老外做英文市场，一天就把「拉客→收邮箱→自动跟进」整条链路搭完上线了——现在我不盯它，它每天自己发邮件养客户、自己记数据，跟进环节我花的时间是零。

### 场景细节（具体）

1. **一天全链路上线**：上午搭落地页（钩子=免费 PDF《The Wealth Phoenix Guide》7 个风水秘诀），中午接邮箱（表单只收 first name + email），下午配自动邮件 + 埋点，傍晚出引流内容（Pinterest 竖版 2:3 图）。一天，全链路上线。
2. **系统自己跑**：有人填邮箱 → Netlify 函数触发 Resend 立即发欢迎信 + PDF → 之后 Day 0/2/4/6/8/10 共 6 封养熟邮件，Netlify 每天自动跑（drip.mjs），用 Netlify Blobs 记状态防重发，每封带免责 + 退订。**我不在，它照发。**
3. **第 5 天翻车**：曝光有了，留资却寥寥无几。扒了一圈发现根因——内容太像机器，AI 一键出的图谁都刷过，没人停。
4. **改法**：把出图改成「AI 只出背景，文字我自己排」，才像活人发的；留资才开始动。
5. **对比锚点**：这事换成请人盯、买工具、人工一封封跟进，又贵又会忘；现在成本基本为零（Netlify 免费、Resend 免费 100 封/天），人工盯守约等于零。

## 本条不写什么（边界 · 守红线）

- **「赚钱」必须降级**：变现尚未上线。片中「它自己在帮我赚钱」只能解读为**系统 24/7 自动积累海外客户/邮箱名单与数据、为变现预热**；**禁写任何已赚金额、收入、ROI、转化金额**。
- **数字守区间**：第 5 天=确凿可写；留资写「个位数 / 寥寥无几」，**禁编具体留资数、转化率、打开率等假数字**。
- **真实自有项目，非客户**：禁 P 图假后台、禁摆拍假数据；项目画面用**真实落地页 / 真实自动邮件 / 真实后台**。
- **玄学品类合规**：风水/招财属灵性品类，**禁 guaranteed / 改运 / 招财保证 / 一定发财** 等绝对化；按 `traditionally believe` 口径，强调「内容/系统」而非「改命」。
- **不导私信**：CTA 走评论区讨论 + 主页钩子（扣【出海】），不写私信路径。
- **不堆工具名**：Netlify/Resend 等是真实栈，可点到，但本条是「一人系统自己跑」的演示，不是工具测评，不做 logo 墙。
