# 视觉语言 · W27D02 会议纪要 OpenMontage 试点

> 工种：视觉语言策展师  
> 状态：trial-pass · 约束 OpenMontage / local montage surrogate 预览  
> 目标：把“散会我先走”的职场爽感做成真实会议蒙太奇 + 清晰任务卡，而不是 PPT 卡片堆叠。

## 1. 参考来源

参考方向：

- 现代协作文档 / 项目管理工具界面：清晰白底、低噪声、信息层级强。
- 职场纪录片式短视频：会议室、手机群消息、待办清单、反差分屏。
- 当前 D02 GPT-image 素材：统一扁平矢量职场角色，避免 D01 卡通圆脸同质。

适配理由：

- 这条的核心不是炫技，而是让观众 3 秒内看懂“别人还在整理，我已经走了”。
- 中段必须让用户看清“纪要 + 待办 + 责任人 + deadline + @ + 提醒”。
- OpenMontage 试点应提升视频感和证据感，但不能改变脚本价值锚。

## 2. 色板

| Token | Hex | 用途 |
|-------|-----|------|
| canvas | `#F6F7F9` | 全局浅灰背景 / UI 外层 |
| surface | `#FFFFFF` | 纪要卡、待办卡、CTA 卡 |
| ink | `#17202A` | 主标题、关键信息 |
| muted | `#6B7280` | 辅助说明、时间、标签 |
| accent | `#1F7AFF` | 群消息、@、主按钮、重点连线 |
| success | `#18A058` | 已发送、已提醒、完成感 |
| warning | `#F59E0B` | deadline / 提醒铃 |
| contrast | `#EF4444` | 旧流程痛点、熬夜整理 |

## 3. 字体层级

| 层级 | 规则 |
|------|------|
| display | 76-88px / 800 / 行高 1.05，用于 0-3s 钩子 |
| headline | 54-64px / 800 / 行高 1.12，用于每镜主判断 |
| body | 34-42px / 600 / 行高 1.35，用于卡片字段 |
| caption | 26-30px / 500 / 行高 1.35，用于来源/状态 |
| data | 30-36px / 700 / tabular，用于 deadline、责任人 |

字体优先：`PingFang SC`, `Hiragino Sans`, `Arial`, `sans-serif`。

## 4. 组件规则

| 组件 | 画法 |
|------|------|
| 群消息卡 | 白底、16px 圆角、轻阴影、左侧蓝色状态条 |
| 纪要卡 | 标题 + 三条要点 + “已发群”状态，不超过 5 行 |
| 待办卡 | 每条包含头像、责任人、动作、deadline、@ 状态 |
| 分屏反差 | 左侧红色痛点标签，右侧绿色状态标签，中间不要塞长文 |
| CTA | 一个问题 + 一个关键词，不做营销式按钮 |
| 标签 | 小胶囊可以用，但不能超过 3 个，避免花哨 |

## 5. 逐镜应用

| 镜头 | 应用 |
|------|------|
| 0-3s | 会议室底图 + display 钩子 + 群消息卡，焦点先人后卡 |
| 3-11s | 手机群消息 / 纪要卡放大，accent 标“已自动发群” |
| 11-22s | 待办卡逐条堆叠，责任人/deadline/@ 是唯一焦点 |
| 22-30s | 左旧流程红标签，右新流程绿标签，反差直接可见 |
| 30-40s | 价值锚 + 自证 + 评论问题，保留呼吸空间 |

## 6. Don't

- 不仿冒飞书、企微、钉钉等品牌 UI。
- 不出现真实客户后台、真实群聊头像、真实公司名。
- 不用随机渐变、霓虹、玻璃拟态堆叠。
- 不把字幕、CTA、卡片三层文字叠在一起。
- 不为“电影感”牺牲中文可读性。

## 7. 像素验收

- 首帧关声音能看出“同事还在整理，我直接走”。
- 中段至少一帧能完整读到待办责任人、deadline、@ 状态。
- 视觉 token 在 OpenMontage / local preview 中可见。
- 成片不得直接覆盖 `douyin/video_with_bgm.mp4`，先进入 `openmontage/`。
