# 选题简报 · topic_brief · W27D05

## 选题(双平台同选题)
**「老板让我帮他招人回客户消息,我让他先看 3 个月群记录 — 数完那天他说"不用招了"」**

X = **实体店老板觉得「客户消息回不过来 → 招个人」;但 3 个月真实群消息的数据告诉他:90% 是 5 个重复问题,根本不是缺人,是缺一个把这 5 个问题自动答的工具(或一份共享话术)。**

## 受众(钉子人群)
- **主**:实体店/小公司老板,**1–8 人团队**,被「客户消息多 → 招人」的本能反应卡了好几次
  - 餐饮(团购回访 + 上门询价)、美容(预约改签 + 项目咨询)、教培(课程报名 + 退课)、母婴(产品适用咨询)、零售(发货+换货)
- **次**:正在做服务业的 Solo / 工作室主理人,自己回客户回到吐

## 钉子场景
一个母婴店老板:
1. 一个月里 3 次说"得招个人专门回客户消息"
2. 看招聘成本:¥3000–¥5000/月 + 培训 2 周 + 还得自己盯着对话避免说错话
3. 我让她把 3 个月微信群 + 私聊记录导出来数一下
4. **数据落地后**:90 天 1,247 条客户问题,真正不一样的问题 **只有 11 类**,头部 5 类占比 73%
5. 她当晚发群:"招人推迟,先让你给我做个表"

## 核心痛点
**老板第一反应 ≠ 老板真问题。**

「忙不过来 → 招人」是肌肉记忆。真问题:
1. 同一个问题被问 N 次,但**老板没有数据感知**,只感受到"我每天都在回消息很累"
2. 招人没解决重复问题 —— 新人也要每天重复回 90% 的同一句话,而且会说错(说错就丢客户)
3. 招人的真正成本不是工资,是**老板要花时间盯着新人对话**,等于多了一个要管的人

## 目标结果
让观众看完记住一件事:
> 下次本能想"招个人来做"的时候,**先打开微信群导出 3 个月聊天记录数一下**。你大概率会发现:不是缺人,是缺数据感知。

## 反转点(全片硬约束)
- 前 3s 大字钩子:"招人这件事,我建议你先别招" + 微信群消息瀑布流(真截屏/可识别)
- 中段反转:**3 个月数据落地** → 重复问题占比柱图 → 老板沉默几秒
- 落点:**老板发群截图:"招人推迟,先做表"** → 字幕"数据不是替代人,是让人看清自己"
- CTA:**评论扣"也想数" → 我发数法 + 一份导出 Excel 模板**(测水信号)
