### 招人解决不了的事
1. **重复问题不会因为多一个人就少** — 新人也要回 1247 条
2. **培训成本高 + 说错丢客户** — 新人不知道行业话术,价格/服务边界容易答错
3. **轮班/请假断点** — 新人请假/离职,客户问题没人接
4. **老板要管多一个人** — 不只是工资,是时间成本

### 真正能解决的方式(由轻到重)
1. **共享话术文档** — 5 个头部问题做好 5 段标准回复,贴店里 + 老板/伙计直接复制(¥0 当天能做)
2. **微信群关键词自动回复** — 客户问"营业时间",群机器人自动答(¥0-50/月)
3. **小程序/公众号自动应答** — 把头部 5 类做成菜单(¥300-500 一次性)
4. **AI 客服(轻)** — 接入 FAQ 知识库,无知识扩展(¥100-300/月)
5. **AI 客服(全)** — 多轮对话 + 业务系统集成(¥1000+/月,小店暂不建议)

## 数法(给老板一份能跑的 SOP)

### 步骤(15 分钟跑完,2 小时分析完)
1. 微信 → 我 → 设置 → 聊天记录迁移 → 导出最近 90 天聊天记录(可指定群/客户)
2. 导出 .txt 文件,用 Excel/腾讯文档打开
3. 逐条贴到 ChatGPT/Claude/豆包,Prompt:"帮我把这些客户问题归 11 类,并统计每类条数和占比"
4. 让 AI 输出 Markdown 表格 → 看头部 5 类占比
5. 如果头部 5 类 > 60%,你不缺人,缺 5 段标准回复

### Excel 模板(免费给到,作 CTA 兑现)
- 列 A:日期
- 列 B:客户问的原话
- 列 C:类型(下拉:营业时间/价格/预约/产品咨询/售后/其他)
- 列 D:是否头部重复(下拉:是/否)
- 总表自动算占比

## 边界 / 不适用场景(片中要诚实说)
- 客户问题极个性化(高客单服务,如咨询/法律/医疗) → 招人是对的
- 服务流程复杂 + 高决策成本 → AI 答不了,必须人接
- 客户数据敏感(母婴医疗) → 第三方 AI 客服有合规风险
