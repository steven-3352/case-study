# 内核 · core_message · W27D05

## 一句话价值锚(全片所有镜/全张所有图必须服务这一句)

> **「你不是缺人,是缺数据感知 — 把 3 个月群消息数一下,你大概率会发现 90% 是同一个 5 个问题。」**

## 3-5 条不可删关键信息(每条都必须进片)

1. **老板本能反应** — "客户消息回不过来 → 招个人"是肌肉记忆,且每月都会再想一次(钉子场景)
2. **数据落地的对比** — 3 个月真实记录:1,247 条客户消息(B 级近似)、真正不一样的问题 **只有 11 类**、头部 5 类占比 73%(柱图视觉硬证据)
3. **真问题不是缺人** — 招人 ≠ 解决重复,新人也会每天回 90% 同一句话,还会说错丢客户
4. **取消招聘的真实截图** — 老板发群"招人推迟,先做表"(可仿真,标"示意/已脱敏")
5. **CTA = 测水** — 评论扣"也想数",我发数法 + Excel 模板(低门槛验证有多少老板真有这痛点)

## 价值层次(从低到高,内容必须命中至少 3 层)
- **看到**:90% 是同一个 5 个问题(柱图反差)
- **信到**:数法可复用 + 不是 AI 营销,是看清自己
- **想到**:我自己是不是也该数一下
- **行到**:评论扣"也想数"(低门槛验证转化意愿)

## 形式约束(传达内核的硬要求)
- **不可**说"AI 替代客服" — 反转点完全不同,要说"数据让人看清"
- **必须**有 3 个月数据落地的视觉:微信群消息瀑布 → 表格数据 → 柱图
- **必须**有老板"沉默几秒"或"自己取消招聘"的反差锚点
- CTA "也想数" 必须出现两次:中段提一次(预告)+ 落尾正式(收口)
- 真截屏优先,不可全片 HTML 渲染(保留至少 2 段聊天/数据/截屏的"真实痕迹")
