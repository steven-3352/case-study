# 动效专属创意点 · motion_wow · W27D01

> 工种: 动效技术导演 + 视觉设计 · 依赖 form_strategy(v2) ✓ motion_tech_plan ✓
> 用途: 声明本条**专属、不可替换为任意选题**的创意点（防模板化/旧帧回流）

## CREATIVE · 专属创意点（本条独有，换选题即失效）

1. **「一句话砸进办公群，一排 Agent 齐刷刷瞪眼」** —— 把"提交任务"演成群聊被 @ 的瞬间，5 个工种头像同帧弹眼。这是 D01 专属开场，换任何其它选题都不成立。
2. **「Agent 吵架抢活」喜剧高潮** —— 编导/编剧/记者/剪辑/运营用各自**真实职责台词**互怼（记者「数据没核实不能写」呼应本系统 fact_check 工序）。台词与本账号工种体系强绑定，非通用搞笑。
3. **「吵完一拍即合 → 5 条进度条齐刷刷跑满」** —— 把"协同"做成一个节奏收束的爽点，对齐 BGM 上扬。
4. **「Agent 群把成品片举给镜头 + 这条就是它做的」自证收尾** —— 卡通角色"交片"动作直接指向观众正在看的这条视频，闭环自证，别人抄文案也抄不走这个结构。

## 与旧帧/旧模板的区别（防回流）

- 不复用 D06 真人 vlog、不复用旧 newsprint/evidence 卡片。
- 不是"换文案的通用卡片轮播"——每镜画面任务不同（瞪眼/吵架/协同/分屏/交片）。
- 角色台词若替换成任意选题仍成立 = 模板化风险 → 本条台词与工种职责绑定，不可平移。

## Phase B 复验项（render 后必勾 · 抽帧验）

- [ ] 镜1：一句话砸入 + 群瞪眼，大字不被头像遮挡
- [ ] 镜2：5 句吵架气泡各停留 ≥0.8s、可读、带真实职责
- [ ] 镜2：进度条齐满收束节奏对齐 BGM
- [ ] 镜3：分屏对比数字为区间（无写死假里程碑）
- [ ] 镜4：交片自证镜 + CTA 大字完整进 mp4
- [ ] 6 角色全片画风一致、可识别工种
- [ ] **完播 gate：** 出片后 3s 完播 ≥3.5% / 5s ≥40%（forecast 参考线），未达回 0–3s 返工
- [ ] **台词不可迁移验证：** 5 句吵架台词若平移到任意"多 Agent"选题仍成立 → 判模板化，须改写为更绑定本系统工序的版本
