## 各版本的核心假设（事后归因用）

### v0 基线 — "热搜狗仔风"
- **假设**：小红书算法吃"惊+痛诉+榨干"这种热搜钩子，5 任全列让用户快速判断"值不值得看完"
- **风险**：标题党词可能触发限流；信息全量可能降低翻页冲动；抽奖 CTA 在 2026 已被识别为营销信号
- **赢的条件**：CTR 最高（首屏吸睛）

### vA 算法版 — "个人叙事 + 钩子前置"
- **假设**：去敏感词换具体数字，首屏只讲 1 个细节留钩子，tags 切到精准流量池，CTA 改成"对号入座"
- **5 个关键改动**：
  1. 标题去掉"惊/榨干/深夜痛诉"，改成 `5 年谈了 5 个对象，没一个撑过 8 个月`（数字反差替代标题党）
  2. 首屏 200 字只讲第 2 任的 5000 刀账单细节 + 留白
  3. P3 标题改 `她每天给我倒一杯美式，月底给我寄账单`（去掉女性向反感词"月入百万"）
  4. tags 从`#海王图鉴 #深夜痛诉`切到`#程序员 #程序员的女朋友 #互联网打工人 #恋爱观察`
  5. CTA 从抽奖改成"评论区认领你的前任型号 + 说一个细节"
- **赢的条件**：完读率/互动率/评论质量最高（流量池升级）

### vB 玩梗版 — "梗密度 + 回旋镖"
- **假设**：保留 v0 的标题风格和 CTA，但把每 P 笑点拉到 ≥3 个，加 6 条跨 P 回旋镖，给每个角色一个 signature gag
- **关键新增**：
  - **6 条回旋镖**：$20→$9.9→按 token 三段递归 / 柯学长 `// TODO:` 被 K 先生 P4 关掉 / "黑乎乎的男人 npm install" P3 埋 P4 打开 / "顾小姐妹妹" P3 埋 P5 DNA 鉴定打脸 / "前 X 天免费" P5→P6 升级 / 报纸期号 ¥3.5→¥7.0 自嘲
  - **C 少爷 signature gag**（v0 缺失）：「Let me check...」+ 炫家世「我爹是 GPT」+ 越权替你投了 5 份简历
  - **报纸编辑部自身被玩**：记者笔名从"本报记者"→"老 K"→"钱多多"→"凌晨值班记者（已无意识）"
- **赢的条件**：互动率（点赞收藏比）+ 完读率最高（一直有新笑点驱动滑动）

## 测试方法建议（控制变量）

### 发布节奏
**同一周内连发，间隔 48 小时以上**，错开但不要差太大：
- Day 1 上午 10:30 发 v0
- Day 3 上午 10:30 发 vA
- Day 5 上午 10:30 发 vB

**为什么**：同账号连发同主题会被算法识别"内容同质"压流，所以要拉开间隔；但拉太开会引入"账号权重变化""平台流量周期"等噪声。

### 风险预案
v0 的"榨干"、vB 的"榨干了"都可能踩限流词。如果 v0 数据明显异常（曝光 < 同账号近期均值 50%），**先停 vB**，避免连环踩坑。vA 标题最安全，可优先发。

> **修正建议**：考虑先发 vA（最安全）打底，第二轮再发 v0 和 vB 做对比，能更干净地归因。

## 看哪些数据（按重要性排序）

| 指标 | 反映什么 | 阈值（小红书新号参考） |
|---|---|---|
| **24h 曝光量** | 首批流量池等级 | 1000+ 起步 / 5000+ 一类 / 10000+ 二类 |
| **CTR**（点击/曝光） | 封面 + 标题吸引力 | 5% 及格 / 8% 优秀 / 12%+ 爆款苗子 |
| **完读率**（滑到 P6/总点击） | 内容是否撑得住 | 30% 及格 / 50% 优秀 |
| **互动率**（点赞+收藏+评论/曝光） | 算法判定的内容价值 | 3% 及格 / 5% 优秀 / 8%+ 二次推流 |
| **评论数 + 评论质量** | 流量池天花板 | 看是否有真实故事/认领，不是"哈哈" |
| **收藏/点赞比** | 内容是否"值得保存" | 30%+ 说明内容有沉淀价值 |

### 归因怎么读
- **CTR：v0 > vA / vB** → 说明标题党在小红书 2026 仍然吃得开（反直觉，需后续验证）
- **CTR：vA ≥ v0** → 标题党红利已经消失，应该全面切到 vA 风格
- **完读率：vB 最高** → 梗密度是完读率的核心驱动，下一轮 vC 应该叠加 vA 的安全标题 + vB 的梗密度
- **互动率：vA 最高但 vB 第二** → 算法友好的 CTA 设计比内容质量更影响互动数据，要重点优化 CTA
- **评论质量：vA 远高于其他两版** → "认领玩法"成立，可推广到 P003+
- **三版数据都很差** → 不是文案问题，是选题问题（拟人化 AI 工具的赛道可能在小红书天花板很低）

## 下一轮（vC）的设计原则

数据回来后**不要**急着写 vC。先做归因，然后：

1. 拿数据最好那一版作为 base
2. 把其他版本中**胜出**的局部元素拼接进去（例如：vA 的标题 + vB 的 P5/P6 梗 + v0 的报纸味开头）
3. **只改 2-3 个变量**，否则下一轮还是没法归因
4. vC 发布间隔距离 vB 至少 7 天，让平台账号权重恢复
