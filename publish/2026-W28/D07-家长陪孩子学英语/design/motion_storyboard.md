## 动画导演判定说明

- **风格 = WaytoAGI 密 VO 演示**：全程 VO 驱动、静态 UI + drawtext 快切、气泡渐出与波形是唯二"连续动画"（CSS 关键帧，非 GSAP）。无重资产、无 Three、无真人，符合轻量模式 + 零技术风险。
- **不需 motion_tech_plan 重审**：无 Web 3D / GSAP / 复杂动效；气泡渐出/波形是纯 CSS 关键帧录屏。
- **交棒**：本表 → 导演做 storyboard/pipeline_config（scene/clip 时长对齐 seg_timing）+ 声音设计师做 audio_plan.yaml（上表 sfx 锚点）+ gen_ui_w28d07.py 出 10 张 UI PNG。
