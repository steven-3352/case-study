# 视觉语言约束 · design_language · W28D07

> 工种: 视觉语言策展师 · Delta（只写本条 vs DESIGN.md 差异）
> 视觉母题: 手机/tablet 聊天界面 + AI↔孩子英语对话气泡 + 3 年龄段 prompt 卡（H6 全新族群，不复用 D06 简历纸面 / D05 暗色卧室）

## 字体层级（1080 宽基准）

| 层 | 字号 | 用途 |
|----|------|------|
| 巨标（反差大字） | 88–100pt | 「一开口就往后缩」「缺的不是又一个班」「重点是敢开口」 |
| 段标（年龄段） | 60–72pt | 「6-8 岁」「9-12 岁」「13-15 岁」 |
| 气泡文字（中英） | 34–42pt | AI/孩子对话内容 |
| prompt 卡正文 | 30–36pt | 可抄的提示词（家长长按截屏） |
| 水印/注释 | 22–24pt | 「示例对话」「可长按暂停截屏」 |

字体：思源黑体 / 系统黑体；英文对话用等宽或圆体增"聊天界面感"。

## 组件

- **聊天界面框**：手机/tablet 圆角外框，顶部"AI 英语陪练"标题条；气泡左（AI 薄荷绿）右（孩子暖橙）交替。
- **年龄段卡**：白卡 + 左上金色年龄角标 + 一句玩法名（角色扮演/复述日记/影子跟读）。
- **prompt 卡**：白卡内一段可抄提示词，右下"长按截屏"金色小标（收藏钩）。
- **敢开口 ✓ 标记**：孩子气泡旁绿色 ✓ 渐次亮起（表现"敢说了"）。
- **边界三图标**：时长钟表 / 发音耳朵(参考) / 话题盾牌(家长把关) —— 具象非抽象。

## Do / Don't

- ✅ 聊天气泡具象化"AI 陪练"（不是空口讲，画成真对话）
- ✅ 暖色亲子基调、圆角柔和、去焦虑
- ✅ prompt 卡可截图、年龄段清晰分层
- ❌ 不用 D06 简历纸面 / D05 暗色卧室 三层堆叠
- ❌ 不用抽象图标糊弄（孩子/AI 用气泡+头像，玩法用具体道具）
- ❌ 不用蓝紫渐变背景 · 不用粉红
- ❌ 气泡英文内容不写"效果承诺"字样（合规延伸到画面文字）
