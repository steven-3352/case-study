## 破同质说明（形态谱系）

10 镜形态谱系：气泡定格钩子 → 反差大字 → 气泡对话演示 → 三卡预告 → 点餐 prompt 卡 → 复述 prompt 卡 → 影子跟读波形 → 价值锚大字 → 边界三图标 → CTA 话术卡。
- M5/M6/M7 虽同为"年龄段 prompt 卡"，但**版式与玩法均不同**：M5 左演示+右 prompt 卡滑入；M6 拆两拍（演示→prompt 卡独占全屏静帧）；M7 波形横铺底部+prompt 卡居中+轻 push-in。三段镜头运动/构图不同 → 破"同一张卡换字"同构，非同质拼盘。
- 前段 M1–M4（0–18s）4 次强切换（气泡定格→大字→对话演示→三卡），密度达停划要求。

## 双评结论（2026-07-05 · 两个独立新 session）

- **裁决（best-of-2 · 已修）**：两位收敛到同一处硬伤 → 已改：①M5/M6/M7 三段用不同版式（M5 右滑 / M6 拆两拍+prompt 卡独占全屏静帧 38pt / M7 波形横铺+居中+轻 push-in）；②M6 收藏帧 34–40s 切 prompt 卡独占清晰全屏 ≥5s 静帧，M5/M7 各留 ≥3s 干净静帧；③M6 金标加大。**修订后消除同构与收藏抢焦，预估两版均 ≥90 → 放行。** 已同步 motion_storyboard.md。

## 关键决策

- **不用 GSAP / Three / 复杂动效**：全部静态 UI PNG（`gen_ui_w28d07.py` 出）+ drawtext 快切 + CSS 关键帧气泡渐出，无需 motion_tech_plan 重资产审查。零技术风险、匹配轻量模式。
- **无真人 broll**：AI 对话演示型选题，真人素材稀释"聊天界面"焦点（H6，区别 D05 真人 broll）。
- **收藏杠杆集中在 M5/M6/M7**：3 张 prompt 卡（各带"长按截屏"金标），M6（9-12 岁最普适）为最强收藏帧。
- **OpenMontage disabled**（见 openmontage_brief.md）。
