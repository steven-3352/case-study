## 受众画像

- 行业/角色: 家有 6–15 岁孩子的家长（妈妈为主）
- 规模/场景: 报过 1–3 年英语培训班（3–6 万），孩子还是不敢开口；预算被通胀挤压，想省钱不放弃
- 当前解法: 换培训班 / 加班课 / App 打卡 / 请一对一外教（更贵） / 放弃

## 钉子场景（一句话）

> 报了两年班孩子还不敢开口——不是又缺一个班，是缺一个能天天陪他瞎聊、说错也不尴尬的对象；AI 每天 20 分钟在家陪练，孩子先敢说。

### 场景细节（至少 3 个，要具体）

1. 孩子学英语的一年时间线：报班 → 上课能跟读 → 回家一句不说 → 家长想加课但心里打鼓（记者/网络调研补真实原话）
2. 不同年龄段孩子跟 AI 对话的实际差异（6-8 岁靠图 + 游戏化指令；9-12 岁能角色扮演；13-15 岁能纠错复盘）——prompt 完全不同
3. 家长最怕的三件事：屏幕时间、AI 发音准不准、内容安不安全——本条要正面回应而非回避

## 本条不写什么（边界 · 合规锁）

- 不推付费英语课 / 付费社群 / AI 学英语 App（不带货）
- 不承诺「AI 让孩子学英语更快 / 3 个月流利 / 提分 / 弯道超车」
- 不喊「省 3 万」这类具体省钱绝对值；只做己方成本对比，省钱是结果
- 不贬低 / 不点名培训班；不说「别报班了」「培训班没用」
- 不说 AI「替代学校 / 替代老师」；定位是「课后在家的陪练补充」
- 不做「要不要报班 / 孩子几岁该学英语 / 跟公立教学冲突」这类争议话题
- 不宣称第一人称"我是英语老师 / 我教过多少孩子"——用「家长过来人 + 方法性表述」
