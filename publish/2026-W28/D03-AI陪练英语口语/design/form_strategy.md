## 关键场景细化

### 场景 A · 深夜钉子（M1-M2，0-8s）

**Q9 铁律：** chaos 必须是真实素材，禁用 AI 生图

- 主 B-roll：**深夜台灯 · 英语课本 · 手部特写**
  - Pexels 素材已下载：
    - `office_desk_dusk_evening_empty__26609644.json`
    - `office_desk_dusk_evening_empty__29540810.json`
    - `office_desk_dusk_evening_empty__7710338.json`
  - 优先使用最能匹配「英语课本 + 台灯 + 深夜」的一条；若光线偏暖光但缺英语课本主体，需 drawtext/drawbox 叠时间戳「23:12」补语义锚
- 手机屏幕：真机拍摄一部 iOS 手机锁屏「23:12」（准备手工设置本机手机时间）· 或 UI 高保真仿真（drawtext + drawbox 复刻 iOS 锁屏 UI · fact_check 允许，因为不是竞品打脸而是环境锚）
- 讯飞录数据：3-8s 段位需真截屏「92% / 78%」引用页（fact_check.md #P0-1 A 级）；若截屏无法获取，用大字「92% / 78%」+ 底部小字「来源：讯飞录《2024 中国英语学习报告》」标注（B 级同帧口径显示）
- **不用**：3D 渲染的手机、AI 生成的深夜书房、HTML 仿真的 iOS 锁屏

### 场景 B · 多邻国打卡幻灭（M3，8-15s）

**合规铁律：** 多邻国界面出现但**不打 logo · 只用连击数字截图**（见 v0/vB 合规自查 · fact_check #P0-2）

- 左半屏：真机截屏「700 天连击」数字放大 · 遮挡 logo · 只留连击数字 + 火苗图标
- 右半屏：手机视频通话 UI（真截屏或高保真仿真）· 沉默 3s · 尴尬表情或空白气泡
- **不用**：多邻国 logo · 竞品公关 · 直接说"打卡 App 没用"

### 场景 C · 类比锚（M5，20-24s）

- 分屏静图：
  - 左：**游泳教程 book cover**（Pexels 或 Unsplash CC0 · `swimming instruction book` 或 `swim manual` 关键词拉）
  - 右：**跃入泳池瞬间**（Pexels · `jumping into pool` · 已知 Pexels 有 CC0 素材）
- 大字类比锚居中：「读游泳教程 vs 跳进泳池」（drawtext + 苹方 headline 96pt）
- 静态分屏 · 无 GSAP 动画 · 只用 CSS transition 或 ffmpeg drawtext 淡入淡出

### 场景 D · role prompt 演示（M6，24-36s）· 全片核心

**关键动作路径：**
1. QuickTime 屏录本机 iPhone 或安卓开豆包语音（不打 logo · 但豆包本身允许出现，因为是主演示 · 见 fact_check.md）
2. 光标滚动到语音输入键
3. 长按语音键 · 显示"松手发送"提示
4. role prompt 大字滑入（分五段 punch-in）
5. 底部标注**「可长按暂停复制」**（小字提示 · 增强收藏动机）

**SVG 打点策略：**
- 不做复杂 GSAP 动画
- 只做**静态 SVG 高亮框 + 淡入淡出**（0.3s 淡入 · 停 2s · 淡出 0.3s）
- 五段标签：「角色卡 / 场景 / 只提问 / 说错不打断 / 用英文」
- 每段标签用 accent_soft（#ffc857 淡黄）底 + 黑字 · 禁 Dracula 霓虹

### 场景 E · 真对话回合（M7，36-42s）

- 屏录真机豆包语音真对话（AI 英文追问 + 用户回答）
- 字幕英中对照：
  - `AI: What kind of book do you enjoy?` / `你（AI 显示的用户话）: Um... mystery.` / `AI: Interesting — what makes mysteries fun?`
- 允许 AI 语音带口音 · 用户回答带口音 · 真实感优先（`feedback_ai-voice-known-gap` 已识别 gap，本条 M7 演示的是用户开口而非 AI 讲课，AI 音色 gap 影响可控）

### 场景 F · 侧躺共同体（M8，42-48s）

### 场景 G · 反教程价值锚（M9-M10，48-58s）
