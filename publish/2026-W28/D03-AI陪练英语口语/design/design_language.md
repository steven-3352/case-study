## 1. 视觉关键词

用 3-5 个词描述本条画面气质，必须能指导取舍：

1. **深夜暖光** — 台灯 3000-3500K 色温 · 房间偏暗 · 只有一盏光让画面聚焦手/课本/手机
2. **孤独可代入** — 拍不到脸（背影/侧影/手部/嘴部特写）· 让每个学英语党能把自己放进画面
3. **克制** — 无 emoji、无强色、无动画特效、无形容词字幕；沉稳同事口吻的克制感
4. **可截图** — 关键 role prompt 页面（小红书 P5-P7）能被学英语党一键截图带走
5. **群体锚数字大** — 92%/78%/700/300/145 等数字必须大字视觉冲击（比 D02 大 20-40pt）· 但字体保持苹方而非装饰性

**核心色策略：**
- 主色 = **深夜黑 + 台灯暖 + 纸黄轮播底**（画面 80% 深色 / 20% 暖光高光 / 轮播切纸感）
- 只用 accent_red + accent_soft 做**极少量**焦点（每帧 ≤ 5%）
- 允许出现系统原生色（iOS 蓝、微信绿、豆包 UI 主色）—— 真实痕迹优先
- 数据锚数字（92%/78%/700/300/145）用 ink_light 白 + accent_red 描边强调 · 不用彩色数字（禁 D04 曾出现的彩色数字堆砌）

### 字体与层级

| 层级 | 字号 / 字重 | 行高 | 用途 | 单屏上限 |
|------|-------------|------|------|----------|
| display | 140-180pt / 900 | 1.0 | 首镜大字「23:12·又一次决心学英语」· 全屏价值锚「不是教你 · 是把 prompt 给你」 | 8 字以内 |
| headline | 88-112pt / 700 | 1.1 | 群体锚大字（92% 中国人不敢开口）· 反差大字（读游泳教程 vs 跳进泳池）· CTA 大字 | 8 字以内 |
| body | 40-52pt / 500 | 1.3 | 中段字幕（口播文本转字幕）· 抖音 42pt · 小红书 50pt · 视频号 42pt（`feedback_pipeline-full-platform-output`） | 12 字以内单行 |
| caption | 28-32pt / 400 | 1.4 | 时间戳（23:12 / 22:45）· 来源标注（讯飞录）· CTA 底部小字 | 10 字以内 |
| mono | 32-40pt / 400 | 1.4 | role prompt 代码块（P5-P7 全屏 + M6 屏录内） | 覆盖满屏 |

**字体族：**
- 中文：**苹方 / 思源黑体**（PingFang SC / Source Han Sans）· 权重区分而非字体族切换
- 英文数字：**San Francisco / Inter**（时间戳、数字、AI 英文对话字幕）
- 代码 / prompt：**JetBrains Mono / SF Mono**（等宽，屏幕录制中的 role prompt）

**禁用字体：**
- ❌ 站酷高端黑（AI 味重灾区）
- ❌ 阿里巴巴普惠体（太企业）
- ❌ 手写体（学英语党不用手写 · 会显做作）
- ❌ 装饰性衬线（宋朝体、颜体等——深夜自习房不需要仪式感）
- ❌ 花字（W27D04 教训 · 会拉低克制感）

### 形状与间距

- **圆角**：屏幕元素跟随原生（iOS `12rpx` 时间戳、微信 `16rpx` 气泡、豆包 UI 原生），自造元素用 `4rpx` 硬边角（不做圆润卡片）
- **边框**：几乎不用；只在反例 punch（M4 摇头 · 打字问 AI 是坑）上用 `2px accent_red` 描边
- **阴影 / 深度**：**禁用装饰性阴影** · 只保留系统原生（微信气泡的默认阴影、iOS UI 阴影）· 深夜画面自带光线阴影（真实 B-roll）够用
- **留白密度**：单屏一个主信息 · 大字周围至少留 1.5 倍字号的空白
- **卡片最大层级**：**2 层**（背景 + 单卡片） · **禁止 3 层堆叠**（`agent_grid` / 备忘录风的多层卡片）

| 组件 | 应该怎么画 | 不该怎么画 |

| **对话框气泡** | 真实微信/iOS 原生气泡 · 豆包语音界面原生 | 自造气泡 · 3D 气泡 · 抽象聊天框 |
| **时间戳** | mono 字体 · 灰色 `#7a7a7a` · 极简（23:12 / 22:45 / 18:15） | 装饰性时间指针 · 数字跳动动画 |
| **role prompt 代码块** | mono 等宽字体 · 黑底 `#0a0a0a` · 每段用 `accent_soft` 淡黄色底行标注（M6 五段标签）| 彩色语法高亮（IDE 风）· 花字装饰 |
| **CTA 大字** | 灰底 `#0a0a0a` + 白字 headline 96pt + 四选项分行或两行两列 + 底部 caption 小字 | 亮色 CTA 按钮 · 「点这里」箭头 · 弹幕特效 |
| **分屏静图**（M5 游泳教程 vs 泳池） | 两图横向并列 · 各占 50% 屏宽 · 中间一条 2px `ink_light` 分割线 · 大字类比锚居中偏下 | 三分屏以上 · 图之间有装饰性边框 · 大字叠图中间遮挡 |
| **群体锚大字**（M2 92%） | 灰底 `#0a0a0a` + display 160pt 白字数字 · headline 96pt 中文文本 · 底部 caption 小字来源「讯飞录 2024」 | 彩色渐变数字 · 数字动效跳动 · 无来源标注（弱信任） |

## 5. 禁用项汇总（一键 fail 触发条件）

- ❌ **Dracula 霓虹紫 `#bd93f9` / 粉 `#ff79c6` / 青 `#8be9fd`** — 项目全局禁（见 SYSTEM Q9 · memory `feedback_no-neon-palette`）
- ❌ **偏粉红 `#ff5252`** — 用血红 `#e53935` 代替
- ❌ **暖红→冷蓝渐变** — 用纯黑 `#0a0a0a` 单色底
- ❌ **HTML+GSAP 居中大字** — 会显 AI 味（见 memory `feedback_anti-ai-visual`）· 本条用真实 UI 截屏 + drawtext 大字 + SVG 打点代替
- ❌ **卡片堆叠 3 层以上** — 避免与 W27D01/D05 agent_grid/pain_stack 撞形
- ❌ **报纸风版面** — 避免与 W27D04 撞形
- ❌ **备忘录风统一 HTML 模版** — SYSTEM Q9 明确禁
- ❌ **AI 生图作主视觉** — Q9 铁律 · chaos 尤禁 · 本条深夜/侧躺 B-roll 走 Pexels
- ❌ **合成假 BGM**（ffmpeg aevalsrc 拼的）— 见 memory `feedback_no-synth-bgm`（本条密 VO 演示型默认无 BGM · 见 `feedback_dense-vo-no-bgm-default`）
- ❌ **多邻国 logo · ChatGPT logo · 其他真实竞品品牌** — 只留数据锚数字或功能锚，不打脸不背书
- ❌ **数字跳动 GSAP 特效** — 数据锚数字用 punch-in 静态大字 · 不用滚动动效（会显 AI 味）
- ❌ **花字 / 装饰性衬线** — W27D04 教训 · 会拉低克制感
