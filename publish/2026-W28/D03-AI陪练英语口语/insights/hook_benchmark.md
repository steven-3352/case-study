## 参考 4 · 抖音「AI 陪练英语」赛道通用钩子公式（agent_hypothesis）

基于 [迅课科技抖音黄金 3 秒法则](https://www.ixunke.com/article/562) + [CSDN 短视频黄金 3 秒](https://blog.csdn.net/TuFuir/article/details/145972487) 归纳，AI 学英语赛道抖音常见钩子类型：

| 类型 | 例句（常见套路） | 我们判断 |
|------|--------------------|----------|
| **反认知型** | 「99% 的人练英语都用错了 AI，看完不敢再打字问」 | ⚠️ 撞车严重 · "99%"数字虚 · 承诺感强 |
| **痛点放大型** | 「学英语 10 年不敢开口 ❗你需要的不是背单词，是这个！」 | ⚠️ 撞车严重 · emoji + 惊叹号偏发疯营销 |
| **标签圈定型** | 「学英语 5 年还不敢开口的举手，这条视频送给你」 | ⚠️ 用得多 · 举手感稍老 |
| **结果前置型** | 「用 AI 语音 30 天，我雅思口语从 5.5 到 7.0」 | ⚠️ **红区** · 效果承诺 · 广告法 §17 教育培训不得承诺升学率 |
| **悬念型** | 「一个 prompt 让 AI 变身外教，评论区自取」 | ⚠️ 用得多 · "prompt 自取"承诺感强 |
| **免费送型** | 「这 3 段 AI 陪练 prompt 无偿分享，用了都不想找外教」 | ⚠️ 承诺打脸真人外教 |
| **提问共鸣型** | 「你有没有过晚上 11 点想练英语但没人陪的时刻？」 | ⚠️ 用得少 · 提问感稍虚 |
| **我们的差异化：场景剧型 + 群体锚定型** | **画面：对墙念英语 3s 静音 · 字幕「23:12 又一次决心学英语」；4-6s 字幕「92% 中国人不敢开口」；口播「不是你的问题」** | ✅ 无叙述、无教程感、无炫耀、无承诺 · 场景剧 3s + 群体锚 6s + 心理释放 |

**同行钩子的共同局限：**
- 都在**描述**（我做了什么 / 我发现了什么 / 我教你什么）
- 都带**承诺**（30 天流利 / 7.0 分 / 变外教）
- 都有**教程感**或**炫耀感**，不是学英语人真实的、沉默的、有点心累的场景
- 都没用**群体锚定**（92% 群体）释放羞耻感

**我们的钩子逻辑：**
- 首镜**演出场景**，不描述（对墙念英语 · 静音 · 咽口水）
- 首镜**无 AI**（AI 是解决方案，不是钩子）
- 3-6s **切群体锚**（92% + 78% 数据）→ 心理关先释放羞耻，再上 AI
- 20s 才引入类比锚（跳进泳池）· 24s 才引入豆包语音演示

## 合成 → 本条 0–3s 设计指令

> **给编剧 / 动效 / 声音的统一一句话：** 把观众放进他自己 22:30 对着墙念英语的孤独场景，3s 环境音静默让他认领「23:12 又一次决心学英语」，随后 3-6s 用 92% 群体锚打破"我不行"的羞耻感。

- **停划画面：** 手机锁屏「23:12」大字锚（前景）→ 主角背影侧对台灯（中景）→ 手上握着英语课本（近景）· 前 3s 环境音（AC / 键盘停下 / 咽口水）· 3s 时字幕大字滑入「23:12 · 又一次决心学英语」
- **停划口播/字幕：** 前 3s 无 VO（环境音钉子，非死区；符合 `feedback_dense-vo-no-dead-air`：3s VO 覆盖起点）· 3s 处 VO：「晚上 11 点，你在对着墙念英语」· 6s 处切「92% 中国人不敢开口 · 不是你的问题」
- **BGM mood：** 全片默认**无 BGM**（密 VO 演示/知识型 · `feedback_dense-vo-no-bgm-default`）· 只在 15-20s 打卡幻灭段位需要节奏时可极轻的滴答表针（agent_hypothesis · 由声音设计师最终定）
- **禁止：**
  - 与同行 7 类套路首镜同语法（惊叹号 emoji / 数字承诺 / "举手感" / prompt 自取）
  - 情绪词 emoji（❗ 🔥 😭 💯）
  - 效果承诺（30 天流利 / 7.0 分 / 秒变外教）
  - 纯口播介绍开场（「今天教大家用 AI 学英语」）
  - 「学英语大牛」「英语救星」「哑巴英语克星」这类形容词

## 差异化验收（编剧稿产出后自查）

- [ ] 前 3s **无 AI 相关信息**（AI 是解决方案，不是钩子）
- [ ] 前 3s **无 role prompt 提示**（prompt 是收藏动机，不是钩子）
- [ ] 前 3s **无教程感开场**（不说"教你 / 分享 / 技巧 / 分享"）
- [ ] 前 3s **无效果承诺**（不说"30 天 / 秒变 / 流利 / 通过"）
- [ ] 前 3s **有具体时间戳**（22:30 / 23:12 / 深夜）
- [ ] 前 3s **有可识别物件**（英语课本 / 手机锁屏 / 台灯 / 墙）
- [ ] 前 3s **打工人/学英语党能一秒代入**（画面里没有"AI 达人"感 · 没有"英语博主"感）
- [ ] 3-6s **切群体锚**（92% + 78% 大字上屏）
- [ ] 6-8s **完成心理关释放**（口播/字幕："不是你的问题"）
