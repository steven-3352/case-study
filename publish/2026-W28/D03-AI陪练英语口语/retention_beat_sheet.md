1. ✅ 清晰直给 — 首句 = 场景锚，无 AI 术语，无教程感，无效果承诺

## 每 6-8s 视觉变化清单（防中段塌陷 · 每一秒必有形式 ID）

- 0-3s：实景 B-roll（台灯 + 手 + 英语课本 + 锁屏 UI）
- 3-8s：大字数据锚 + 讯飞录官方截图 UI
- 8-15s：分屏混切（多邻国 App UI + 手机视频通话 UI · **不打真实竞品 logo**）
- 15-20s：UI 快切（AI 打字对话框 + 摇头动作 B-roll）
- 20-24s：分屏静图对比（游泳教程 book cover vs 跃入泳池）+ 大字类比锚
- 24-36s：手机屏幕录制（豆包语音 + role prompt 大字滑入）
- 36-42s：屏幕录制真对话回合（英文字幕 + 中文对应）
- 42-48s：实景 B-roll（侧躺 + 台灯 + 屏幕亮）+ 时间戳大字
- 48-54s：全屏大字价值锚（无画面 · 只有字）
- 54-58s：CTA 大字 + 口播

**10 段形式切换**（远超铁律 ≥3 种），每 3-6s 一变化，符合观赏性硬门。

## 片内互动 CTA（口播 + 字幕一致 · 54-58s）

> 「评论「面试 / 雅思 / 日常 / 旅游」——我把对应 role prompt 给你。」

**为什么这个 CTA 有效：**
- ✅ 具体选项（4 个场景标签一目了然）
- ✅ 低成本回答（一个词即可评论）
- ✅ 有反馈承诺（"把 prompt 给你"）
- ✅ 不硬拉私信（走评论区互动为主，私信自然延伸）
- ✅ 与 skin.landing_intent 一致（评论 → 按场景发 prompt）

## 评论区埋点（给运营）

| 关键词 | 回复方向 |
|--------|----------|
