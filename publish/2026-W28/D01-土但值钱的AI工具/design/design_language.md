> 工种：视觉语言策展师  
> 目的：把“土但值钱”的认知反差做成可执行画面约束，避免廉价科技感。

- content_id: W28D01

- 观众行为目标: 停划 / 看懂 / 评论流程名
- 参考来源:

  - 不照抄声明: 不复制样本文案和镜头，只借“强钩子 + 情绪画面服务旁白”的结构

## 1. 视觉关键词

- 克制的工作流
- 真实的重复感

## 2. Token 提取

### 色板

| 角色 | 色值 | 用途 | 禁用 |
|------|------|------|------|
| canvas | `#F6F4EF` | 小红书背景 / 抖音信息面板 | 不做大面积纯白刺眼背景 |
| surface | `#FFFFFF` | 卡片、表格、聊天气泡 | 不叠卡套卡 |
| ink | `#171717` | 标题 / 关键判断 | 不用浅灰主标题 |
| muted | `#6B7280` | 辅助说明 / 页码 | 不承载核心信息 |
| accent | `#1F7A5A` | “可 AI 化”通过状态 | 不全片泛绿 |
| contrast | `#C2410C` | “第一步错了”等冲突提示 | 不做警报式滥用 |
| data | `#2F5DCC` | 流程节点 / 输入输出箭头 | 不走紫蓝渐变科技风 |

### 字体与层级

| 层级 | 字号 / 字重 | 行高 | 用途 | 单屏上限 |
|------|-------------|------|------|----------|
| display | 64-78 / 800 | 1.05 | 封面 / 首镜大字 | 2 行 |
| headline | 42-52 / 750 | 1.12 | 每页主标题 | 2 行 |
| body | 28-34 / 500 | 1.25 | 解释文本 | 4 行 |
| caption | 20-24 / 500 | 1.2 | 标签 / 注释 | 2 处 |
| mono / data | 24-30 / 600 | 1.15 | 字段 / 流程节点 | 6 个词以内 |

### 形状与间距

- 圆角: 8px，最多 10px；不用大圆角胶囊。
- 边框: 1px `#E5E0D8`，信息卡片轻边框。
- 阴影 / 深度: 只用 0 8px 24px rgba(0,0,0,0.08)，不做玻璃拟态。
- 留白密度: 单页边距 ≥64px，标题与正文间距 ≥24px。
- 卡片最大层级: 1 层；禁止卡片里再套卡片。

## 3. 组件规则

| 组件 | 应该怎么画 | 不该怎么画 |
|------|------------|------------|
| 封面标题 | 大字占上半区，下面露出流程/表格/聊天视觉 | 不用空泛科技背景 |
| 信息卡片 | 白底、轻边框、短句 | 不写满段落 |
| 表格 / 字段表 | 只保留 3-4 列大字段 | 不做真实 Excel 密密麻麻 |
| 对比块 | 左“高级想象”，右“重复现实” | 不用复杂左右长文 |
| CTA | 评论输入框 + 示例流程名 | 不出现私信/扣1 |
| 标签 / badge | 高频、重复、输入、结果四个固定标签 | 不做满屏标签雨 |

## 5. Do / Don't

### Do

- 用真实工作材料的“仿真版”：聊天、表格、日报、报价。
- 让每屏只承担一个信息动作。
- 把“土”做成可靠、清楚、可执行，不做成廉价。

### Don't

- 不做蓝紫赛博科技感。
- 不做机器人、发光大脑、抽象粒子。
- 不把小红书页面做成课程 PPT。
- 不让字幕遮住表格和流程节点。
