## 业务决策链（中腰部创作者会不会用 AI 帮想选题）

1. **用户先问什么**：「AI 想的选题真的能拍吗？会不会全是'如何做好 XX'那种废话？我试过一次，太烂了不想再试。」
2. **中间犹豫什么**：
   - ① AI 出的选题会不会被同行都拍过？—— 差异化担忧
   - ② AI 不了解我的账号历史 / 粉丝画像，出的东西对不对味？—— 定位担忧
   - ③ 我拍 10 条真的能筛出 8 条能用的吗？—— 命中率担忧
   - ④ 会不会需要我先花 2 小时给 AI 喂账号资料才能出？—— ROI 担忧
   - ⑤ 我账号才 3000 粉，还没爆款怎么办？—— 起号阶段担忧
3. **什么促成行动**：
   - ✅ **看见完整 prompt**（Role + 账号定位 + 目标人群 + 输出格式 4 段 · 可暂停截屏抄）→ 门槛清晰
   - ✅ **看见 AI 输出对比**（烂 prompt 输出「如何做好 XX」vs 好 prompt 输出「梅雨天怎么防霉衣柜」）→ 反差自证
   - ✅ **看见筛选标准**（3–5 条明确判据 · 具体场景 / 反差 / 数字锚 / CTA · 现场评价）→ 「10 里 8」承诺可验证
   - ✅ **看见 landing intent**（私信"你在做什么账号、想拍什么方向"→ 我给你 5 条 · 无付费无社群）→ 同行互助感

## 中腰部创作者流程链路（他们视角 · 一周产 2 条）

```
周一 09:00 → 打开备忘录写选题 → 15 分钟空白 → 崩溃
  → 打开 ChatGPT 问「帮我想 10 个选题」→ 输出「如何做好 XX」全废
  → 翻竞品 30 分钟 → 存 8 张截图 → 一个都不想拍
  → 打开小红书搜「选题灵感」→ 20 篇方法论 → 记不住
  → 中午吃饭刷手机 → 想「今天先算了明天再说」→ 心里烦
  → 下午摄像头亮着 · 笔记本空着 → 「我要不换赛道吧」
  → 晚上再试一次 · 还是「帮我想 10 个」·还是「如何做好」
  → 关电脑 · 停更 +1 天
```

**AI 帮想选题 · 好 prompt 流程**是在这条链路上的**动作真替换**：

```
周一 09:00 → 打开 ChatGPT / DeepSeek
  → 粘贴一段准备好的 prompt（Role + 账号定位 + 目标人群 + 输出格式 · 3-4 段）
  → AI 输出 10 条候选选题（含场景 / 人群 / 钩子 / 拍摄成本）
  → 现场评价 · 5 条判据打勾（具体场景/反差/数字/CTA/差异化）
  → 筛出 8 条能用 → 存进选题库 → 定周三/周五拍哪 2 条
  → 09:30 收工 · 今天真的定好了 · 心里踏实
```

**关键**：不是给创作者加了个 AI 工具，是把「今天拍什么」这个 30 分钟-半天的痛苦决策**压到 30 分钟一次搞定**。核心不是「AI 生成」，是「决策收敛」。

## 专业概念口语化

| 术语 | 口语说法 | 是否可出镜播 |
|------|----------|--------------|
| Prompt / 提示词 | "喂给 AI 的话" / "起手 4 段话" / "同一段模板" | ✅ 说人话 |
| Role prompting / System | "先告诉 AI 它是谁" / "身份卡" | ✅ 用「身份卡」最贴 |
| Profile / 账号定位 | "把你账号的三件事告诉它：拍什么 / 给谁看 / 已发爆款" | ✅ |
| Format / 输出约束 | "让 AI 按表格出，每条都得给场景 / 人群 / 钩子" | ✅ |
| Zero-shot / One-shot | 不提 · 说「不用你举例它就能出」/「你给一个爆款样例它就照着调」 | ❌ 术语 |
| Chain-of-Thought | 不提 · 直接演示分步 | ❌ 术语 |
| LLM / 大模型 | "AI" 或直接工具名（ChatGPT / DeepSeek / 豆包） | ❌ LLM 不出镜 |
| Fine-tune / RAG / Agent | ❌ 完全不提 | ❌ 与本条无关 |
| System / User / Assistant 三角色 | 说「起手身份 + 你的账号 + AI 输出」三段 | ⚠️ 慎提；观众不熟就说「三段 prompt」即可 |
| 温度 temperature | 不提 · 默认 | ❌ |
| Token / 上下文长度 | 不提 · 用「一段 200 字左右能装下」代替 | ❌ |
| 差异化 / 反权威 / 细节化 | 说「和同行不一样的角度」 | ✅ |

| **AI 数字人 / AI 直接生成视频** | 免费、不出镜 | 与"选题"这个动作无关 · 是"内容形态"不是"选题" | 不提 · 本条只解决"下条拍什么"这一个环节 |

## 好 prompt 结构（本条核心方法论 · 4 源交叉支撑）

**结构（三段 / 四段 · 可暂停截屏抄）**：

### 第 1 段 · 身份卡（Role · System）

告诉 AI 它是谁 · 什么行业 · 什么专业度

**通用模板**：
```
你是一个专门帮 [赛道] 中腰部创作者想选题的运营顾问，
擅长把用户账号定位、历史爆款、目标粉丝痛点，
转化成能拍的、具体到场景的短视频选题。
```

### 第 2 段 · 账号定位（Profile · User）

告诉 AI 你是谁 · 拍什么 · 已经发过什么 · 给谁看

**通用模板**：
```
我的账号情况：
- 平台：[抖音 / 小红书 / 视频号]
- 赛道：[家居收纳 / 职场沟通 / 母婴辅食 / ……]
- 粉丝：[3.5w] · 目标人群：[25-35 岁 · 女性 · 已有一娃 · 一线城市租房]
- 我的三个内容标签：[实拍改造 / 30 元以内小工具 / 出租房友好]
- 已发过的爆款（≥1 条）：[「厨房吊柜 30cm 净宽的 5 种放法」赞 1.8w] 
- 我不做的：[不带货 / 不接大牌 / 不做甲醛焦虑]
```

### 第 3 段 · 目标粉丝的真实痛点（User）

告诉 AI 你从评论区 / 私信抓到的粉丝真实痛点（3 条以内）

**通用模板**：
```
最近粉丝常问 / 抱怨的 3 件事：
1. 「租房不能改造墙怎么收纳」
2. 「小户型阳台放洗衣机+柜子怎么摆」
3. 「梅雨天衣服晾不干怎么办」
```

### 第 4 段 · 输出约束（Format · Assistant）

告诉 AI 每条选题必须包含什么、按什么格式输出

**通用模板**：
```
请生成 10 条候选选题，每条按以下表格给出：
| # | 选题标题（≤15 字） | 具体场景（时间/地点/人群） | 前 3 秒钩子（冲突/反差/悬念/数字之一） | 拍摄成本估算（低 <30 分钟 / 中 30 分钟-2 小时 / 高 >2 小时） | 差异化角度（我 vs 同行 · 一句话） |

要求：
- 每条选题必须能对应一个具体拍摄动作，禁「如何做好 XX / 浅谈 XX」类通用句
- 至少 3 条走「反常识 / 反权威」角度（例："其实厨房吊柜别装门"）
- 至少 3 条低拍摄成本（<30 分钟）
- 禁与已发爆款重复
```

## 3 个"能用的 prompt"示例（不同账号类型 · 可直接抄）

### 示例 1 · 家居收纳类账号（对应 topic_brief.hook_scene）

```
你是一个专门帮家居收纳中腰部创作者想选题的运营顾问。

我的账号情况：
- 平台：抖音
- 赛道：家居收纳（出租房 + 小户型方向）
- 粉丝：3.5w · 目标人群：25-35 岁 · 女性 · 一线城市租房
- 内容标签：出租房友好 / 30 元以内小工具 / 实拍改造
- 已发爆款：「厨房吊柜 30cm 净宽的 5 种放法」赞 1.8w · 「租房 5 秒改造玄关」赞 1.2w
- 我不做的：不带货 / 不推奢牌 / 不做甲醛焦虑

粉丝最近问的 3 件事：
1. 租房不能改造墙怎么收纳
2. 小户型阳台放洗衣机+柜子怎么摆
3. 梅雨天衣服晾不干怎么办

请生成 10 条候选选题，每条按以下表格给出：
| # | 选题标题（≤15 字）| 具体场景 | 前 3s 钩子 | 拍摄成本 | 差异化角度 |

要求：至少 3 条反常识 · 至少 3 条低成本 · 禁"如何做好"套话 · 禁与已发爆款重复。
```

### 示例 2 · 职场沟通类账号（知识型）

```
你是一个专门帮职场知识类中腰部创作者想选题的运营顾问。

我的账号情况：
- 平台：小红书 + 视频号
- 赛道：职场沟通（向上管理 + 会议表达方向）
- 粉丝：8w · 目标人群：25-32 岁 · 大厂中层管培 / 转岗第 2-3 年
- 内容标签：真实对话截图 · 反 PUA · 不鸡汤
- 已发爆款：「老板说'先这样吧'其实是不满意」赞 2.3w · 「周报里的 3 个致命词」赞 1.5w
- 我不做的：不推课 · 不做鸡汤 · 不做"如何当高管"类话题

粉丝最近问的 3 件事：
1. 老板不回消息我要不要追问
2. 同事把功劳抢走我该怎么开口
3. 汇报的时候数字被质疑怎么接

请生成 10 条候选选题，每条按以下表格给出：
| # | 选题标题（≤15 字）| 具体场景 | 前 3s 钩子 | 拍摄成本 | 差异化角度 |

要求：至少 3 条走"真实对话+截图分析"路线（我的差异化）· 至少 3 条低成本 · 禁"教你 X 招"套话。
```

### 示例 3 · 母婴辅食类账号（好物型 · 起号阶段）

```
你是一个专门帮母婴辅食小账号想选题的运营顾问。

我的账号情况：
- 平台：小红书
- 赛道：母婴辅食（1 岁+ 手指食物方向）
- 粉丝：2800（起号阶段） · 目标人群：25-35 岁 · 一二线宝妈 · 娃 12-18 月龄
- 内容标签：3 分钟一顿 · 不用料理机 · 手残友好
- 已发笔记：15 篇 · 最高赞 340 · 无爆款
- 我不做的：不推贵料理机 · 不做超龄辅食 · 不推付费课程

粉丝最近问的 3 件事：
1. 娃只吃白粥怎么加菜
2. 出去外面吃饭时给娃带什么手指食物
3. 一顿要做 3 种不同的娃才肯吃

请生成 10 条候选选题，每条按以下表格给出：
| # | 选题标题（≤15 字）| 具体场景 | 前 3s 钩子 | 拍摄成本 | 差异化角度 |

要求：至少 3 条围绕"起号阶段容易上手"的选题 · 至少 3 条低成本（≤15 分钟能拍完）· 禁"5 个必吃/必买"套话（起号阶段易被识别 AI 味）。
```

**说明**：三个示例的差异不在"prompt 语法"，而在**账号定位 + 粉丝痛点 + 差异化标签**这三个变量。观众看到这三个 prompt 会立刻明白："我把我账号的这三件事写清楚，AI 就能给我出能拍的选题"——这是本条的 landing 关键动作。

## 筛选标准：AI 出 10 条，怎么筛出"能用的 8 条"

**5 条明确判据（现场评价 · 一票否决）**：

| # | 判据 | 通过标准 | 否决理由 |
|---|------|----------|----------|
| 1 | **具体场景** | 有时间 / 地点 / 人群 / 动作四要素 | "如何做好家居收纳" · 没场景 → 否 |
| 2 | **前 3s 钩子** | 有冲突 / 反差 / 悬念 / 数字之一 | "10 个卫生间收纳误区" · 无冲突 → 否 |
| 3 | **差异化** | 我 vs 同行有一句话说清 | "厨房收纳神器" · 同行都在拍 → 否 |
| 4 | **可复现拍摄** | 我 30 分钟-2 小时能拍完 | 需要请专业摄影 / 特殊场地 → 否 |
| 5 | **粉丝相关** | 命中我这批粉丝已问的 3 个痛点之一 | 泛家居爆款但和"出租房"标签无关 → 否 |

**通过 4/5 = 能用**（8 条通过说明本条 prompt 结构 work）· **通过 ≤3/5 = 换 prompt 再来一次**。

## 平台差异（对选题的要求）

| 平台 | 钩子密度 | 完播/停留优先级 | 选题倾向 | 本条视频落点 |
|------|---------|----------------|----------|-------------|
| **抖音** | 高（前 3s 必须冲突/反差） | **完播率 > 互动** | 反常识 · 强反差 · 情绪爆点 | 45–60s 演示 · 屏录 AI 出选题现场（本条主视频） |
| **小红书** | 中（首图/首句必须命中痛点） | **收藏 > 点赞** | 可收藏的模板 · 清单 · 分账号类型 · 步骤 | 6–8 页轮播 · 分账号类型 4 段 prompt + 筛选标准 |
| **视频号** | 中低（首屏语速可缓） | **完播 + 转发** | 长信息量 · 有共鸣的抱怨 + 系统方法 | 60–90s 稍长版 · 加"中腰部创作者的一天"情绪段 |

**结论**：
- **抖音主打反差演示**（打「帮我想 10 个」→ 输出全废 vs 打三段 prompt → 输出能拍）
- **小红书主打分账号类型的 prompt 模板集合**（首图：3 段 prompt 结构可暂停截屏 · 收藏动机高）
- **视频号加情绪段**（前 15s 演"选题荒的一天"情绪 · 后半段给方法）

## 反 AI 味起手（视觉设计参考）

- ❌ AI 味起手：「大家好，今天我们来讲 AI 帮你想选题」→ 教程感 · preach 感
- ✅ 同行起手：「上周我也这样，摄像头亮着我坐在这，笔记本空着」→ 同事感 · 场景感

- ❌ AI 味结尾：「学会了记得点赞收藏」→ 卖惨感
- ✅ 同行结尾：「你在做什么账号、想拍什么方向？私我一下我给你 5 条」→ 互助感 · CTA 落地
