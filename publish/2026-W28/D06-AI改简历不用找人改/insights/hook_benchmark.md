# 钩子基准 · hook_benchmark · W28D06

> 工种: 编剧（钩子研究）· 前 3s 停划设计 · 拆同行热门

## 同行热门钩子拆解（求职/简历赛道）

| 类型 | 同行常用 | 停划机制 | 本条取舍 |
|------|----------|----------|----------|
| 数字冲击 | "投 300 份 0 面试" | 具体大数字 + 惨 | ✅ 用"几百份已读不回" |
| 花钱踩坑 | "花 XXXX 改简历被坑" | 金额痛 + 共鸣 | ✅ 叠进钩子第二句 |
| 认知反转 | "简历没回音不是你以为的原因" | 制造信息缺口 | ✅ 本条核心，12s 落地 |
| HR 揭秘 | "HR 划走你简历只用了 X 秒" | 权威视角窥探 | ⚠ 改口径用"几秒到几十秒"，不喊"6 秒" |

## 本条钩子（前 3s · 三选一，编剧定稿）

- **H-A（痛点叠加）**：「投了几百份已读不回，还花几千找人改——改完照样没面试。」
- **H-B（认知缺口）**：「简历没回音，多半不是你文笔差。」（留白 → 承接"是 HR 那侧…"）
- **H-C（HR 视角）**：「HR 扫一份简历只有几秒到几十秒——你的根本没被看到。」

> 推荐主钩：**H-A 起 + H-B 转**（0–1s 痛点砸，1–3s 抛认知缺口）。视觉：一份简历被红色"已读不回/无面试"戳章盖满 → 3s 反差大字「不是文笔问题」。

## 前 3s 视觉冲突

- chaos(1.0s)：简历上密密麻麻盖"已读"红戳 + 投递计数飙到几百
- punch(0.6s)：一只手把"花 3888 改简历"的账单拍上桌
- reveal(1.4s)：大字反差「不是文笔问题，是没被看到」

## 停划自查

- [x] 前 3s 有具体数字（几百份）
- [x] 前 3s 有痛点共鸣（已读不回 + 花钱没用）
- [x] 前 3s 抛认知缺口（不是文笔）
- [x] 不喊"6 秒"假数据 / 不承诺逆袭
