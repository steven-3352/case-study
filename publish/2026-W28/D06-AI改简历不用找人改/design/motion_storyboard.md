## 动画导演判定说明

- **风格 = WaytoAGI 密 VO 演示**：全程 VO 驱动、静态 UI + drawtext 快切、扫描线是唯一"连续动画"（CSS 关键帧，非 GSAP）。无重资产、无 Three、无真人，符合轻量模式 + 零技术风险。
- **不需 motion_tech_plan 重审**：无 Web 3D / GSAP / 复杂动效；扫描线是纯 CSS 关键帧录屏，帧规格已在 form_strategy 落地（≥8 帧/30fps·步长=简历高/8·补缓动）。
- **交棒**：本表 → 导演做 storyboard.yaml（scene/clip 时长对齐）+ 声音设计师做 audio_plan.yaml（上表 sfx 锚点）+ gen_ui_w28d06.py 出 10 张 UI PNG。
