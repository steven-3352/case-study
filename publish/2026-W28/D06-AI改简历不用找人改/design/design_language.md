# 视觉语言约束 · design_language · W28D06

> 工种: 视觉语言策展师 · Delta（只写本条 vs DESIGN.md 差异）
> 视觉母题: 简历纸面 + HR 视角扫描线 + before/after 分屏（H6 全新族群，不复用 D05 暗色卧室/三层堆叠）

## 色板（禁霓虹 · palette gate 蓝紫 H=240~290 必 <5%）

| 角色 | hex | 用途 |
|------|-----|------|
| 纸面底 | `#f5f0e6` | 简历纸张暖白（区别 D05 全黑底） |
| 纯白纸 | `#ffffff` | after 简历卡 |
| UI 框底 | `#14171c` | 外框/HR 侧界面近黑（非蓝，H≈210 但饱和极低不触阈） |
| 墨字 | `#1a1a1a` / `#33312c` | 简历正文 |
| 硬伤红（戳章/圈错） | `#e53935` | 血红，禁 #ff5252 粉红 |
| 通过绿（after/✓） | `#2e7d32` | 森绿，非荧光 |
| 扫描线琥珀 | `#d98c00` | HR 扫描高亮，暖调（替代任何蓝色扫描） |
| 副文灰 | `#6b6b6b` | 注释/示例水印 |

**禁用：** `#bd93f9`/`#ff79c6`/`#8be9fd` Dracula 三色 · 任何蓝紫渐变 · linear-gradient 蓝紫端 · `#ff5252` 粉红。
**gen_ui 铁律：** 背景一律单色（不用 linear-gradient），跑完立即 `gate_check_palette.py`（memory feedback_gen-ui-avoid-blue-purple-gradient）。

## 字体层级

| 层 | 字号(1080宽基准) | 用途 |
|----|------|------|
| 巨标（反差大字） | 90–100pt | 「不是文笔·是没被看到」「HR 没看到的 3 处」 |
| 段标 | 60–72pt | 「第一/二/三处」序号 |
| 简历正文 | 30–38pt | 纸面模拟经历条目 |
| 对照句 ❌→✅ | 42–50pt | M6 可截图公式 |
| 水印/注释 | 22–24pt | 「示例·化名」「可长按暂停截屏」 |

字体：思源黑体 / 系统黑体（简历正文可用衬线思源宋体增"文档感"，与 UI 黑体对比）。

## 组件

- **简历卡**：白/暖白纸，圆角 12px，投影柔和；顶部「示例·化名·陈默」水印条。
- **HR 扫描线**：琥珀横线自上而下扫过，停在 6 个区域打点。
- **硬伤标注**：红色手写圈 + 红戳「已读不回」「无面试」。
- **before/after 分屏**：左 before（去饱和/灰）右 after（正常色 + 绿✓）。
- **对照句卡**：❌红 → ✅绿，一行一改。
- **三改一屏清单卡**（编剧+ 建议，收尾收藏帧）：三处硬伤+改法合成一屏静态卡。

## Do / Don't

- ✅ 纸面质感、文档感、真实简历排版模拟
- ✅ 红=错、绿=对 的直觉色码
- ✅ 大字互斥布局，逐张目视查叠层
- ❌ 不用 D05 的暗色 Dracula 蓝紫 / 三层堆叠 / 卧室 broll
- ❌ 不用抽象图标糊弄（简历就画成简历，HR 视角用扫描线具象化）
- ❌ 不用蓝紫渐变背景

## H6 差异化声明（vs D05）

| 维度 | D05 | D06 |
|------|-----|-----|
| 底色 | 全黑 #0a0e14 | 暖白纸面 #f5f0e6 |
| 母题 | 卧室晨起→办公三层堆叠 | 简历纸面 + 扫描线 + before/after |
| 主色 | 暗底血红点缀 | 纸白 + 红错/绿对/琥珀扫描 |
| broll | 睡姿/桌面真人 | 无真人 broll，纯文档 UI |
