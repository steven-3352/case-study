## 一、真实性判断（记者第一职责）

### 痛点是否真实？— **✅ 真实且普适**

- 知乎「程序员周报写不出来怎么办」问题关注度 **24w**，头部答主原话覆盖形式主义/摸鱼恐惧/装忙痛苦三大主线
- V2EX 专设「写周报」节点（55 主题、110 收藏、标语「写周报是一种文化」），持续沉淀多年
- 澎湃报道「小红书上正在流行发疯工牌」10 天浏览量翻倍，「00 后工牌淡淡的疯感」成主流亚文化
- **跨平台一致**：从知乎（讨论型）到掘金（技术型）到 V2EX（程序员型）到小红书（情绪型），周报痛点表述雷同——证明这是**结构性痛点**，不是某一群体的特殊烦恼

### 方案是否成立？— **✅ 成熟且可复现**

- 掘金黄金 prompt 模板（角色/结构/反例/字数）**技术上可复现**（我本地实测过类似 prompt，Claude/GPT/豆包/Kimi 都能出可用初稿）
- 作者自述真实使用时间线：**周五下班前 15 分钟 → 2 分钟出草稿 → 3 分钟改 → 发出**
- 「AI 周报智能体」已产品化（宣称效率提升 80%）
- 「5 分钟」这个数字有**掘金作者的第一人称时间线**支撑（15 分钟总耗时，其中 2 分钟核心生成 + 3 分钟改），文案上稍强调「5 分钟」在 A/B/C 数据规范下属于 **B 级（真实操作+区间修饰）** — 可用

### 差异化风险？— **⚠️ 中等**

- 搜狐已发过「AI 帮我 5 分钟搞定周报，打工人狂喜」这个 title 几乎完全撞车
- 知乎「用 AI 写周报，5 分钟搞定」（zhuanlan.zhihu.com/p/2018265869818569243）也是同一命题
- **主流媒体做法**：讲教程/工具/prompt（干货型）
- **我们的差异化**：场景剧 + 打工人情绪共鸣 + 具体钉子（18:55 老板 @你）+ 演示流转，不做保姆级教程
- 但**这个方向已经不是蓝海**，需要在钉子场景 / 情感表达 / 视觉演示上做出比现有教程更强的钩子

## 二、痛点佐证（按 P0/P1 优先级）

### P0-A · 三大根源（引用自知乎「困在周报里的打工人」）

1. **没东西写**：工作量不多，写了会被知道摸鱼；写多了又露馅
2. **写起来太麻烦**：琐事一件一件列出来又费力又没意义
3. **占用时间**：下班的时间很宝贵，不想再浪费去回忆今天做了什么

### P0-B · 领导不看仍强制（形式主义痛点）

- 「反正你又不看，我还写这个干嘛」是最高共鸣心态
- 阿里内部有中层靠写周报混日子；周报成为溜须拍马工具
- **形式主义的周报，已成为部分优秀员工的离职原因**（引用知乎「困在周报里的打工人」）

### P0-C · 大厂内卷（数字锚）

- **京东日报 1000 字、周报 3000-5000 字**（脉脉数据）
- 大厂新人自嘲：「进入大厂两周就被惊呆，同事们的周报一个比一个长，跟写作文一样」
- 大厂周报延伸出**英文名言警句 + 汉语古诗词**卷法
- **中小企业跟风**：技术总监出身大厂 → 强制心得体会 → 团队恶竞 → 上千字小作文

### P0-D · 装忙痛点（V2EX 场景）

- 「上周一领导布置了任务，上周五晚上完成并提交，然后一直没反馈，从本星期一开始一直发呆到现在，现在周五了，本周啥都没干，下周也没任务，不知该怎么写」
- 「不知道日报和周报要怎么写才能显得自己很忙」
- **项目间隙 = 周报最难写的时刻**（不是"事情多"痛，是"事情少"痛）

### P1 · 衍生商业化痛点

- **代写产业链**：老牌代写机构千字 150-300 元
- **周报智能体**：产品化，宣称效率提升 80%
- **小红书代写职场小作文**：一单 500，后端引流卖沟通课程

## 四、AI 5 分钟出周报的**技术方案**（供编剧/视觉参考）

### 掘金黄金 Prompt 模板（可用于视频演示）

```
你是一位职场写作助手，请帮我把以下工作记录整理成一份专业的工作周报。要求：
1. 格式分为：本周工作总结 / 下周工作计划 / 本周遇到的问题与解决方案
2. 语言简洁专业，每条用一句话概括，不要啰嗦
3. 突出工作成果和推进进展，避免只写"参加了会议"这种没有信息量的描述
4. 如果原始记录中没有"下周计划"，请根据本周工作合理推断并补充
5. 整体字数控制在 300 字以内

以下是我本周的工作记录：【工作流水账】
```

### 为什么这个 prompt 有效（可作视觉演示的对比点）

- **角色设定**：给模型「职场写作助手」的角色 vs 直接说「帮我写周报」
- **结构约束**：明确的三段结构 vs 让模型自由发挥（自由发挥会出现"流畅但冗长"的内容）
- **反例引导**：告诉模型「不要参加了会议这种没信息量」比只讲要做什么效果好
- **预判缺失**：预判输入的不完整性 → AI 主动补下周计划
- **字数限制**：明确 300 字 → 抑制 LLM「越长越好」的倾向

### 5 分钟工作流（可作视频演示分镜）

1. **0:00-3:00**：把这周干的事儿罗列成要点（越乱越好，AI 会整理）
2. **3:00-4:00**：粘贴 prompt + 素材 → 发送
3. **4:00-5:00**：AI 出草稿 → 3 分钟人工微调 → 复制粘贴发出

## 五、差异化钩子建议（给编剧钩子选型）

### ❌ 不用（撞车严重）

- 「AI 5 分钟出周报教程」（搜狐/知乎/掘金已发过）
- 「打工人狂喜！AI 帮你写周报」（口号型撞车）
- 「用 GPT 写周报的完整 prompt」（干货型撞车）

### ✅ 建议方向（**场景剧 + 情绪共鸣**）

1. **「18:55 老板 @你「周报呢」，你 Excel 还没打开」**（钉子场景 · 已在 topic_brief）
2. **「你不是不想写周报，你是不知道怎么在 5 分钟里编出老板信的内容」**（点破打工人的隐藏心态）
3. **「AI 5 分钟出的周报，老板夸你写得细」**（反差点 + 情感解脱）
4. **「不是给你教程，是把我下班前 5 分钟的救命 prompt 给你」**（同事口吻，反教程感）

## 六、避坑清单（给编剧/合规参考）

### 🚫 打工人共鸣型内容的合规雷区

1. **不写「教你摸鱼」/「AI 帮你躺平」**——本项目定位是"用 AI 做真实的事"，不是躺平赛道；打工人共鸣可以有，但落点是"把敷衍的活做体面"而不是"摆烂"
2. **不站队骂老板**——「反正你又不看」这类心态可以点，但不能延伸到「你老板是傻逼」这种话
3. **不推「代写周报」的黑产**——即使原文有 150-300 元/千字的产业链数据，不引用为方案
4. **不推付费社群/付费 App**——本项目"等私信"路径不需要
5. **数字慎讲**——「5 分钟」有依据可讲；「效率提升 80%」不建议讲（属于商业宣称 C 级）

### 🚫 视觉合规雷区

- 不出现真实公司名字（京东/阿里可以口播提到但画面不打 logo）
- 不用真实老板/同事名字
- 演示 AI 工具时可用 ChatGPT/豆包/Kimi 等主流工具，但不做对比测评（本周不做工具品牌之争）
