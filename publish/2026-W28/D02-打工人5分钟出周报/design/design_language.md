## 1. 视觉关键词

用 3-5 个词描述本条画面气质，必须能指导取舍：

1. **沉默** — 前 3s 无 BGM · 环境音打底 · 让打工人自己意识到"这是我"
2. **真实痕迹** — 手机屏幕上的时间戳、微信通知气泡、Excel 光标闪、系统 UI 原生痕迹（不美化不修饰）
3. **克制** — 无 emoji、无强色、无动画特效、无形容词字幕；同事口吻的克制感
4. **可截图** — 关键 prompt 页面（小红书 P5）能被打工人一键截图带走
5. **傍晚感** — 光线色温偏暖（3200-4000K）· 办公室下班场景 · 而不是清晨或午间

## 2. Token 提取

### 色板

| 角色 | 色值 | 用途 | 禁用 |
|------|------|------|------|
| canvas | `#0f0f0f` | 视频黑场底 / 大字字幕背景 | Dracula 紫粉青 · 暖红→冷蓝渐变 |
| surface | `#f5f5f0` | 备忘录/纸质表面 / 静态对比图卡 | 亮白 `#ffffff`（太刺眼） |
| ink | `#1a1a1a` | 标题 / 正文 | 纯黑 · Dracula 深蓝紫 |
| muted | `#7a7a7a` | 时间戳 / 辅助信息 | 灰紫 · 冷蓝 |
| accent | `#e53935` | 反例 punch 标注 / 反面提示 | 偏粉红 `#ff5252` · 荧光橙 |
| accent_soft | `#ffc857` | prompt 五段标签底色 / 正解引导 | 荧光黄 · 霓虹绿 |
| system_blue | `#007aff` iOS 蓝 / `#95ec69` 微信绿 | 系统 UI 原生痕迹（真截屏自带） | 自造品牌蓝 · 3D 玻璃质感 |

**核心色策略：**
- 主色 = **纸黑白 + 傍晚暖**（画面 80% 灰阶）
- 只用 accent 红 + accent_soft 黄做**极少量**焦点（每帧 ≤ 5%）
- 允许出现系统原生色（iOS 蓝、微信绿、Excel 绿）—— 真实痕迹优先

### 字体与层级

| 层级 | 字号 / 字重 | 行高 | 用途 | 单屏上限 |
|------|-------------|------|------|----------|
| display | 120-160pt / 900 | 1.0 | 首镜大字「18:55·周五」· 价值锚 | 8 字以内 |
| headline | 72-96pt / 700 | 1.1 | 每段痛点大字（没得写/写不出/占私人时间） | 6 字以内 |
| body | 40-52pt / 500 | 1.3 | 中段字幕（口播文本转字幕） | 12 字以内单行 |
| caption | 28-32pt / 400 | 1.4 | 时间戳（18:15）· 来源标注 | 10 字以内 |
| mono | 32-40pt / 400 | 1.4 | prompt 代码块（黄金 prompt 五段） | 覆盖满屏 |

**字体族：**
- 中文：**苹方 / 思源黑体**（PingFang SC / Source Han Sans）· 权重区分而非字体族切换
- 英文数字：**San Francisco / Inter**（时间戳、数字）
- 代码 / prompt：**JetBrains Mono / SF Mono**（等宽，屏幕录制中的 prompt）

**禁用字体：**
- ❌ 站酷高端黑（AI 味重灾区）
- ❌ 阿里巴巴普惠体（太企业）
- ❌ 手写体（打工人不用手写）
- ❌ 装饰性衬线（宋朝体、颜体等——傍晚办公室不需要仪式感）

### 形状与间距

- **圆角**：屏幕元素跟随原生（iOS `12rpx` 时间戳、微信 `16rpx` 气泡），自造元素用 `4rpx` 硬边角（不做圆润卡片）
- **边框**：几乎不用；只在反例 punch 上用 `2px accent_red` 描边
- **阴影 / 深度**：**禁用装饰性阴影** · 只保留系统原生（微信气泡的默认阴影）
- **留白密度**：单屏一个主信息 · 大字周围至少留 1.5 倍字号的空白
- **卡片最大层级**：**2 层**（背景 + 单卡片） · **禁止 3 层堆叠**（`agent_grid` / 备忘录风的多层卡片）

## 3. 组件规则

| 组件 | 应该怎么画 | 不该怎么画 |
|------|------------|------------|
| **封面标题** | 黑底 `#0f0f0f` + 大字 `display / 140pt` + 单行 8 字以内；标题下方一行 `caption` 补时间戳 | 渐变底 · 3 行标题 · emoji + 惊叹号 · 「打工人狂喜！」这类感叹式 |
| **信息卡片** | 只用于静态对比（M7）· 两卡横向并列 · 卡内只有 UI 截图 + 一行 caption | 卡片堆叠 · 4 张网格 · 卡内嵌套小卡片 |
| **UI 截图** | 保留系统状态栏 / 时间戳 / 通知位置 · 真实痕迹优先 | 裁掉状态栏 · 抠白底 · 加装饰性框 |
| **数据数字** | mono 字体 + accent 色（红/黄）· 数字周围留白至少 1x 字号 | 数字 + emoji · 数字 + 动效跳动 · 数字堆砌 |
| **对话框气泡** | 真实微信/iOS 原生气泡 | 自造气泡 · 3D 气泡 · 抽象聊天框 |
| **时间戳** | mono 字体 · 灰色 `#7a7a7a` · 极简 | 装饰性时间指针 · 数字跳动动画（M8 除外，用 SVG 简单滚动） |
| **prompt 代码块** | mono 等宽字体 · 黑底 `#0f0f0f` · 每段用 `accent_soft` 淡黄色底行标注 | 彩色语法高亮（IDE 风）· 花字装饰 |
| **CTA 便签** | 纸黄底 `#f5f5f0` · 黑色手写模拟字体 or `mono` · 光标闪 | 亮色 CTA 按钮 · 「点这里」箭头 |
