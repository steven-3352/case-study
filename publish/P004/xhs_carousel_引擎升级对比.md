### P4 · 对比② 生产流程（最大变化）

**画面：** 流程箭头对比

**旧版（容易敷衍）：**
```
选题 → 直接写脚本 → 出图/剪辑 → 发
```

**新版 v2（强制不偷懒）：**
```
选题
 → 并行深挖（记者/选品/领域专家）
 → 洞察包四件套（谁烦什么·关键信息·事实校验）
 → 留存节拍表（完播·互动·形式切换）
 → 脚本三版（只能引用洞察卡，不能瞎编卖点）
 → 分镜（≥3 种表现形式）
 → 音画方案（配音+BGM+字幕）
 → pipeline 出片
 → CHECKLIST 验收 → publish
```

**加粗一句：** 没有洞察包，不许写稿；没有节拍表，不许分镜；没有 BGM+字幕，不许外发。

## 正文（发布区粘贴）

做了 20 年互联网，自己创业。这个 repo 最初只是一个**自动化案例的素材包**——能出几张架构图、一段 TTS 草稿，但离「能稳定发内容」还差很远。

最近把它升级成了一套**内容生产引擎**，核心就一件事：

**指定选题 → 采料 → 多 Agent 分工 → 直接能发的视频/图文。**

和旧版比，我觉得最大的提高在这五块：

**① 定位清楚了**  
旧版：案例展示工具。新版：你只管选题，系统负责产出 publish 发布包。

**② 流程不让偷懒**  
新版强制走洞察包（谁、烦什么、关键信息、事实校验）→ 留存节拍表 → 再写脚本。不能一上来就喊口号。

**③ Agent 更专业**  
加了选题深挖、内核提炼、领域专家、留存设计、声音设计……编剧不能再瞎编卖点。

**④ 视频能发了**  
以 P004 为例：真实 B-roll 钩子 + 双 punch 字幕 + MiniMax 配音 + BGM + 硬烧字幕。外发默认带 BGM 的成片，不是裸 mp4。

**⑤ 同选题迭代更狠**  
K1 从「对着创作者讲 AI」改成「对着开店老板讲微信群第 800 遍」——受众、钩子、痛点全换，因为先把选题挖透了。

当前账号皮肤仍是「小老板烦事 → 小系统」，那只是**验证引擎用的垂直方向**，不是项目边界。换一批选题，同一套流水线还能跑。

你们做内容最卡哪一步？写稿、做图还是剪辑？评论区扔一个场景。
