## ⚠ 已知不达标项

### Caveat 1: 视频时长偏短

**事实**: 38s
**抖音规范**: 45-60s · **短 7s**
**视频号规范**: 60-90s · **短 22s**
**小红书**: 在 60s 内 ✓

**判断**: **不阻塞发布**

**理由**:
1. 平台技术不强制下限,38s 抖音/视频号都能上传
2. 短视频完播率与时长强相关,38s 反而占优势
3. 此条作为基线,等数据反馈再决定是否扩长

**数据回流后的决策树**:
- 抖音 完播 ≥ 35% → 时长 OK,继续短形态
- 抖音 完播 < 25% → 不一定是时长,先看钩子,再看 CTA
- 抖音 完播 25-35% + 评论问"还有吗" → 扩长版本(加 1 条具体场景案例)
- 视频号 完播 ≥ 50% → 视频号用户能吃短的,继续
- 视频号 完播 < 30% → 视频号需要长版,加片头招呼语 + 案例

### Caveat 2: 路人测试未做

**事实**: 没有让 1 个真人(非业内)看前 30s 测共鸣
**判断**: **建议补,不阻塞**

发布前可临时找 1-2 个开店朋友看前 10s,问"这是讲什么的"。如果答出"群消息回不完"=钩子有效,直接发;否则改钩子重出。

### Caveat 3: BGM(已修复)

**事实**: `我曾经的丫头.mp3` 不在仓库,build.py 自动跳过 BGM
**修复**: `pipeline/p004_video/mix_bgm.sh` 合成 ambient drone(A2+E3 + brown noise)叠到 final
**当前**: `p004_K1_with_bgm.mp4` 已含 BGM,VO 1.0 + BGM 0.10 混合,前 1.5s 淡入,末 2s 淡出
**判断**: **不阻塞,可发**

如需更好 BGM:
```bash
bash pipeline/p004_video/mix_bgm.sh path/to/your_track.mp3
```

风格建议: 低 BPM Lo-Fi/钢琴/Ambient,峰值 -14dB 以下,38s 内有起伏不要太平。
