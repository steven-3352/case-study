## Round 4 · 对标 D01：形态必须错开

**编导：** D01 已发 F2 punch + 证据链（hook/chat/table/flow/terminal）。D02 **禁止复用同一套 evidence 序列**。抖音必须走 **F3 原生 UI 体**：手机通知栈、柜台 tally 贴纸、客资档案卡——不是 mac 窗口 + 微信气泡。小红书必须走 **F4 报纸清单轮播**，不压短视频。

**记者（深化钉子场景）：**
- **谁：** 20 桌家常菜，老板+前台 2 人，无专职运营
- **何时：** 周五 17:30 晚高峰 + 月底对账前
- **在哪：** 收银台口头 tally 贴纸、老板手机商家通知
- **烦什么：** 218 单卖了说不清谁来过；差评 3 天后才看到；团购客没留微，来了一次就没了
- **要什么：** 三条线（核销/差评/留微）有人提醒，不靠脑子记

**网络调研员（补调研 · 2026-06-22）：**
- 网易：团购不赚钱常因核销波动、复购链路断，考核应从卖券转向核销率+复购率
- 有赞 76126：6 步闭环——店内标准化接待与核销、加微沉淀、活动节奏复购；**每一步对应负责角色+话术+指标**
- 腾讯新闻：经营分低分门店核销排名/评价维度落后，线上单量可差 2–3 倍（区间化引用，不说「必罚」）

**本轮决议：** 形态锁定 F3/F4；钉子场景五要素补齐；网络参考 +3 URL。

## Round 5 · 叙事升级（学 D01 v3 改造实录）

**内核提炼师：**
- 钩子升级：**「流量来了留不下」**（比纯 shock「回访0条」更有叙事弧，0–3s 仍用数字卡）
- 价值锚升级：**「三条线在谁脑子里？」** —— 不是缺表，是核销/差评/留微三条并行提醒没人跑
- P0 新增：① 218单/0回访 ② 柜台 tally 口头漏 ③ 差评滞后 ④ 客资空白 ⑤ 三步最小链 ⑥ 小流程提醒

**领域专家：** 小馆决策链：优惠引流→到店体验→有无联系方式决定复购。替代方案：请运营（请不起）、上大 SaaS（用不起来）。本片只说「三张最小表 + 提醒」，跟 D01「一条链」形成板块内对照。

**编剧：**
- vA：数字 shock 强，缺改造过程 → 作抖音 0–8s
- vB： empathy 弱 → 弃
- **vC（新定稿）：** shock 开场 + 改造实录中段 + terminal「团购助手」+ 两周 metric + 讨论 CTA；跟 AI 关系：登记/撞档检测/回访节点都是**重复规则**，适合做成小流程，不说买服务

**留存与互动设计师：**
- 抖音 7 段，体裁 ≥4 种：notify / tally / profile / flow / terminal / metric / note
- 每 6–8s 换 UI 形态（F3 核心）
- 小红书 6 张报纸轮播，末张收藏动机 + 讨论 CTA（**去扣「清单」**）

**运营：** CTA 改讨论型：「三条线靠人盯还是靠提醒？」；标签偏 #餐饮经营 #团购运营

**事实校验员：** 218→约200单；3天→2–3天；经营分案例仅作背景，不写「你也会被限流」

**本轮决议：** 选用 vC；CTA 去扣1；价值锚/钩子更新。
