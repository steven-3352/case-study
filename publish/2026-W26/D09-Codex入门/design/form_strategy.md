# W26D09 · 形式策略会

> 原则：表达方式服务数据假设，不为炫技。Codex 题材容易硬，所以画面必须先让普通人看到“重复事”，再出现 Codex 工作台。

## 逐镜策略

### 01 · 任务风暴

- 镜头任务：停划。
- 候选表达方式：实拍桌面堆文件 / 2D 卡片飞入 / Three/Web 3D 任务风暴。
- 数据杠杆：completion_3s、痛点理解。
- 理解成本：3D 只做卡片和文件，不放复杂人物；大字覆盖主信息。
- 制作成本：中；可用 CSS 3D/GSAP 2.5D 降级。
- 技术风险：Three.js 可能拖慢；若首帧不清楚，降级为 GSAP 卡片风暴。
- 推荐方案：GSAP 2.5D 或轻 Three 任务风暴。比静态 Codex 截图更能让普通人停下。

### 02 · 错误 prompt

- 镜头任务：制造好奇。
- 候选表达方式：真实 Codex 界面 / 仿真输入框 / 终端动画。
- 数据杠杆：3s 后续看。
- 理解成本：仿真输入框最清楚，不冒充真实 UI。
- 制作成本：低。
- 技术风险：真实 UI 易过时。
- 推荐方案：仿真输入框，显示“帮我做个管理系统”膨胀成乱线。

### 03 · 三个输入

- 镜头任务：看懂方法，支撑收藏。
- 候选表达方式：3D 卡片 / 2D 卡片 / 口播字幕。
- 数据杠杆：理解、收藏。
- 理解成本：2D 卡片最低。
- 制作成本：低。
- 技术风险：无。
- 推荐方案：2D 三卡片：现在怎么做、哪里重复、想要结果。

### 04 · 客户表格例子

- 镜头任务：证据感。
- 候选表达方式：真实表格截图 / 仿真表格 / 抽象图标。
- 数据杠杆：理解、信任。
- 理解成本：仿真表格清楚且不涉及隐私。
- 制作成本：低。
- 技术风险：文字过小。
- 推荐方案：仿真表格 before/after，大字段，不做密集 Excel。

### 05 · Codex 工作台

- 镜头任务：看懂 Codex 怎么干活。
- 候选表达方式：真实 UI / 终端 / 任务看板。
- 数据杠杆：完播、信任。
- 理解成本：任务看板比真实终端更适合普通人。
- 制作成本：中。
- 技术风险：真实 UI 过时；终端吓退普通人。
- 推荐方案：仿真工作台：读文件、写脚本、跑一下、报错再改、给你确认。

### 06 · 小工具结果

- 镜头任务：高潮。
- 候选表达方式：3D 分拣 / GSAP 流程 / 静态结果图。
- 数据杠杆：完播。
- 理解成本：GSAP 流程最稳；轻 3D 分拣可作为视觉变化。
- 制作成本：中。
- 技术风险：3D 抢戏。
- 推荐方案：GSAP 流程 + 轻 3D 卡片分拣，混乱任务变成“今日跟进名单”小面板。

### 07 · CTA

- 镜头任务：互动。
- 候选表达方式：评论区截图 / 四选项卡 / 口播问题。
- 数据杠杆：评论。
- 理解成本：四选项卡最低。
- 制作成本：低。
- 技术风险：无。
- 推荐方案：四选项大卡：表格 / 文案 / 文件整理 / 小网页。

## 总体路线

```text
前 3 秒：任务风暴 + 错误问题
中段：2D 卡片 / 仿真表格 / 工作台
高潮：混乱分拣成小工具
结尾：四选项 CTA
```

## 禁用

- 不用真实 Codex UI 当主视觉，避免过时和权限差异。
- 不做全片 3D，避免信息不清。
- 不用“功能列表”式讲法。
