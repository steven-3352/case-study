# vB · 情绪痛点版

你不是不会用 Codex。

你是把问题问得太像老板了。

一上来就说：帮我做个系统。

听起来很合理，但对 Codex 来说，这句话里面缺了最重要的东西：你的真实流程。

普通人第一次用 Codex，别先学代码，也别先做系统。

先丢给它一件每天重复的小事。

比如客户表格每天都要改格式，备注里还要翻出今天该跟进的人。

你就告诉它：
我现在怎么处理，
哪一步最重复，
最后想要一张什么清单。

它就可以从这里开始，读文件、写脚本、跑检查，一步步把这个流程变成小工具。

所以 Codex 最适合普通人的第一件事，不是宏大的系统。

是一件你已经烦了很久的小重复。

你会先交给它哪件事？
