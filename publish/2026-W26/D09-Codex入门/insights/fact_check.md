# W26D09 · 事实校验

> 当前状态：已由只读调研 Agent 核验 OpenAI 官方 Codex docs / help 页面；发布前仍建议二次打开确认入口和 plan 口径是否变化。

## 绿区

- 可以说 Codex 是 OpenAI 面向软件开发/代码任务的 coding agent。
- 可以说 Codex 能帮助读代码、改代码、跑命令、修 bug、做 review。
- 可以说 Codex 有多个官方使用入口，如 Codex app、CLI、IDE extension、Web/Cloud；视频里只说“可选入口”，不做安装教程。
- 可以说 Codex 默认有 sandbox/approval 机制，不应被描述成会随便读全盘或自动联网。
- 可以说普通人使用时应先把具体任务讲清楚，而不是直接抛大而空的“做系统”。
- 可以用“表格整理、小网页、文件处理”作为解释性案例，但要说明是示例。

## 黄区

- “免费用户也能用”：官方帮助页提到 eligible plans 可能包括 Free，但额度/可用性随账号和计划变化；视频不写死。
- “是否需要订阅/权限”：只说“看账号和计划，额度不同”。
- “Codex 一定能完成某类任务”：改成“更适合从这类任务开始试”。
- “不会代码也能做系统”：容易夸大，改成“能从一件重复事开始做小工具”。

## 红区

- 不说“零基础一键做完整系统”。
- 不说“免费可用”。
- 不说“所有人现在都能用某个入口”。
- 不展示未经核验的官方 UI 当作真实界面。
- 不承诺具体执行结果、速度、成功率。
- 不说“Codex 不需要授权就能联网、读全盘、自动发布”。
