# W26D09 · 内核提炼

## 一句话价值锚

普通人用 Codex 的第一步不是学代码，而是把一件重复事讲清楚。

## P0 信息

1. 不能把这条做成“Codex 功能介绍”，否则会像 AI 教程号。
2. 反常识钩子是：第一次用 Codex，别先让它写系统。
3. 入门方法必须落到三件事：现在怎么做、哪里重复、想要什么结果。
4. 案例必须具体：客户表格改格式 → 今日跟进名单。
5. 结尾必须让用户选择自己的第一件任务，促评论。

## P1 信息

- Codex 可以被表达为“帮你把清楚的重复流程变成可试的小工具”的 coding agent。
- 不讲具体安装、订阅、权限细节，避免产品口径过时。
- 不承诺“不会代码也一定能做复杂系统”，只强调从小任务开始。

## 不可删句

```text
很多人第一次打开 Codex，第一句话就问错了。
```

```text
普通人更好的用法，是先交给它一件重复事。
```

```text
它不是让你先变成程序员，而是把你说得清楚的重复流程，变成能跑起来的东西。
```
