## 可引用转述

- Codex 是 OpenAI 的 coding agent，可用于写代码、改代码、跑命令、查项目、修 bug、做 review，把改动推进到提交/PR。
- 普通人入门入口不要写成唯一入口；官方文档包含 Codex app、CLI、IDE extension、Web/Cloud 等不同使用方式。
- 新手最稳的用法不是“重写整个系统”，而是让 Codex 解释项目、找 bug、小步修复、补测试、做 code review。
- 权限表述要谨慎：官方有 sandbox/approval 机制，通常在当前 workspace 内工作，联网或越界能力需要批准或配置。
- 计划/额度表述要谨慎：不同 plan 的可用性、额度和 credit 选项会变化；视频里不写死。

## 对脚本的约束

- 不做安装步骤。
