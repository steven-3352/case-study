# 形式选型 · format_spec

> 选题 ID: T016 · 内容 ID: W26D08

## 原则

本条不设固定技术优先级。每一镜按意图选择形式，目标是停划、看懂、互动和差异化。

## 抖音

- render_route: mixed_broll_evidence_gsap
- 画面语法:
  1. Pexels 竖屏 B-roll：手机消息 / 小老板电脑前处理客户
  2. 仿真聊天栈：客户消息混乱
  3. Agent 分工卡：分层 / 提醒 / 预警
  4. 今日待跟进看板：售后风险、复购提醒、沉默客户
  5. 风险预警卡：退款、差评、高价值客户沉默
  6. CTA 选项卡：分层 / 回访 / 复购 / 售后

## 小红书

- delivery: video_reuse + custom_carousel_only
- 轮播建议:
  1. AI agent 不是替你聊天
  2. 私域真正乱在哪
  3. 先做客户分层
  4. 再做节点提醒
  5. 再做风险预警
  6. 机器盯节点，人聊关键客户
  7. 你最容易漏哪一步

## 禁止路线

- 禁止复用旧的通用卡片视觉直接出片。
- 禁止复用旧的报纸式轮播作为小红书成品。
- 禁止只把 Pexels 写进说明而不实际下载/剪入首镜。

## 与上一条差异

- 不沿用 D06 纸质账本/对账视觉。
- 不沿用 D07 泳道蓝图。
- 本条用“消息混乱 → Agent 分工 → 今日清单 → 风险预警”的私域运营语法。
