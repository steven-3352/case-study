# motion_wow

## 本条唯一性

本条视觉不围绕“录屏优先”或“GSAP 优先”，而是按镜头目的混合：

1. 首镜用 Pexels 手机消息压力感，先抓“私域很吵”的情绪。
2. 中段用聊天栈，把新客/退货/沉默/复购混乱可视化。
3. Agent 分工不做科技脑图，做成运营工作台里的三个助手。
4. 今日待跟进看板把价值落到“人工今天先跟谁”。

## 创意点

- 创意点 1：消息泡泡自动归类成 4 个客户状态。
- 创意点 2：三 Agent 不是机器人形象，而是“运营岗位卡”。
- 创意点 3：风险预警像客服工单提醒，不像科幻 HUD。
- 创意点 4：CTA 直接变成四个可评论选项。
