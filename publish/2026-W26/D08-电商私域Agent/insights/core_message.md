# 洞察包 · core_message

> 选题 ID: T016 · 内容 ID: W26D08 · 工种: 内核提炼师

## 核心判断

电商老板做私域，AI agent 最先解决的不是“替你聊天”，而是把客户节点盯住：谁该回访、谁该复购、谁有售后风险、谁值得人工优先聊。

## P0

1. 私域的第一问题不是群发少，而是客户状态混乱。
2. Agent 的第一价值是做分层、提醒、预警。
3. 人工只处理关键客户，才不会把私域做成另一个客服黑洞。

## 价值锚

> 机器盯节点，人去聊关键客户。

## 可删项

- 技术架构
- 大模型原理
- 自动成交承诺
- 复杂 CRM 名词

## 禁写

- “一键搭建私域闭环”
- “全自动成交”
- “私信我”
- “扣 1 拿方案”
