> 选题 ID: T016 · 内容 ID: W26D08 · 工种: 领域专家

## 业务拆解

电商私域里最先值得自动化的不是“聊天内容”，而是客户状态和节点。

| 模块 | 原来靠什么 | Agent 可先接什么 |
|------|------------|------------------|
| 客户分层 | 客服记忆 / 手工标签 | 新客、复购客、沉默客、售后风险 |
| 节点提醒 | Excel / 个人日历 | 发货后回访、复购周期、售后未处理 |
| 风险预警 | 老板翻聊天 | 退款集中、差评苗头、高价值客户沉默 |
| 人工跟进 | 谁想起来谁跟 | 今日关键客户清单 |

## 画面素材建议

- Pexels B-roll: 小老板看手机消息、客服电脑前处理消息、夜晚笔记本工作。
- 仿真体裁: 微信聊天栈、客户分层表、今日待跟进看板、风险预警卡。
- 不需要真实录屏才能做；但不能把仿真看板冒充真实后台。
