# D08 · 电商私域 Agent · 讨论室摘要

## Round 1 · 选题定义

**编导：** 用户原题是“我是一个电商老板，正在尝试做用户私域。现在的 AI agent，能帮我解决什么问题?” 不做 AI agent 教程，改成具体私域流程：分层、提醒、预警。

**记者：** 场景要落到老板每天打开订单、微信、客服聊天，不知道先跟谁。不要写“AI 自动成交”。

**内核提炼师：** 价值锚是“机器盯节点，人去聊关键客户”。

## Round 2 · 脚本

**编剧：** vA 用女装小电商场景，开头“私域不是多发消息”，三段解法自然。

**留存设计师：** 0–3s 用反常识 + 手机消息压力画面；中段每 6–8s 换一次画面语法。

## Round 3 · 形式

**形式选型师：** 不设固定优先级。首镜 Pexels B-roll，混乱段用聊天栈，解法段用 Agent 分工卡，价值段用今日待跟进看板。

**平台表现分析师：** 缺真实录屏会影响证据感，但本条是“能帮什么问题”的说明型内容，不是项目复盘。可用 Pexels + 仿真体裁，只要不伪装成真实后台。

## 决议

- 脚本：vA
- 抖音：混合视频
- 小红书：视频复用，可转 7 张轮播
- 状态：package_ready，待 render 后 Phase B 复验
