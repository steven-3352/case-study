# T042 配音稿 v2 · 证据边界版

1. 同一个迷茫问题，我跑了两轮。普通问法首答内就给建议；加上流程后，它只问一个问题：你现在靠什么活着？
2. 差别只支持到这里：回答顺序变了，不代表更准，也不代表真能帮你找到方向。
3. 这份流程先收四类生存事实：靠什么活、还能撑多久、真正做过什么、过去放弃过什么。
4. 再问两件事：你最怕什么；三个月后，什么状态算没白过。
5. 最后逼到行动：你是买方还是卖方、第一个真实用户是谁、这周最小验证什么。
6. 九问之后还有第十问：现在，你能不能说出一个之前没有的具体下一步？
7. 完整指令放在画面上。你最卡哪一问，评论留个数字；AI 先问事实，拍板和验证还是你自己。

红线：不声称效用提升；第十问是编辑补充；以最终 MiniMax timing 为唯一时基。
