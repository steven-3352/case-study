# S4系列共享视觉基础设施复用声明

> 适用:T040/T041/T042/T043/T044(系列「让AI说真话」)
> 目的:避免每条重复从零做 openmontage_brief/form_competition/design_language——这些判断的依据是**内容性质**(真实AI输出证据展示),5 条选题内容性质高度一致,判断结论天然共享。但**不是盲目复用**:每条production docs阶段仍需独立确认"这条有没有特殊情况需要偏离"。

## 复用什么(已由 T040 独立判断,验证有效)

1. **openmontage_brief → disabled_by_choice**:核心资产是真实API输出/真实文本,视觉命题是"给观众看证据",OpenMontage的生成式能力(运镜/形象/场景)用不上。此判断依据"内容是真实证据展示"这个共性,T041-044同样成立。
2. **视觉路线 → 方案A(P001真实截图合成+ffmpeg)为骨架,局部混GSAP(P004)做精细排版动效(指令卡逐行/长文滚动锁帧),真实录制片段(raw)仅用于"证明动作真实发生过"的窄场景(如T040④真实打字闪回)**。
3. **design_language → 浅色/白底为主**(2026-07-16 T040 v1暗色被打回重做后确立,已写死进 `CLAUDE.md`):canvas暖白`#faf9f6`、surface浅暖灰`#eeece5`、ink近黑`#1c1e22`、accent血红`#c0392b`(危险/致命点高亮)、secondary深琥珀`#9c6b0a`。参考气质:Notion/Airtable/Mintlify(明亮知识库文档感),不用Linear/Vercel/Cursor暗色开发者工具美学。字体层级(display/headline/body/caption/mono)、组件规则(自绘对话气泡非品牌UI截图、指令卡mono字体但非终端窗口皮肤)全部照搬T040 `design/design_language.md` §2-3。
4. **反同质硬规**:不用W29连载"数字桌面纪录片终端风"皮肤;不用catalog标配三连;不堆玻璃拟态/多层发光/夸张圆角。

## 每条仍需独立判断的(不能盲目复用)

1. **具体镜头设计**(retention_beat_sheet/motion_storyboard/form_strategy/storyboard.yaml):每条脚本内容不同,节拍/画面主体/时长必须按各自脚本重新设计,不能套用T040的镜头顺序。
2. **是否有特殊内容需要偏离共享路线**:比如某条若需要展示"多角色对比"这类T040没有的画面机制,要重新走五维打分,不能因为"系列复用"就放弃独立判断。
3. **motion_tech_plan的具体技术清单**:技术路线(GSAP/capture_frames.py机制)复用,但每条的具体场景/参数需要按各自storyboard重新拆解。
4. **audio_plan.yaml**:VO硬约束(真人声,禁TTS)对全系列都成立(同一账号人设),但每条的录制内容/emotion_arc要按各自脚本单独写。
