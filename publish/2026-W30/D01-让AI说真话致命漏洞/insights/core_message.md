# T040 内核提炼

> 状态：`draft` · 依据：2026-07-19 双轮受控 A/B

## 价值锚

**做辞职或重投入创业决定前，别只让 AI 全面评价；让它先指出一个尚未验证、却决定成败的前提。**

## 不可删信息

| 优先级 | 信息 | 证据边界 |
|---|---|---|
| P0 | 普通问法在两轮中也指出“能力/市场尚未验证” | 不能说普通问法没挑刺 |
| P0 | 单点问法两轮都在第一句优先指出“能否交付客户愿意持续付费的结果尚未验证” | 只能描述本次模型输出，不等于客观真漏洞 |
| P0 | 完整 Prompt 要求只讲一个，并优先找尚未验证却决定成败的假设 | 可复制收藏物 |
| P1 | 被测辞职计划是虚构实验材料 | 不是作者经历、客户案例或真实创业复盘 |
| P1 | AI 负责提出优先核查项，人负责查证和决策 | 不承诺用了就能避坑或成功 |

## 一句话口径

全面建议不是错，但大决定前，先让 AI 把一个必须验证的前提放到第一句。
