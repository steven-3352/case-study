**四场硬切**：
- 0s → 12s **场景 1**：山夜 · 轩珩 & 中里毅（青灰调）
- 12s → 25s **场景 2**：断桥雨战（水墨爆点）
- 25s → 40s **场景 3**：长街酒肆（暖光但克制在青灰）
- 40s → 52s **场景 4**：山顶群像 · 收尾（明月+云）

**大字歌词字体**：思源宋体 Heavy 或汉仪长美黑 · 主字 100–140pt · 括号副 tag `【明月天涯】` 每段固定右下。

**DV UI**：从第 8 段（22s，诺兰进入）开始叠加。竖侧`RECORDING` + 底部动态时间码 `%{pts\:hms}` + 右下电池 + `1h 15m` 假时长。

## 4. 制作路径决策

按 playbook §2.2 三方案打分：

| 方案 | 打分 | 说明 |
|---|---|---|
| A · 剪映 | ★★★★☆ | 大字预设 / 光效 / 节拍分析都有，出片快；DV UI 需自制 PNG |
| B · AE | ★★★☆☆ | 精度好但客户预算未知，上手成本压 |
| C · FFmpeg 脚本 | ★★☆☆☆ | 一次单条不值当，除非客户后续要一批 |

**决策：走 A（剪映）为主，本引擎只出立绘/背景素材。**

### 4.1 走本引擎的部分

**只做两件事**：

1. **立绘补齐 & 换装**（`pipeline/gen_d07_stills.py`）
   - 复用 D06 GPT-image-2-1k `/v1/images/edits` 多参考图管线
   - Cy / 中里毅 / 诺兰 各生 3 个姿势（正面近景、侧脸远景、背影/剪影）
   - 轩珩已成武侠不换装，只补 2 姿势（持箫+高马尾特写、背影抱剑）
   - 4 场景背景各 1 张（山夜/断桥雨/长街酒肆/山顶月）
   - 5 线程并发；产出 `tmp/d07_moon/stills/*.png`
   - **调色板锁**：`neg = neon purple, neon pink, saturated red`；`hint = ink wash, black white cyan tint, silver, moonlit`

2. **交付源包**（不做视频拼接，交给剪映）
   - 15 张立绘 PNG（透明底优先）
   - 4 张背景 PNG（1920×1080）
   - 15 条歌词 SRT（用 WAV 起始时间对齐）
   - DV UI PNG 模板（一次做，多客户复用）
   - `shotlist.md`（本文 §3 表）

### 4.2 不走本引擎的部分

- **视频合成**（大字弹入 / 光效 / DV UI 动态时间码 / 粒子 / 色差 / fade）→ 剪映
- **节拍打点**→ 剪映内置节拍分析
- **交付**→ 剪映导出 1080p H.264 8Mbps
