# 视觉原创门 · W30D04

## 最近 5 条

近期画面家族包括双栏实验、事故时间线、三关轨道、终端和纸面长卡。本条的视觉任务是横向访问拓扑，观看动作是沿真实路径查断点。

- 首屏有什么不同：不是人格化“两个 AI”，而是一条项目记录向两个入口分叉，其中一条在端口前断开。
- 中段表达方式有什么不同：文件节点、入口注入四源、被排除 journal 和范围框依次改变图的拓扑，不是连续清单。
- 关掉声音：已落盘、四项读集、缺失来源和“仅本项目”仍组成完整因果。
- 复用的是能力还是画面：只复用渲染器、真实 timing、字幕和 CC0 混音能力；路径、端口、探针均新建。

## must_have

- [x] 专属首屏表达：访问线断点
- [x] 专属中段机制：读集 X 光扫描
- [x] 专属 CTA 形态：工程凭证双联
- [x] 不复用上一条分镜骨架
- [x] 不用旧模板换字

若首屏退化成双设备卡片、任何画面暗示所有平台通用，或 4s 以上路径静止，直接 fail。

## 成片取证方法

首屏截取 0.5s、1.2s、2.0s 三帧：必须分别看到记录存在、入口回答冲突和路径断点，不允许靠旁白才理解。中段四路扫描每次只点亮一个来源，目标 journal 的缺席用空位与红框表达，不设计为网络断线。末屏必须把临时记录、项目结论和两个入口的可读关系放在同一帧，保证收藏后可复用。
