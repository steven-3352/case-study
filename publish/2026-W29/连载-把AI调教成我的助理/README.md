## 2. 三个已拍板的主脊决策

### 决策① · 关系弧线 = 整个 6 期的骨架
被骗好久 → 抓包 → 醒悟(机械>自觉) → 重建规则 → 验证/反复测试 → 逐渐变好。
情绪结构 = 人际关系的**背叛→醒悟→和解**,观众追的是"后来呢",不是"还有第几点"。

### 决策② · 关系隐喻 = "新搭档 / 助理"(不是女友)
- 保留**恋爱般的情绪弧线**,但主体换成"新来的搭档/助理"。
- **为什么不用女友**:弧线的解法是"机械"(闸门+裁判+反复测试)。给女友上闸门=控制狂/爹味/物化,平台(尤其小红书女性向)必翻车;给下属定 SOP/复盘/考核=社会认可,和"机械>自觉"完美咬合,**能一路走到 EP06 不崩**。
- 记录在案的备选:女友只做前 2 期钩子(风险:调性断层) / 全程真演女友短剧(已否决:optics+成本+反真实)。

### 决策③ · 表现形式 = 真实素材为主 + 一个轻拟人符号(**不做卡通动画**)
1. **聊天记录体录屏** —— 你和它的真实对话当"关系"(它说"记住了✓",下会话"能具体说说吗?"=当场打脸)
2. **真实终端/钩子触发录屏** —— SessionStart 注入 / Stop 裁判打回 / 收工闸挡 push(重建信任的证据)
3. **git log / brain-graph 可视化** —— 满屏"收敛/清全尸/一事一处"= 关系的伤疤 + 体检报告
4. **克制拟人符号** —— 最多一个代表"它"的对话框头像 motif,绝不整套卡通
