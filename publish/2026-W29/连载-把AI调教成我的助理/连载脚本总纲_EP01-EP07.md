## 0. 全系列一句话 & 铁律(每集不得破)

**一句话**:一个人真实地把通用 AI 调教成"懂我、可验证、绕不过约束"的私人助理——**被骗→抓包→醒悟→重建→验证→翻车→变好**的关系弧线,成功和翻车都记。

**不得破的铁律**:
1. **诚实纪录片口吻**,第一人称。绝不滑向"我的 AI 多牛"的元叙事(§9:"写成真实记录是内容,写成效果炸裂就是元叙事")。
2. **隐喻 = 新搭档/助理**(非女友),留恋爱般情绪弧线但主体是"带一个下属"。
3. **每集单核**:一集只讲一个不可删的核心信息。(EP04 拆上下正为守此律。)
4. **每集集尾勾下集**:留"后来呢"的扣子,不是"还有第几点"。
5. **只用真实锚点**:真原话 / 真 commit / 真翻车 case;不编时长/数字/没发生的事。幻觉类并入"说做了没做/编个假成片交差"(真实的编造),不硬凑纯幻觉 case。
6. **表现形式**:终端/Claude Code 代码感 B-roll(聊天记录体 / git log / brain-graph)+ 一个轻拟人 🤖 对话框 motif,不做卡通动画。视觉语言已锁(`assets/ep01_*.html`:深底 #0b0e14 + 系统绿/琥珀/血红 + 红戳,禁霓虹)。
7. **北极星**:真实推进 + 真实同路人,不是播放量(§102)。CTA = 追连载 / 评论区找同路人(非变现)。
