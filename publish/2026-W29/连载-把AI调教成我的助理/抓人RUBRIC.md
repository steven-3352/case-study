# 抓人 RUBRIC · 钩子 + 情绪硬标准

> 起因(2026-07-09):EP01 编剧首版"合格但太平",最抓人的洞察反而是用户(非专业)提的。系统缺一道"抓不到人就打回"的门。此表 = 所有创作类 agent(编剧/留存/动画导演)的**最低出工门槛**,也是"停划裁判"的打分表。
> 归属:先放本连载;验证有效 → 升级进 `templates/` + `pipeline/gate_check`,并写进创作 agent 的 brief。

---

## A · 前 3s 钩子(必须命中一种"停划机制")
- [ ] **秘密/坦白**(悄悄告诉你 / 我不太好意思承认…)—— 人对悄悄话零抵抗
- [ ] **反常识/打脸**(你以为…其实…)
- [ ] **高风险悬念**(我差点… / 那天我…)
- [ ] **冲突画面直给**
- **必带**:①情绪(羞耻/脆弱/火/后怕,不是中性)②好奇缺口(逼观众想知道后续)
- **禁**:平铺直叙介绍背景("今天讲一下我怎么…")

## B · 口播是"说话"不是"旁白"
- [ ] **短句、断句**(一句一个气口;关键处一字一顿:它、不、看)
- [ ] **口语语气词**(欸/好家伙/结果呢/你猜/我跟你讲)
- [ ] **情绪落差**(平静↔爆发↔发凉,同一条至少 3 个转折)
- [ ] **可表演**(每句能标出"怎么念")
- **禁**:解释感受("最可怕的是…因为…")、长复合句、匀速平读、书面词

## C · 情绪曲线
- [ ] 全片有明确起伏图,**顶点(必炸)+ 落点(必凉/必戳)** 两个锚点单独验收
- [ ] 不允许中段一路平

## D · 传播性
- [ ] 至少 2 句能被单独截成封面/评论区置顶(自带金句)

## E · 停划裁判(出工种前必过)
逐句盘问,命中任一即打回重写:
1. 这句会让人划走吗?
2. 这句没情绪 / 是中性陈述吗?
3. 这句像旁白解说,不像一个人在跟我说话吗?
4. 顶点够炸吗?落点够凉吗?还是"讲道理"?

> **达标线**:每句过 E 的四问;A/B/C 全绿。不到线不准进下一工种。宁可重写,不出"合格但平"的稿。
