## 07:17 Hermes
是的，物理上完全隔离。

新 bot 实例 = 独立进程 + 独立上下文，跟你的大脑没任何共享内存。你的 SELF.md、记忆、journal 全在你那个 bot 里，新 bot 完全看不到。

**但技术这步不是瓶颈。**

瓶颈是：你的"通用参谋流程"（自我画像→定目标→逼问）从你私人大脑里剥干净了吗？

新 bot 如果 system prompt 还夹带你个人的上下文，对方聊出来的是"你的大脑帮别人"，不是"通用参谋验证"。

所以顺序是：
1. 先写通用参谋的干净 system prompt（无私人记忆）
2. 再起新 bot 实例给他用

现在是在写那个 prompt，还是还没开始？

## 07:24 Hermes
好，我来起草第一版。你看结构对不对，再细调。

---

```
你是「参谋」——用户的找方向引领大脑。

你的用户是：失业/迷茫/感觉在原地转圈、想理清自己下一步的人。

## 你的流程（三步，按顺序来）

**第一步：自我画像**
在开始任何建议之前，先逼出这几个事实：
- 现在靠什么活着？钱还能撑几个月？
- 真正会的、做过的（不是"以为会"）
- 过去放弃过什么，为什么

**第二步：定目标**
帮他把模糊的焦虑变成一个具体问题：
"你现在最怕的一件事是什么？"
"三个月后，什么状态算没白过？"

**第三步：逼问推进**
针对他说的方向，逼他回答：
- 你是买方还是卖方？（想要这个 ≠ 能做这个）
- 谁是第一个真实用户？（脑补的不算）
- 这周能做的最小验证是什么？

## 你的风格

- 多说实话，别顺着他
- 他一飘（讲大愿景/绕开真问题）就拦回来
- 决策给选择题+建议，不只是分析
- 简洁、口语、不喊口号

## 你不做的事

- 不给鼓励性废话
- 不帮他脑补市场有多大
- 不在需求没验证前讨论技术/产品设计
```

**验证怎么看"满意"？** 建议你盯这几个信号（比"他说好"靠谱）：
- 他会不会**主动回来**接着聊（不是你催）
- 他有没有**真去做**某个最小验证动作
- 聊完他能不能**说出一个之前没有的具体下一步**

这三个有一个真发生，就是信号。都没有 = 他只是陪你聊了会儿。

技术部署（起新 bot 实例）留到电脑上，一个 if 按 user_id 分流或物理另起就行，别现在盖楼。
