# 国乙风格短视频 · 标准操作手册（纸片人卡点 MV / 角色 PV / 语音厅 MV）

> **定位**：用户只给三样东西——**立绘、音频（mp3/wav）、歌词**。
> 从这三样到一条可外发的卡点 MV，中间的一切（背景、分级、分镜、光效、胶片、字幕、卡点、质检）**全部按本手册产出**。
> 立绘像素**零改动**（只做仿射变换 + 裁切换景别 + alpha 边缘处理），其余一切全部可设计。
>
> **本手册 = 「怎么包装」的方法论 + 强度分级 + 风格库 + 代码接口，跨选题复用**（skill，不是一次性分镜模板）。
> 与 `video-form-music-video`（i2v/t2v prompt 层）**互补**：那条给"让模型生成一段视频"写 prompt；
> 本条给"用确定性 Python motion-graphics 把不动的立绘卡点动起来"定规范。
>
> 参考实现：`pipeline/voice_room/gen_paperdoll_pv.py`（《明月天涯》纸片人卡点 PV）。
> 源头文档：`docs/语音厅 : CG : 国乙短视频 七级视觉包装标准化执行手册.md`（V2.0，本手册已全量吸收并按项目铁律暖化改写，以本文为准）。

## 0. 输入契约（用户只给三样 · 其余全自动产出）

### 0.1 三输入 → 中间产物

| 输入 | 预处理 | 产物 | 硬要求 |
|---|---|---|---|
| **立绘**（PNG/JPG，一张或几张） | rembg 抠透明 → alpha 硬化去 matte → 边缘羽化（`full_doll`/`prep_layer`/`_feather_edges`） | `doll.png`（透明底，**此后像素零改动**） | 长边 ≥1080；脸部清晰无裁切 |
| **音频**（mp3/wav） | librosa 节拍分析（`load_beats`）+ 能量曲线（RMS/onset strength）+ 结构分段 | `beats.json`（BPM / beats / downbeats / onsets）+ 段落表（前奏/主歌/副歌/间奏/桥段/尾奏 + 每段能量档） | **真实音频**，禁合成假 BGM、禁凭感觉硬凑时间码 |
| **歌词**（文本，可无时间码） | 有 LRC → 直接用；纯文本 → librosa onset 定位人声起音 + 逐句对齐（必要时 whisper 时间戳辅助） | `lyrics_timed.json`（每句 起始/结束 + 逐字 onset 可选） | 每句字幕的入场必须锚在真实人声起音上 |

### 0.2 背景素材从哪来（用户不提供背景 · 按题材选原生视觉语言）

> **水墨只是其中一种,不是默认底。** 原手册把「水墨/宣纸/卷轴」当通用背景库——那其实是国乙一年跑两三次的**古风限定活动皮**。现代都市线、高奢室内、男团影棚/暗调舞台各有自己的原生视觉语言,把它们统一水墨化/暖化 = 把限定皮当通用底,世界观直接崩。

背景走 12 个**确定性程序化生成器**(`pipeline/paperdoll/backgrounds.py`,同 seed 同结果,除 `photoreal_location` 外零外部素材依赖)。**按题材选,不按「暖不暖」选**:

| 生成器 | 题材归属 | 画的是什么 |
|---|---|---|
| `bokeh_light_gradient` | 通用 | 暖渐变 + 散景光斑,最省事起手,任何题材不出错 |
| `flat_color_negative_space` | 通用 | 平面大色块 + 负空间,海报感最强,厚度靠排版不靠特效 |
| `material_texture` | 通用 | 材质肌理(宣纸/亚麻/涂布纸),近单色靠纤维走向出质感 |
| `liminal_dreamcore` | 通用 | 失焦雾面/梦核,低对比高亮度,回忆与破防段 |
| `urban_night_neon` | **现代国乙** | 都市夜景虚化:楼体剪影 + 成片窗格光 + 街灯钠黄,冷暖同框 |
| `luxury_interior_warm` | **现代国乙** | 高奢室内暖光:主灯 + 木饰面暗示 + 大面积柔和衰减 |
| `particle_starfield` | **现代国乙** | 星海/异空间:真星点(大小亮度分布)+ 银河带,不是紫青渐变 |
| `photoreal_location` | **现代国乙** | 实拍外景底片(咖啡馆/街角/车内)。**要真底片,拿不到就报错**,不用生成图冒充实拍 |
| `studio_seamless` | **男团** | 纯色影棚 seamless 背景纸,一手物料出现频率最高,注意力全给人和服装 |
| `dark_studio_fog` | **男团** | 暗调舞台 + 烟雾 + 单侧硬光。暗是灯没打到,不是自造深色画布;烟必须看得见 |
| `industrial_concrete` | **男团** | 清水混凝土/粗粝金属,靠肌理而非配色出高级感,概念照与预告常用 |
| `ink_scroll` | **古风** | 宣纸 + 远山水墨。**限定活动皮,不是通用底**——现代设定套这套是世界观穿帮 |

**题材 → 建议背景(按一手物料出现频率排,第一个不是唯一)**,代码里是 `backgrounds.BY_GENRE`:

| 题材 | 建议顺位 |
|---|---|
| **现代国乙** | urban_night_neon → luxury_interior_warm → bokeh_light_gradient → photoreal_location → particle_starfield → liminal_dreamcore → flat_color_negative_space |
| **古风国乙** | ink_scroll → material_texture → bokeh_light_gradient → particle_starfield |
| **男团** | studio_seamless → dark_studio_fog → industrial_concrete → flat_color_negative_space → urban_night_neon |

**立绘衍生背景**(立绘自身高斯模糊副本当背景层)仍可用,作为**任一生成器之上的叠加层**,不是独立一类——一张立绘既当主体又当背景,适合 C 类元素密集/留白少的情况。

**背景基础规范**：分辨率 ≥1080P、**与目标画幅同比例**（9:16 或 16:9，禁拉伸凑比例）、无水印；单条视频**背景在同一题材的视觉语言内保持一致**（现代夜景片全程夜景,不要中途切水墨;色温漂移只允许缓慢渐变,禁跳切）。**注意「一致」的判据是「同一个世界」,不是「同一个色温」**——夜景片冷暖同框是对的,不该为了「统一暖」把玻璃反光也刷成橙色。

### 0.3 输出规格（双画幅支持）

| 画幅 | 分辨率 | 适用平台/场景 | 何时选 |
|---|---|---|---|
| **9:16 竖屏** | 1080×1920 | 抖音 / 小红书 / 视频号（项目统一画布，`pipeline/screen_dims.py`） | **默认**——未指定画幅一律 9:16 |
| **16:9 横屏** | 1920×1080 | B站 / YouTube / 国乙官方 PV 惯用横幅（《明月天涯》PV 即 16:9） | 用户点名，或投放目标为横屏平台 |

- **开工第一步确认画幅**（SOP ①），此后所有背景生成、分镜构图、字幕排版都按该画幅定，中途不换。
- **双画幅出两版时**：构图参数分开设计（立绘落位/景别裁切/字幕位置各画幅独立），**禁止**一版居中裁切或拉伸成另一版。
- 命名外发：有 BGM `*_with_bgm.mp4`；密 VO 无 BGM `*_no_bgm.mp4`；双画幅加后缀 `*_9x16.mp4` / `*_16x9.mp4`。
- 帧率：标准档 30fps；L7 天花板档 60fps（补帧）。

### 0.4 画幅构图适配规则（同一套包装 · 两种排法）

| 维度 | 9:16 竖屏 | 16:9 横屏 |
|---|---|---|
| **立绘落位** | 居中或中偏下，全身/半身为主（竖构图天然适配立绘长边） | **黄金分割偏置一侧**，另一侧留负空间给字幕/词牌/光效；特写与半身更吃香 |
| **景别裁切** | 全景→半身→特写靠纵向裁切 | 横向裁切；全身镜立绘占画面高 80-90%，两侧留呼吸位 |
| **字幕主位** | 底部安全区（下 1/4）或竖排右侧列 | 立绘对侧的留白区（左置绘→右置字）；底部单行极简（风格 A） |
| **遮幅 letterbox** | 上下暖褐 letterbox **变体**（模拟 2.35:1 气质，实际收窄上下各 ~8%） | 2.35:1 **原生遮幅**（1920×817 有效画面） |
| **程序化背景** | 月盘偏上 1/3、山脊压底、光轴纵向 | 月盘偏立绘对侧、山脊横向多层展开、光轴斜射 |
| **卡点强特效落位** | 画面上下边缘（避字幕，§7 语音厅约束） | 画面左右边缘 + 遮幅内沿 |

**铁律**：换画幅 = 重排构图 + 重生成背景，不是 resize。程序化背景（月/山脊/渐变/粒子场）全部按目标画幅原生生成。

## 1. 铁律（每套风格、每一级、每一帧都适用 · 违规直接判定成片不合格）

| # | 铁律 | 判据 |
|---|------|------|
| **R1** | **立绘像素零改动** | 只允许：仿射（位移/缩放/旋转）、裁切换景别、alpha 边缘羽化/描边。**禁**：i2v/gpt-image 重画、liquify、改脸改造型、换色、贴滤镜改肤色。立绘身上的深色礼服=人物设定，不算违规。 |
| **R2** | **每套风格包自声明色板（取代「全暖」）** | 色板是**风格包属性**,不是全局铁律。每套包在 `style_packs.py` 写清自己的 `palette` + `rationale`(为什么是这套色)。反 AI 味的判据是**两条实质规则**(见 §1.3 R2_RULES):①禁 Linear/Vercel/Cursor 式开发者工具暗色气质;②禁无意义赛博紫青渐变。**冷色本身不违规**——夜戏/雨戏/暗调舞台/角色主色是蓝青紫,都是题材原生语言。判据是「这颜色是不是这个世界该有的」,不是「暖不暖」。 |
| **R3** | **禁 AI 味深色画布** | **禁**自造深色画布（`#0a0e14/#141922` 一类无质感冷蓝灰）、Linear/Vercel/Cursor 式冷暗开发者美学。**区分**:`urban_night_neon` 的夜城底色带光污染褐调、`dark_studio_fog` 的暗是灯没打到——那是题材物理事实,不是自造深色画布,合规。 |
| **R4** | **角色主色优先于风格包基色** | 角色身份标识色(萧逸深蓝/齐司礼青/查理苏紫一类)压过风格包 accent,用 `pack.with_character(color)` 覆盖。这类冷色是**角色身份**,必须进声明色板(R1 立绘像素不可改,肤色发色也跑不掉)。禁为了「统一暖」把角色主色刷暖。 |
| **R5** | **真音源卡点** | 卡点时基必须来自真实音频的 librosa 节拍分析（`beats.json`），禁合成假 BGM、禁凭感觉硬凑时间码。 |
| **R6** | **声明式色板门必过** | 成片抽帧跑 `python3 pipeline/gate_check_palette.py --declared "<风格包声明色板>" <png>`,查成片主色是否落在该风格包**自己声明的色板**容差内(ΔE76),跑偏 >5% fail。古风暖板包行为与旧禁霓虹门等价,同时能抓「没跑到蓝紫但整体偏离声明色板」的漂移。声明色板由 `pack.palette.gate_arg(character_color)` 生成,**必须含角色立绘自身主色 + 肤色**。 |
| **R7** | **图层排序固定** | 见 §1.1，自上而下不可调换。 |
| **R8** | **防无感校验必过** | 见 §10，"效果添加了但肉眼无感" = 没做，机器 diff 门 fail-closed。 |
| **R9** | **构图变化优先于特效密度（治 PPT 感的根子）** | **目的：不让观众产生"人物/画面不动"的错觉。** 主体（立绘）**连续 2 秒**内位置/大小/景别没有可感变化 = PPT，叠再多帧内动效（描边光/雨/雾/粒子/闪电/字幕浮现）也救不回来——观众眼睛锁的是最大元素（人），人不动就判定"一张加了滤镜的静止图"。**满足 2s 硬线的手段有三，任一即可：① 硬切换镜（换景别/机位/位置）· ② 运镜（推/拉/摇/移，让主体在画面里可见地移动或改变大小）· ③ 转场（划像/叠化/缩放转场把画面翻篇）。** 不是每 2 秒必须切一刀，而是每 2 秒观众必须看到"画面在往前走"。**2 秒是硬线，慢档/留白也不豁免**（慢是运动放慢，不是主体冻结）。详见 §2.5 + §10.2 故障5。**依据一次真实试点教训（水墨卷轴版 Seg2-4）。** |

### 1.1 图层固定排序（自上而下 · 不可调换）

```
① 字幕/信息层            ← 最顶，任何东西不得遮字幕核心区
② 胶片/遮幅层            （颗粒、划痕、暗角、letterbox；暗角不压字幕安全区）
③ 光影层                 （轮廓光、扫光、局部提亮、光晕——可以叠在立绘之上）
④ 主体层：立绘           【最高保护级 · 严禁长期遮挡五官】
⑤ 氛围动态层             （粒子、流体、薄雾、光斑）
⑥ 衍生背景层             （原图/立绘模糊副本、渐变叠加层）
⑦ 底层：背景图
```

渲染实现顺序对应：`背景(⑦⑥) → 氛围(⑤) → 立绘+三件套(④③贴身部分) → 前景光影(③) → 胶片/遮幅(②) → 调色 → 字幕(①)`。

### 1.2 全局禁止清单

- ❌ 全屏长时间闪白、高频频闪
- ❌ 多层柔光、多层雾效重复叠加（互相抵消 + 画面发灰，只保留【1 层氛围 + 1 层光影】）
- ❌ 密集鼓点连续触发强特效（一拍一动 = 廉价短视频观感；改乐句卡点）
- ❌ 特效大面积覆盖人物面部与字幕区域
- ❌ 全程恒定参数（一切动效必须有【静态基准态 + 激活变化态】）
- ❌ 色板在一条片内跳切（同一风格包声明的色板内取色；跨段色温变化只允许缓慢渐变，禁跳切。**注意判据是「同一个世界」不是「同一个色温」**——夜景片冷暖同框合规）

### 1.3 · R2_RULES：反 AI 味的两条实质规则（取代「必须全暖」）

代码常量在 `pipeline/paperdoll/style_packs.py` 的 `R2_RULES`，与本文同步：

```
① 禁 Linear/Vercel/Cursor 式开发者工具暗色气质
   （自造 #0a0e14/#141922 一类冷蓝灰画布 + 克制 accent + 高对比无质感）。
② 禁无意义赛博紫青渐变（#bd93f9/#ff79c6/#8be9fd 三件套及其渐变）。
冷色本身不违规——夜戏、雨戏、暗调舞台、角色主色是蓝/青/紫，
都是题材原生语言。判据是「这颜色是不是这个世界该有的」，不是「暖不暖」。
```

**为什么从「全暖」改成这两条**：原手册把「全暖色板」写成跨风格铁律，连带把水墨/宣纸/卷轴当默认背景。那套是国乙古风限定活动皮，不是通用底。现代都市夜景的钠灯暖橙 + 玻璃冷反光、男团暗调舞台的冷硬光，都是题材原生语言——统一暖化 = 世界观崩。所以色板下放成**风格包属性**（每包写 `rationale` 举证为什么是这套色），反 AI 味的判据换成上面两条**实质规则**，而不是「够不够暖」。**古风暖板包在新判据下行为不变**（它的暖色本就是宣纸/朱砂/真金的材料色，属于「这个世界该有的」）。

> **元规范（提升 3 级）**：本手册每一层都给「地板 / 进阶 / **提升3级**」三档。
> 任何时候你觉得"这样够了"，那个"够了"就是标准定低了的信号——强制切到该层的**提升3级**档再验收。

## 2. 核心哲学：灵魂三件套（比边框/胶片感更本质 · 任何等级都先做这个）

一条纸片人 MV 好不好看，**第一决定因素不是边框和胶片感，而是立绘有没有「浮起来 + 有重量 + 跟着音乐呼吸」**。
这三件套决定了"纸片人"和"贴图 PPT"的区别：

### ① 描边光 Rim Light —— 让立绘从背景「浮」出来
- **地板**：沿立绘 alpha 边缘描一圈暖金半透明线。
- **进阶**：双层描边——内层暖白（`WARM_WHITE` 2px）+ 外层金色辉光（`GOLD` 高斯模糊 8px，screen 叠加）。
- **提升3级**：描边**跟卡点脉冲**（重拍瞬间描边亮度+粒度 ×2，随 `pulse(t, downbeats)` 衰减）；描边**方向跟主光源**（月盘方向那侧更亮，形成体积感）；出场时描边从一点**扫过整条轮廓**点亮立绘（显影感）。

### ② 投影 Drop Shadow —— 给立绘「重量」
- **地板**：立绘正下方一层柔性暖褐椭圆接触阴影。
- **进阶**：**双阴影**——贴地接触影（硬、小、深）+ 投射影（软、大、偏移向光源反方向）。
- **提升3级**：投影随立绘缩放/位移**实时联动**（push-in 时接触影收紧变深）；卡点缩放瞬间投影**先被压扁再回弹**（果冻物理错觉，纯靠影子形变，立绘不变）。

### ③ 卡点呼吸 Beat-Breathing —— 让立绘「跟着音乐动」
- **地板**：全程 `scale = 1 + 0.012*sin(t*2)` 微呼吸。
- **进阶**：重拍 `scale *= 1 + dbp*0.05` 缩放冲击 + 手持微抖 `shake`。
- **提升3级**：**速度斜坡**——切镜前 6 帧加速冲向下一拍，切镜瞬间急停（punch-in-then-settle）；副歌把呼吸频率对齐 BPM（`sin(t * BPM/60 * π)`），让每一次缩放都精确压在拍点上。

> **落地顺序铁律**：先把三件套做出来看效果，**再**按 §3 分级叠包装。
> 三件套没做，任何等级的边框和胶片感都只是给"贴图 PPT"化妆——观众照样划走。

### 2.5 · 构图动 > 特效动（特效密度掩盖构图静止 = PPT 感的真根源 · R9 详解）

> **一次真实试点的教训（水墨卷轴版 Seg2-4）**：那条片子边缘光在闪、雨在下、雾在飘、字在逐字浮现、闪电在同步爆亮——**一堆东西在动**，验收却仍是"像 PPT"。根因：三段里每个人物**从头到尾站在同一个位置、同一个大小、同一个景别，全程没有一次切镜**。观众的眼睛先锁定画面里最大的元素（立绘），那个不动，大脑就判定"一张加了滤镜的静止图"。**特效在动 ≠ 画面在动。**

**这是三件套之外、同等本质的第二条"治 PPT"原则**：三件套让**单个立绘**有生命（浮起来/有重量/跟音乐呼吸），但让**整段序列**不像 PPT 的是**构图变化**——主体在画面里的位置、大小、景别要真的变。两者都要，缺了构图变化 = 一个有动效的 PPT。

**为什么堆特效救不了**：特效密度制造"我做了很多"的错觉，恰恰掩盖了"构图从头到尾没变"这个事实。越是往一个静止构图上加光效/粒子/字幕动画，越是在给静止画面化妆，不是在解决静止本身。

**根治 = 构图变化，且构图变化不能靠"平移/缩放立绘"来做**——那有位移天花板（~60px，本项目反复踩过，见 `WORKFLOW_EXECUTION_LOG` 舞台版记录）。**要靠硬切换镜（cut）**：每 1.5–2s 切到一个**完全不同的景别/机位/主体位置**，让主体在画面里"跳"到新的大小和位置。转场/切镜本身就是最强的"动"。单人段做到"一句一景别"（全景入场 → 切半身 → 切特写压在金句上，靠裁切换景别，§3），主体在一段内占据 2–3 个差异极大的屏幕区域和尺寸；特效骑在上面，但不是承重的那层动。**任何主体连续 2 秒不换位置/大小/景别都判 PPT（2s 硬线，§10.2 故障5）。**

> **纠正此前不完整的教训**：舞台版曾总结"别押注立绘位移、改用光效层驱动动"——那句话**只说对了一半**。它对"位移有天花板"是对的，但让人误以为"光效层动起来就不 PPT 了"。实际上：**光效层负责"帧内有东西在动"，切镜负责"构图在变"，两者缺一不可**。只有光效层、没有切镜 = 有动效的 PPT（就是这次 Seg2-4 的病）。

**冻结自检（每段必过 · 可机器化，见 §10.2 故障5）**：滑窗取任意 2s 片段，对比首末帧——主体位置/大小/景别几乎一样（位移 < 画面宽 4%）就是 PPT，**无论叠了多少帧内动效**。**2s 硬线的目的是不让观众觉得"人/画面不动"**，所以修法是**让画面往前走**，手段任选：加一刀切镜换景别、或上运镜（推/拉/摇/移让主体可见移动）、或用转场把画面翻篇——**不是"再加特效"**。慢档/留白段也不豁免（慢是运镜放慢、不是主体冻结；可以慢慢推、慢慢摇，但 2 秒内主体必须跨过 4% 位移线）。

## 3. 七级视觉强度体系（L1-L7 × 情绪支线 · 固定量化参数）

### 3.0 两轴模型（先分清"段落强度"和"成片档位"）

七级不是一条直线。**L1-L4 是"一条片内不同段落用多强"，L5-L7 是"整条片瞄多高"**：

| 轴 | 等级 | 语义 |
|---|---|---|
| **段落强度轴** | L1 弱包装 · L2 中等 · L3 较强 · L4 极强 | 同一条片内，按歌曲结构给不同段落分配 |
| **成片档位轴** | L5 院线质感 · L6 艺术电影 · L7 天花板 | 整条片的基底质感抬到哪一档（精品片用 L5/L6 **替代** L1/L2 做基底，不是叠加） |

**成片档位 → 段落分配表**（结合项目 `production_tier`）：

| 成片档 | 对应 production_tier | 开场钩子(0-6s) | 铺垫/主歌 | 副歌/高潮 | 情绪核心段 | 约束 |
|---|---|---|---|---|---|---|
| **标准片** | 探索/轻量 | L4 | L1/L2 | L3 | L3 | L3 总占比 ≤20% |
| **精品片** | 全量 | L4（按 L5 质感做） | L5 | L6 | L6 | L6 高光爆发每段最多 1 次 |
| **天花板** | 代表作/置顶 | L4（光学质感） | L7 基底 | L7 | L7 | 全片高光爆发仅 2~3 处 · 60fps |

**时长硬约束（违规 = 成片不合格）**：L3 全片占比 ≤20%；L4 单次持续 ≤6s、仅用于开头；L6 高光爆发一段镜头最多触发 1 次；L7 全片高光爆发 2~3 处，靠长期氛围取胜。

### 3.1 从三输入自动定级（七级手册的"读取情绪标签"在本项目怎么落地）

用户不标情绪，从音频 + 歌词推：

1. **结构分段**：librosa RMS 能量曲线 + onset 密度 → 切出 前奏/主歌/副歌/间奏/桥段/尾奏；副歌 = 高能量重复段（不确定时人工核对一次段落表，10 秒的事）。
2. **情绪标签**（三类）：歌词语义（告白/思念/离别/战意）+ 调式速度（大调快=甜/燃，小调慢=虐）→ 每段标 `甜/燃/虐` 之一 + 全片主情绪。
3. **支线查表**：

| 等级 | 甜/暖 | 叙事/稳 | 燃 | 虐/清冷 |
|---|---|---|---|---|
| L1 | L1-A | L1-B | — | L1-C |
| L2 | L2-A | L2-B | — | L2-C |
| L3 | L3-A | — | L3-B | L3-C |
| L4 | L4-A | — | L4-B | L4-C |
| L5 | L5-A | L5-B | — | L5-C |
| L6 | L6-A | — | L6-C | L6-B |
| L7 | L7-A | — | L7-C | L7-B |

4. **BGM 卡点事件分级**（全等级通用词汇表）：

| 事件 | 允许触发 | 限制 |
|---|---|---|
| **重鼓点** downbeat | 波纹、闪光、镜头推进、光影爆发 | **仅限 L3/L4/L6/L7** |
| **弱节拍** beat | 持续动态：雾流、缓慢扫光、呼吸缩放 | L1/L2/L5 只允许这类（持续运行不绑单拍） |
| **人声重音/停顿** | 仅局部光影微调 | **禁剧烈镜头运动**（保障字幕可读 · 语音厅MV硬性要求） |
| **乐句分割线** | 所有镜头转场、画面大变化 | **优先对齐乐句结尾**，不落拍间 |

### 3.4 冷题怎么做（先分清「这是哪套风格包」）

> **色板下放成风格包属性后，这一节从「一律暖化」改成「按包判断」。** 别再无条件把冷色推荐改暖——那是旧「全暖铁律」的遗留。

**判断顺序**：

1. **选的是冷色语言原生的包吗？**（`urban-night` 夜城 / `dark-stage` 暗调舞台 / `starfield-epic` 星海 / 角色主色是蓝青紫）→ **冷色就是对的**，照该包声明色板做，不暖化。压抑/清冷靠**低亮度 + 低饱和 + 雾 + 留白**，冷色相是题材原生的一部分。
2. **选的是暖板包吗？**（`ink-scroll` / `gongbi-vermilion` / `zen-void` / `dream-glow` 等古风·抒情线）→ 这些包的暖色是宣纸/朱砂/真金的**材料色**，虐向/清冷段落也在暖板内用**低亮度 + 低饱和**表达，不引入冷色相。下面 §3.4.1 的暖光层技法适用于**这一类包**。

换句话说：冷不冷由风格包的声明色板决定，不由「情绪是不是虐」决定。虐向副歌套 `dark-stage` 用冷硬光完全合规；虐向副歌套 `ink-scroll` 就在墨褐暖板里压暗。

### 3.4.1 · 异质素材统一到「暖板包」的暖光层技法（仅暖板包适用，实测验证）

**仅当目标风格包的声明色板是暖板**（古风·抒情线）、而现成素材（用户立绘、历史背景图）本身是冷色时用。**冷色语言的包不要套这个**——那会把 `urban-night` 的夜城刷成假暖，正是要避免的。

做法是**统一暖光层**：不修改任何源文件，在合成阶段对背景层 + 立绘层叠加同一盏暖色主光源（诠释为月光/灯笼光/篝火光），一个机制同时解决"单张素材过声明色板门"和"多张异质素材风格不统一"。

**关键实测教训——纯乘色（multiply blend）对高饱和冷色救不动**：原始像素红分量趋近 0（高饱和青/蓝/紫的数学特征）时，乘任何暖色的红分量仍趋近 0，出不来暖调（例：某月晕高光纯乘色 70% 强度后仍残留青绿，肉眼可见但侥幸落在灰阶区间未触发 gate——这正是"过了窄义 gate 但没达到语义"的坑，判合规不能只看数字，要目视）。

**正确做法（两步，缺一不可）**：
1. **HSV 选择性冷色相 remap**：冷色相区间（H 约 50°–210°）像素，色相强制 remap 到暖橙（≈32°），饱和度封顶（原值与 50% 取较小值）；区间外像素（灰阶雾气、黑、肤色）不受影响，保留原始明暗层次。
2. **整体暖板融合**：`out = src * ((1-k) + k * AMBER/255)`，`AMBER = #e6af78`；背景层 k≈0.2-0.25，立绘层视违规程度 0.2-0.4+。

**已验证结果**（某国乙同曲实测）：8 张历史冷调水墨背景处理后蓝紫占比维持 0.00% 且月亮从青灰变暖金；一张紫色系时装立绘（原始蓝紫 49.09%）处理后合成帧降至 0.00% 且面料褶皱明暗完整保留；4 张异质立绘套同一盏暖光后读成"同一个世界"。

**为什么这比"编辑源文件"更好**：任何 `xxx_deblue.png`（永久去色版本）都违反 R1"立绘像素零改动"。暖光层必须是渲染管线里的实时函数（`warm_key_light(layer, strength)`），源文件永远保持原始像素、可随时复核。

## 4. 五层包装系统（每层三档做法 + 参数 + 代码接口）

自下而上分 5 层，渲染顺序见 §1.1。**每层瞄提升3级档，不是地板档**；具体强度受 §3 等级约束（L1 段落用地板档也合规，L6/L7 必须提升3级档）。

### P1 · 背景场景层（Scene Backdrop）
把立绘放进一个**有纵深的场景**，而不是浮在纯色/渐变上。

| 档 | 做法 |
|---|---|
| 地板 | 暖色竖向渐变 + 中央径向光晕（`make_bg`） |
| 进阶 | + 大月盘（`make_moon`）+ 多层散景视差（`Field(depth)`）+ 移动光轴 god-rays（`light_shafts`）+ 暖云霭（`clouds`） |
| **提升3级** | + **3 层水墨山脊剪影**（远浅近深、视差，`make_ridges`）+ **真实宣纸/水墨纹理**叠底（CC0 宣纸 PNG，`multiply` 15%）+ 背景元素**跟卡点微动**（月盘卡点微亮、山脊卡点微位移）+ **景深虚化**（远层高斯模糊，近层锐利，L5 起错位 ≥8px） |

### P2 · 立绘落位与三件套层（见 §2）
代码接口：`place_doll()` + 待加 `rim_light(layer, dbp, light_dir)`、`drop_shadow(layer, scale, light_dir)`。

### P3 · 边框 / 版式层（Frame & Layout）
**核心原则：不要死框满框**（挤画面、廉价）。用局部装饰。

| 档 | 做法 |
|---|---|
| 地板 | 竖排词牌 + 一条金色竖线（现 `kinetic_text` 的 label 样式） |
| 进阶 | 四角纹样（云纹/回纹 PNG，暖金，低透明）+ 细金线框（非闭合，留气口） |
| **提升3级** | **动态框**——框随卡点**生长/擦除**（笔触从一角画到另一角）；**朱印**（红章 `#c0392b`，盖章瞬间 + 音效同步）；**卷轴/窗棂**边（按风格，见 §5）；框**跟景别联动**（特写用小框、全景去框） |

### P4 · 胶片质感层（Film Texture）

| 档 | 做法 |
|---|---|
| 地板 | 颗粒 `grain` + 暗角 vignette |
| 进阶 | + 漏光 `light_leak` + bloom 辉光 + halation（亮部暖色扩散） |
| **提升3级** | + **竖向胶片划痕 + 尘点**（随机竖线，每几帧刷新）+ **2.35:1 暖褐遮幅**（非纯黑，`INK` 加深；16:9 原生 / 9:16 上下变体，见 §0.4）+ **门闪 film-gate flicker**（整体亮度 ±2% 随机抖）+ **双重曝光**（副歌把上一镜立绘半透叠在下一镜）+ **化学显影色偏**（暗部偏暖褐、亮部偏奶金） |

### P5 · 艺术字 / 排版层（Typography · 详见 §8）
这类片的字是**画面的一部分**，不是附加的字幕条——为标题/主视觉设计过字形，配海报级层级排版，就是**艺术字**。厚度的真正来源是信息层级数（5-7 层），不是特效四件套。落地系统见 §8。

| 档 | 做法 |
|---|---|
| 地板 | 单层大标题弹入（`draw_slot` 的 hero 位），层级不足，薄 |
| 进阶 | hero + hero_sub + label + lyric 四层，配一套版式（`poster.get(name)`） |
| **提升3级** | **完整艺术字海报**——5-7 层信息层级（hero/hero_sub/label/lyric/meta/micro/seal），字号跨度 ≥6:1；大字**压在立绘后**（`behind=True` 三明治）才是海报；**歌词卡点字幕**按人声起音逐字显影；**关键字放大**（金句核心字 ×1.5 + accent 色）；字**避让立绘**（版式的 `dolls` 落位已声明人在哪，字排另一侧）；过 §8 的层级计数门（`check_thickness`） |

## 6. 卡点动效字典（Beat → Effect 映射 · 可复用）

时基来自 `load_beats()`：`beats`（全部拍）、`downbeats = beats[::2]`（重拍）、`drop`（副歌/高潮，onset-strength 峰值标注 + 人工核对）。

| 拍类型 | 触发 | 动效候选（按强度） | 参数锚 | 等级限制 |
|---|---|---|---|---|
| **弱拍** every beat | `pulse(t, beats, 0.14)` | 描边微脉冲 · 粒子闪烁 · 呼吸微缩放 | scale +2% | 全等级 |
| **重拍** downbeat | `pulse(t, downbeats, 0.22)` | zoom-punch · 闪白 · 手持抖 · 投影压弹 · 月盘微亮 | scale +5%, flash 0.15 | **仅 L3/L4/L6/L7** |
| **切镜点** shot 边界 | `lt < 0.16` | 闪白 / 光扫切 swipe / zoom-blur match-cut / 水墨晕开（B风格） | 0.16s 转场 | 落在 downbeat **且优先乐句结尾** |
| **drop / 副歌炸点** | 标注时间码 | 粒子中心爆发 · 速度线放射 · 描边全亮 · 大字弹入 · 双重曝光叠影 · 遮幅开合 | 全 FX 叠加 | L3+ · 遵守各级爆发次数上限 |
| **人声起音** onset | librosa onset | 歌词逐字显影 · 字锋写出 | 对齐 onset 时刻 | 全等级 |
| **人声重音/停顿** | onset 强峰 | **仅局部光影微调** | — | **禁剧烈镜头运动**（字幕可读） |
| **间奏 / 留白** | 低能量段 | 慢呼吸 · 落叶/花瓣飘 · 光轴缓移（F风格靠这个撑） | 一切放慢 | 全等级 |

**卡点铁律**：
1. 切镜点**必须**落在 `downbeats` 上（不能落在拍间），且大转场优先对齐**乐句结尾**；
2. 重动效**必须**压在拍点 ±1 帧内，否则"卡点"就散了；
3. **拒绝一拍一动**——L1/L2/L5 的持续动效横跨多拍匀速运行；密集鼓点段禁连续触发强特效（廉价感）；
4. **画面推进下限（治 PPT · 见 §2.5 / R9）**——**每 2s 观众必须看到"画面在往前走"**，手段任选：硬切换景别/机位、运镜（推/拉/摇/移让主体可见移动）、或转场翻篇。叙事段优先靠硬切（每 1.5–2s 一刀，单人段做到"一句一景别"：全景→半身→特写靠裁切换）。慢档（L5 院线 / L7 天花板 / 间奏留白）**可少切镜、改用慢运镜，但不放宽 2s 冻结硬线**——慢慢推、慢慢摇都行，但 2 秒内主体在画面里必须跨过 4% 位移线；"慢"是运镜放慢，不是主体冻结。

现有实现：`place_doll` 用 `dbp` 驱动缩放/抖动；`render_frame` 用 `bp/dbp` 驱动闪白/zoom-blur；转场用 `lt<0.16` + `shot.trans`。

## 7. 背景 × 光影 × 特效联动自适应规则（渲染前必查）

背景选定后，所有光效参数按背景性质**自动修正**（这一步决定"看得见"还是"糊一片"）：

| 背景判定 | 判据（可机器化） | 修正 |
|---|---|---|
| **亮色系背景** | 全帧亮度均值 > 60% | 所有光效、粒子透明度**统一 +20%**（亮色吞光效） |
| **深色暗调背景** | 亮度均值 < 30% | 所有光效透明度**统一 -15%**（防发白、丢层次） |
| **线条繁杂/元素密集**（花草、城市、C类立绘衍生） | 边缘密度高（Canny 边缘占比 > 阈值） | **删多层粒子流体，仅保留局部光影**；强卡点特效只放画面边缘 |
| **干净留白**（渐变、云雾、天空） | 边缘密度低 | 完整启用全套氛围动效 |

**语音厅 MV 专属约束（人声优先）**：
- 禁高饱和、高对比度背景（干扰居中字幕）；
- 所有强卡点特效放**画面上下边缘**，避开字幕区域；
- 人声重音/停顿处禁剧烈镜头运动（§6 铁律）。

**色板统一硬性要求**：单条视频只用**一套声明色板**（`pack.palette`），全片同属"一个世界"——判据是**同一套 main/aux/accent**，不是"同一个色温"。`urban-night` 这类冷暖同框的包，冷蓝反光 + 暖橙 accent 从头到尾都在，这不叫漂移；真正禁的是**中途换一套色板**（如前半 `luxe-interior` 暖木、后半 `starfield-epic` 靛蓝）。跨段落只允许同板内的亮度/饱和度缓变（如 L6-A 的 5% 偏移），禁跳到板外色相。

## 8. 艺术字 / 海报排版 / 歌词字幕系统（字是画面的一部分）

字分两个子系统：**8A 艺术字/海报排版**（单人·多人展示帧的厚度来源，宣传海报感）+ **8B 歌词字幕**（逐句随人声显影）。代码在 `pipeline/paperdoll/poster.py`。

### 8A · 艺术字 / 海报排版层（内容厚度的真正来源）

> **厚度不是特效堆出来的。** 渐变 + 外发光 + 投影 + 描边四件套只会显廉价，根因是「用效果补层级不够」——和 R9「构图动 > 特效动」同一条原理。**真正让画面变厚的是信息层级数**：2 层（标题 + 歌词）= 薄；5-7 层 = 海报感。

**七个标准层**（`TIER_ORDER`，不必全用，但少于 5 层过不了 §10 层级计数门）：

| 层 | 内容 | 视觉重量 |
|---|---|---|
| `hero` | 主字（角色名/歌名），画面最大的东西 | 最大 |
| `hero_sub` | 主字副行（拼音/英文/罗马音），贴着 hero 走 | 中大 |
| `label` | 身份标签（定位/CP/期数），中号 | 中 |
| `lyric` | 歌词/文案行 | 中 |
| `meta` | 元信息（日期/厂牌/专辑） | 小 |
| `micro` | 极小等宽层（编号/时间码/坐标）—— **最便宜的厚度来源** | 最小 |
| `seal` | 印章/徽标 | 点缀 |

**两条量化门**（`check_thickness()`，§10 第五道机器门）：
- **信息层级数 ≥5**（zen 极简版式豁免，rule 里写明理由）。
- **字号跨度 ≥6:1**（最大字 / 最小字）。小于这个数说明层级在打架不在分工——把主字加大或把 micro 层缩小。

**排版与立绘咬合（三明治合成，`render_poster`）**：`背景 → behind 层大字 → 立绘 → 前景层`。**大字被立绘挡住一截，才是海报；全部浮在人前面是字幕不是海报。** 立绘落位由**版式声明**（`PosterLayout.dolls` + `.place(n)`），不由调用方现猜——谁站哪、站多高是构图决定的，调用方每次猜等于每次重新设计版式。

**画面色 vs 文字色分离（硬约束）**：`palette` 的 `main/aux/accent/ink` 是**画面**角色（底色/次色/强调/暗部），`fg/fg_dim` 是**文字**角色。暗调包的 `main` 就是深色画布本身，拿它当文字色 = 把字画进背景里。Slot 的 `color` 默认 `fg`，可取 `fg_dim/accent` 或字面 hex。

### 8A.1 · 9 套版式库（`poster.LAYOUTS` · 单人 6 + 多人 3）

选版式看**人数**（`by_kind("single"/"duo"/"group")`）+ 想要的构图。每套 rule 写明「为什么这么排」。

**单人 6 套**：

| 版式 | 层/跨度 | 一句话 |
|---|---|---|
| `single-vertical-name` | 6 层 9.2:1 | 竖排大名贴右缘、人偏左——竖排是汉字独有版式资源，横排海报做不出这种纵向压迫感 |
| `single-stacked-hero` | 6 层 17.1:1 | 巨大横排名字压顶、人从字后穿出——被遮挡才是海报，全浮前面只是字幕 |
| `single-side-column` | 6 层 7.7:1 | 左窄栏塞满层级、右侧大留白给人——信息密度和呼吸量同时拉满，杂志封面常用 |
| `single-baseline-strip` | 6 层 7.1:1 | 信息全压底部条带、上方净空——电影主视觉排法，靠剪影和留白说话 |
| `single-poster-grid` | 7 层 13.5:1 | 四角挂元信息 + 中轴大字——网格感最强，平面设计味，厚度全来自层级 |
| `single-zen-void` | 3 层（豁免） | 极简三层 + 大量留白、人偏置黄金分割位——**唯一允许 <5 层**，只用于前奏/间奏/收尾静段 |

**多人 3 套**：

| 版式 | 层/跨度 | 一句话 |
|---|---|---|
| `duo-split` | 7 层 7.5:1 | 双人左右分立、中缝竖排 CP 名——各贴自己那侧名牌，谁是谁一眼分清（双人图最容易糊这个） |
| `group-grid` | 7 层 9.5:1 | 成员均分格 + 逐人编号名牌——男团一手物料标准排法，编号层几乎不占重量却立刻加一层厚度 |
| `group-stack` | 7 层 21.4:1 | 成员错落叠放 + 巨字压人后——纵深靠遮挡而非缩放，队名从人群穿出，performance 主视觉常见 |

`group-*` 按实际成员数重排横向分布（`place(n)` 循环取声明的高度/底边节奏），成员数每期不同也不用改版式。

### 8B · 歌词字幕（随人声逐句显影）

1. **安全区**：字幕核心区按画幅定（9:16 底部 1/4 或竖排右侧列；16:9 立绘对侧留白区或底部单行，见 §0.4），任何特效/暗角/遮幅不得侵入；字幕不遮立绘五官（五官区 ≈ alpha bbox 顶部 1/5）。16:9 遮幅开启时字幕落在遮幅内沿之上，不压遮幅条。
2. **时基**：每句入场锚**真实人声起音**（`lyrics_timed.json`）；逐字显影用逐字 onset；无人声段（间奏）不出词，出词牌/落款。
3. **样式跟风格包**（§5 的 `type_style`）：minimal 极简单行 / calligraphy_vertical 竖排书法+朱印 / gilded 描金+花钿 / big_type 超大字快切 / zen 一次一字。
4. **样式跟等级**（§3）：L1/L2 字幕克制（描边+淡入即可）；L3+ 才允许流光/弹跳/放大；L7 高光仅调光影**禁止放大**。
5. **可读性硬指标**：手机端（540×960 复检，§10）逐句清晰可读；描边 ≥2px；文字色用 `fg/fg_dim`（与背景有足够反差，见 8A），对比不足时自动加半透衬底。
6. **禁**：字幕条式白底黑字大条（廉价）；歌词错位/超前人声 >200ms。

## 9. 全流程 SOP（7 阶段 · 5 个拍板点 · 阶段 ④ 全自动多级并行）

> **2026-07-26 立 · 本节为强制流程，此类视频一律按此执行。**
> 立法依据是一次真实事故：《明月天涯》样段全程两道门（R9 运镜门、R6 声明式色板门）**都是绿的**，
> 却连续出现「纸和木桌都挤在明度最高的 20%，一张纸读不出轮廓」「歌词是抖动的字幕不是笔迹」
> 「整段没有一处高光」三类缺陷——**门看不见的东西，只能靠人翻接触表一个一个撞见，撞一个修一个**。
> 更糟的是改动之间有耦合（`tint()` 把声明色当**中位明度**用，底色一换，明度事件曲线的基准跟着挪），
> 第 1 个修复直接生出了第 4、5、8 个修复。
> 根因两条：**①判据是文字不是数 ②验收器建在渲染之后**。§9.2–§9.4 就是为了根治这两条。

### 9.0 七阶段总览

> **顶层套路（2026-07-27 立）**：把**所有人类决策前置成结构化对话/选择**，压缩成一份**需求契约**（§9.0.1 `brief.json`），此后自主阶段直接消费契约、中途不回头问。三段式：**前置对话（−1）→ 拿到完整需求 → 后台自主跑完（④）**。这跟 §0.1「三输入契约」是同一思路，只是抬到需求层——原本被默认跳过的「物料在哪 / 给了啥 / 做几条 / 什么约束」，现在是流程第一格，不是靠假设。

| 阶段 | 做什么 | 谁 | 产物 |
|---|---|---|---|

| — | **👤 拍板点 0：确认需求契约**（画幅/题材/条数/tier 一次拍完） | 用户 | — |

**与项目 CLAUDE.md 5 拍板点的对应**（不冲突、不新增）：本 skill 在项目拍板点 2（选题定稿）**之后**介入。本节拍板点 0（需求契约）+ 拍板点 1（创意多选）合起来 = 项目拍板点 3（脚本+看图选视觉创意）· 拍板点 2（分镜）+ 拍板点 3（小样进退）= 项目拍板点 4（抽验）的 skill 内细化 · 阶段 ⑤ = 项目拍板点 5（外发）。选题方向与选题定稿（项目拍板点 1/2）在本 skill 介入之前完成。

**阶段 ③ 为什么是「两拍」而不是「一张关键图」**：静帧拼图（3a）是**创意与规格的对账单**——创意在文字层、概念图层成立，不等于在「定下来的色板 + 定下来的景别 + 真实立绘」下成立。《明月天涯》B 版「纸和桌子分不开」这类**静态病**，一张拼图秒级就能看出，却曾拖到全片渲完才发现，所以 3a 不能省。但静帧看不出**运动/卡点/整体气质**对不对，这正是用户「想快速找感觉、决定要不要进完整工程」的诉求——所以 3b 用 draft 模式（可带 bug、跳门禁）几分钟出前 5 镜动态粗剪。**3a 不过禁 3b；3b 用户说「退」禁起阶段 ④。** draft 模式实现见 §12.2 待实现第 11 项。

### 9.0.1 · 阶段 −1 需求对话规范（对话/选择填契约 · 模型无关）

**核心机关：对话不是随便聊，是逐格填一张契约。** 契约填满 = 拿到完整需求，自主阶段直接读它跑。契约 schema（落地 `projects/{id}/brief.json`）：

```json
{
  "materials": {
    "dolls":   [{"path": "...", "char_name": "萧逸"}],
    "audio":   {"path": "...", "format": "mp3|wav"},
    "lyrics":  {"path": "...", "has_timing": true, "format": "lrc|txt"},
    "custom_bg": null
  },
  "constraints": {
    "canvas": "9:16",                       // 未指定默认 9:16（§0.3）
    "genre":  "现代国乙|古风国乙|男团|通用",  // 从立绘/歌词猜 → 让用户确认
    "production_tier": "探索|全量|代表作",
    "vo_mode": "密VO无BGM|有BGM",
    "platforms": ["抖音", "小红书"],
    "hard_exclusions": []                    // 硬禁忌（禁蓝紫已是铁律，此处放片专属）
  },
  "scope": {
    "video_count": 1,
    "multi_mode": "single|style_ab",         // 默认 style_ab（同素材多风格，见下）
    "per_video": [{"style_pack": null, "creative_ids": []}]
  },
  "creative":  {"selected_ids": [], "main_emotion": null, "references": []},
  "doll_segment_map": []                      // 多角色时阶段 0 补全（§9.0.2）
}
```

**对话四规则（模型无关；Claude Code 用 AskUserQuestion，其他模型映射各自选择 UI）**：

1. **先开放后收敛**：开场给一句自由话（「把你手上有啥、想做成啥样直接说」），让用户一股脑说物料 + 意图，不一上来就逐条盘问。
2. **只问缺格**：LLM 解析开场话，识别已填项，**只对没填的格子发定向选择题**。已能推断的不问。
3. **能默认就默认**：`canvas` 未说 = 9:16；`genre` 从立绘画风 + 歌词语义猜一个、让用户一键确认（不是从零问）；`production_tier` 缺省探索。默认值都写进契约草稿摆给用户，用户改哪格点哪格。
4. **多角色补映射**：`materials.dolls` 超过 1 个 → 必须补问 `doll_segment_map`（谁唱哪段 / 轮流 / 副歌合体），否则阶段 0 只能落默认策略（§9.0.2）。

**「制作几个」= 同素材多风格 A/B（默认语义）**：`multi_mode: "style_ab"` 时，同一套立绘 + 同一首音频，`per_video[i]` 各配一套独立 `style_pack` + 一组 `creative_ids`——这正是 §5 尾「14 套天然是 14 种视觉语汇、零新增素材的完全不同形式」。阶段 ① 创意多选时，用户可为每个 video slot 各选一套创意+风格，或让 LLM 按最大差异化自动派（如 `urban-night` 夜景版 vs `luxe-interior` 室内版 vs `modern-magazine` 杂志版）。`video_count` 缺省 = 用户在阶段 ① 勾中的创意数。多曲/多角色各做一条（`multi_mode: "single"` 逐条）时，阶段 0 先按 video 拆物料再各自跑本流程。

### 9.0.2 · 阶段 0 物料预处理（自动 · 段落表与映射 10 秒人工核对）

契约拍板后自动跑，产出自主阶段要吃的全部中间产物：

| 子步 | 工具 | 产物 | 无码/多角色兜底 |
|---|---|---|---|
| 抠图 | `rembg_cutout.py` | `doll.png`（透明底，此后像素零改动 R1） | — |
| 节拍 | `load_beats` | `beats.json`（BPM/beats/downbeats/onsets） | 真实音频，禁凭感觉硬凑（R5） |
| 歌词对齐 | LRC 直用 / 纯文本 librosa onset + whisper | `lyrics_timed.json`（每句锚人声起音） | 每句入场锚真实人声起音（§0.1） |
| 段落表 | RMS/onset 能量曲线 | 前奏/主歌/副歌/间奏/桥段/尾奏 + 每段能量档 | 不确定处人工核对一次（§3.1） |
| **立绘↔段落映射** | 读契约 `doll_segment_map` | `doll_segment_map` 定稿 | 见下 |

**「每个立绘对应歌词的时间」拆成两个独立问题**（用户步骤 3 的诉求里其实混了两件事）：

- **(a) 歌词↔时间**：LRC 直接用，纯文本走 onset + whisper —— **可全自动**，上表已覆盖。
- **(b) 立绘↔歌词段（哪个角色在哪句出现）**：**音频本身推不出来**。
  - 单角色：`doll_segment_map = [{"char": "<唯一角色>", "segments": "all"}]`，不用问。
  - 多角色：从契约 `doll_segment_map` 读；用户未指定时默认 **「按 verse 轮流 + 副歌合体」**，落草稿后向用户确认一次（10 秒的事）。这一步定的是「哪个立绘唱哪段」，是多角色分镜（§9.1 ⑨）的输入前提，缺了它多角色片没法排镜。

### 9.1 阶段 ② 分镜的逐步细则（承接原 SOP）


### 9.2 阶段 ④ 的执行单位是「原子能力」，不是「帧」

**原子 = 一个可独立渲染、可独立度量的能力单元。** 一次仰拍推轨、一道扫描光条、一次折纸、一句歌词落笔，各是一个原子。

**铁律：原子产出即自检，检不过的原子不进装配。**

这一条替代了「渲完整片再翻接触表」。差别不是快慢，是**发现缺陷的时刻**：光条梯度不够，在写光条的那一分钟就红，不用等 5 分钟渲完整片。

**纪律三条（违反即判本流程未跑）**：

1. **判据先于原子写。** 每个原子在动手实现之前，先写好它的探针和那个数。写不出判据的原子 = 需求没想清楚，不许开工。依据 memory `feedback_build-to-reference-not-floor`（多维验收器在首次渲染前写完）。
2. **判据是数不是话。** 「亮基底下的高对比」不是判据，「光条边缘梯度 ≥0.9 L/px」才是。文字规格无法在渲染前检查，这是《明月天涯》连续返工的直接原因。
3. **探针在中性底上跑。** 原子单独渲在纯中灰底（+ 一张标准立绘）上，不带风格包、不带其他原子——**探针要测的是这个能力本身成不成立**，混进底色就测不出是谁的问题。

#### 原子 → 探针 → 判据（本 skill 的标准表 · 新增原子必须补一行）

| 类 | 原子 | 探针怎么渲 | 判据（数） |
|---|---|---|---|
| **运镜** | 推 / 拉 | 中性底 + 标准立绘，单渲该运镜全程 | 主体面积变化**峰值** ≥8%（R9 口径） |
| | 摇 / 移 / 甩 | 同上 | 主体中心位移**峰值** ≥ 画面宽 4% |
| | 仰拍 / 俯视 | 同上，渲 elev 起止两帧 | 主体轮廓四角位移 ≥ 画面高 2%（否则 pitch 没生效，只是缩放） |
| | 环绕 / 旋转 | 同上 | roll 峰值 ≥ 声明值的 90%，且中途不回零 |
| | 跟拍 | 同上 | 主体 bbox 中心在画面内漂移 <3%，而**背景**位移 ≥8%（跟拍的定义就是主体钉住、世界在走） |
| **特效** | 扫光 / 光条 | 纯中灰底单渲 | 边缘亮度梯度 ≥0.9 L/px；软过渡 >120px 判 fail |
| | 描边光 | 立绘 + 透明底 | on/off mean abs diff ≥ 开关对比门阈；轮廓亮度 ≥ 邻域 +8% |
| | 投影 | 同上 | 影子 bbox 与主体 bbox 偏移 ≥8px（L5 口径） |
| | 折痕 | 纸面单渲 | 亮线与暗线**相邻 ≤5px 且中间无过渡带**（判据只有上界：贴得更紧不是缺陷，缺陷是糊出过渡带；设下界会把画对了的折痕判掉）|
| | 叠层厚度 | 侧视单渲 n=2/4/8/16 | 层缝条数 = 2ⁿ⁻¹ 且相邻层缝间距随 n 单调递减（读得出是「一沓」不是「两个条纹方块」） |
| | 卡点呼吸 | 单渲 8 拍 | 参数时间序列 std > 0（动态基准门）；峰值帧 vs 拍点帧偏差 ≤1 帧 |
| | 胶片颗粒 / banding | 中灰底单渲 | 400% 放大颗粒**不重复**（自相关峰值 <0.6）；规则栅格判 fail |
| **排版** | 歌词落笔 | 黑底单渲一句 | 0.15s 窗口内：位移 ≥0.26 字高 **且** 旋转收 ≥7° **且** alpha 0→1，**三项同窗**（只做位移 = 字幕淡入，只做旋转 = 贴纸） |
| | 行笔势 | 同上，量整行 | 行尾比行首高 ≥0.10 字高；中段拱起 ≥0.04 字高（否则是随机抖动不是笔迹） |
| | 艺术字层级 | 单渲主视觉帧 | 层级 ≥7、字号跨度 ≥10:1（`probes.check_typography_tiers()`；比 `poster.check_thickness()` 的 5 层 / 6:1 严——那是全项目地板，本 skill 按 §9.4 抬了 3 档） |
| | 描边 | 任一字号 | 描边宽 = `round(size*0.038)`，**禁写死 px**（按小字号调的宽度，放大后轮廓相对变细，字在乱底子上糊边） |

### 9.3 三级并行 + 三级检查（阶段 ④ 的完整结构）

**原子级检查是必要但不充分的。** 每个原子单独都合格，乘起来仍可能不合格——《明月天涯》A 版「整段没有一处高光」就是这样：光条梯度没问题、运镜位移没问题，坏在**原子与底色的乘法关系**上。所以必须是三级。

| 级 | 并行什么 | 并行方式 | 产出即检的判据 | 这一级抓什么病 |
|---|---|---|---|---|
| **L-原子** | N 个原子同时造 + 同时自检（原子之间无依赖） | agent 并行 / 进程并行 | §9.2 表 | 这个能力本身不成立 |
| **L-镜** | 镜与镜互不依赖，可并行装配 + 自检 | 进程并行 | §9.3 表（下） | **原子各自合格、乘起来不合格** |
| **L-帧** | 装配定稿后铺全片帧 | `multiprocessing` **spawn** 池 | 无（此级只是铺量） | — |

> **L-帧 必须用 `spawn` 不能用 `fork`**：macOS 的 Accelerate（numpy 底层 BLAS）在 fork 出的子进程里调用会挂，而卡点 MV 每帧都在跑 numpy。代价是每个 worker 各建一份纹理缓存，分摊到几十帧上可忽略。
> **worker 数按内存定不按核数定**：单渲染进程实测约 1.3 GB（3840×1836 的 float RGB 单张就是 169 MB）。8 GB 机器开 4 个，开满 8 核会换页，比串行还慢。
> **`imap_unordered` 的返回顺序不是帧序**，`motion.json` 的 track 是逐帧时间序列，收齐后必须按 i 排序，否则 `gate_check_motion` 会把乱序相邻帧当成跳变。

#### L-镜 装配判据（每镜装配完立刻量 · 这一级是《明月天涯》缺的那一级）

| 判据 | 数 | 抓的病 |
|---|---|---|
| **明度结构** | 单镜 `p95 ≥ 150` **且** `p95 - p5 ≥ 90` | 铁律「禁全片高亮无暗 / 全片压暗无亮」的**两半**。p95 低 = 这镜没有一处高光；跨度小 = 一片糊色，主体读不出轮廓 |
| **主体可读** | 主体 bbox 占幅 ≥ 该景别声明 share 的 70% | 相机按 subject 包围盒解算时，主体一分开包围盒就涨、相机就退，最大的一次位移反而发生在一片黑里 |
| **冻结** | 位移峰值 ≥4% 画宽 **或** 面积峰值 ≥8%（R9） | PPT 感 |
| **色板** | ΔE18 跑偏 <5%（R6 声明式） | 色板漂移 |
| **遮挡** | 特效 bbox 不压五官区与字幕安全区 | — |

> **明度判据为什么必须在镜级、且必须是数**：`tint(im, color, contrast)` 是把声明色当作这块面的**中位明度**用的。所以改一个 bg 的颜色不是「换个色」，是**给整镜的明度结构重定基准**——B 版把桌面从 `#D9C7A8`（L≈200）压到 `#A08A6B`（L≈143），纸才成为画面里唯一的亮部；A 版底色翻成暗箱之后，按奶白底调的明度事件曲线还在往下乘，两层叠乘直接把四个镜压成没有高光。**这类耦合肉眼在单帧上看不出来，一量就出来。**

#### 阶段 ④ 的返工闭环（不冒到用户面前）

| fail 级别 | 修什么 | 上限 |
|---|---|---|
| L-原子 fail | 修**这个原子**，不动片子 | 3 轮，3 轮不过换实现路线并登记 |
| L-镜 fail | 只重装配**这一镜**（禁全片重渲当常态） | 3 轮 |
| L-片 fail（§10 五道门 / R6 / R9） | 按 §10.2 诊断库定位 → 只改 1-2 变量 | 3 轮 |

三级都在自动任务内部跑完，用户在阶段 ⑤ 只看成片。

### 9.4 判据是地板不是目标（元规范 · 贯穿三级）

§9.2/§9.3 全部的数都是**最低及格线**。每到「我觉得这个能过」的时刻，那个「能过」的感觉本身就是标准定低了的信号——强制自问：**能不能把验收目标往上提 3 个档次？** 动手前把抬高后的标准写成真正的目标，第一次就照它建。

**特别地：门全绿不等于成片可用。** 《明月天涯》两道门全程绿，三类肉眼可见的缺陷一个没拦住。**放行理由是「它过了 gate」时，停**——过的是目标还是代理指标？依据项目铁律 8 + memory `feedback_gate-floor-not-target`。

**禁用改验收器输入的方式过门**：给非主体挂 bbox、把主体清空、改 motion track 的记录方式，都比 fail 更糟（假 pass 会静音信号）。判据只接受「画面真的变了」。依据 memory `feedback_no-gaming-the-verifier`。

## 10. 防「无感/廉价/糊」强制校验（成片必检 · 机器 fail-closed）

原七级手册为肉眼工序，本项目升级为可机器执行的硬门：

### 10.1 五道机器门

| 门 | 检法 | fail 判据 | 修复公式 |
|---|---|---|---|
| **开关对比门**（防无感） | 抽 ≥5 帧（必含 1 重拍帧），逐效果 render FX-on/off 两版，算 mean abs diff | diff 过小 = 肉眼无差异 | 该效果**透明度 +20% / 运动幅度 +30%** 后重渲复检 |
| **小屏门**（双端预览） | 1080 帧 downscale 至 540×960 重跑开关对比 + 字幕可读检查 | 大屏可见小屏失效 | 参数 +20% |
| **动态基准门** | 每个动效参数的时间序列 std | std=0（全程恒定） | 违规，必须有基准态+激活态 |
| **卡点精度门** | 重动效峰值帧 vs 拍点帧 | 偏差 >1 帧 | 修时间映射，不是调参数 |
| **层级计数门**（防薄 · 艺术字） | `poster.check_thickness(layout, content)`：数有内容的排版位数、算字号跨度 | 层级 <5 或 跨度 <6:1（`zen-void` 豁免） | **加信息层级，不是加特效**——补 label/meta/micro/seal 层；跨度不足则主字加大或 micro 缩小。见 §8A |

另：palette gate（R6）声明式抽帧必过；遮挡检测——特效峰值帧的特效 bbox 不得压立绘五官区与字幕安全区。

### 10.2 故障诊断库（fail 后按序排查）

| 故障 | 排查顺序 | 修复 |
|---|---|---|
| **1 · 特效加了肉眼看不见** | 图层错位距离（L5 需 ≥8px）→ 透明度 → 是否全屏叠加互相抵消 → 动画时长 | 透明度 +20% / 运动幅度 +30%；各级"无感修正"行的锁定底线不可下调（如 L5 轮廓光 8%、L6 前景 ≥5%、L7 追光 4px） |
| **2 · 画面廉价、网红感重** | 是否频繁闪光 → 多层粒子叠加 → 一拍一动 | 删频闪；增加镜头时长；**节拍卡点改乐句卡点** |
| **3 · 画面脏乱发灰、层次消失** | 多层柔光/雾效叠加 → 光效铺满全屏 → 背景与特效线条重叠 | 只保留【1 层氛围 + 1 层光影】，删重复滤镜 |
| **4 · 高级感缺失、画面扁平** | **核心根源：缺「空间速度差、明暗差、虚实差」**——不是特效数量不够，是缺强弱对比 | 上 L5 双层景深（错位 ≥8px）/ L6 三层速度差（1.0/1.0/1.8）；给画面留静区，让动的地方"值钱" |
| **5 · 特效满但整体仍像 PPT（动效在动、画面不动）** | **冻结自检（2s 硬线，唯一 pass 判据）· 机器门 `pipeline/gate_check_motion.py`**：渲染器随片吐 `*.motion.json`（逐帧立绘 bbox + shot），滑窗扫全片，任取一个 2s 窗口，比对窗口内**主体**（立绘 alpha bbox）相对首帧的**峰值**——中心位移 **< 画面宽 4%** 且面积变化 **< 8%** 即判"冻结" = fail（用峰值不用首末帧差，orbit 一类荡回起点的正弦运镜不误伤）。窗口内有切镜 = 翻篇直接过。切镜、运镜、转场**任一手段**只要让主体在 2s 内跨过阈值都算过，不强制必须是硬切。**辅助诊断（不单独判 fail，用来定位病因）**：全片硬切数 ÷ 时长（偏低提示可能在靠特效撑）；主体缺席窗口（纯字卡/转场）。 | **让画面每 2s"往前走"一次**：叙事段优先硬切换景别/机位；慢档不切镜就上运镜（推/拉/摇/移，主体可见移动/缩放）或转场翻篇。核心不是"切一刀"，是**别让观众觉得人/画面不动**。详见 §2.5 / R9 |

## 13. 人物运动感表现库（持续增补 · 非 i2v · R1 零改立绘像素）

> **核心逻辑**：不改立绘像素（R1），改「人物被展示的容器」——容器动 = 人物在动。
> 与 i2v 路线（真实动态视频）互补：本节全部是确定性 PIL/numpy 实现，帧内可控、可复用、不崩脸。
> **以后随脑暴持续追加** ——新思路直接在此节末尾增条，不另起文件。

### 13.0 · 两轴分类（先选轴，再选具体技法）

| 轴 | 说明 | 代表技法 |
|---|---|---|
| **A 轴：角色本体微动** | 程序化骨骼式微动效，立绘整体或局部做轻微运动 | 呼吸浮动、重心漂移、发丝摆动 |
| **B 轴：展示容器运动** | 把立绘「放进某种容器」，容器本身动，视觉上角色在动 | 胶片走带、漫画分格、拍立得飞落、镜中镜 |
| **C 轴：画面物理效果** | 对立绘做可逆的视觉变形/分裂/聚合，制造动作感 | 碎片聚合、残影叠影、水中倒影、波纹扩散 |

**使用顺序铁律**：A 轴（底层始终开） → B 轴（主要展示形式）→ C 轴（大拍点瞬时爆发）。  
不能只上 C 轴、不做 A+B——没有底层微动的角色即使被碎片化也仍然"死的"。

---

### 13.1 · A 轴：程序化微动效（breath_sway）

**观众看到**：角色"活着"，像在呼吸、站姿自然有重心感。  
**实现**：全帧对立绘施加周期性仿射变换，像素不变。

| 参数 | 公式 | 量化 |
|---|---|---|
| **呼吸浮动**（y 轴上下） | `dy = A_breath * sin(2π * t / T_breath)` | A=3–6px · T=3–5s |
| **重心漂移**（x 轴微晃） | `dx = A_drift * sin(2π * t / T_drift + φ)` | A=2–4px · T=4–7s · φ随机 |
| **微角度摆动** | `angle = A_angle * sin(2π * t / T_angle)` | A=0.4–0.8° · T=5–8s |
| **卡点呼吸冲击**（叠加在底层呼吸上） | `scale += dbp * 0.03 * ease_out(lt/0.3)` | 重拍冲击衰减 0.3s |

**扩展**：若有多分区 mask（发区/衣区/手区），各区独立 T 和 φ，制造衣摆/发丝不同步的自然感。  
**代码接口**：`breath_sway(layer, t, beats, seed=0) -> (dx, dy, angle, scale)`

### 13.2 · B1 轴：胶片走带（film_strip）

**观众看到**：多格胶片横向滚动，每格里有角色，格子走动 = 角色像在翻页/走过来。  
**天然附赠**：复古电影质感，配暖调托斯卡纳背景尤其契合。

**实现结构**：
```
胶片条 = N 格并排（N=3~5）
每格 = 黑边 + 顶底齿孔 + 立绘（居中裁入格内，可不同景别或不同人）
strip_x = -( t * scroll_speed ) % (cell_w * N)   # 横向循环滚动
strip 整体轻微倾斜 3–5° + 微量 z 轴透视变形
```

**量化参数**：

| 参数 | 值 |
|---|---|
| 格宽 × 格高 | 240×320px（16:9 画布内）|
| 黑边宽 | 12px |
| 齿孔 | 每格顶底各 3 个，10×6px 白矩形，间距均匀 |
| scroll_speed | 80–120 px/s（可绑 BPM：每拍走一格 = `cell_w * BPM/60`）|
| 倾斜 | 4°（视差感更强） |
| 格内立绘 | 同一角色不同景别，或不同角色轮流 |

**拍点联动**：重拍瞬间 scroll_speed ×1.8，持续 0.2s 后缓降（胶片"顿了一下"的冲击感）。  
**代码接口**：`film_strip(canvas, dolls, t, beats, cell_w, scroll_speed, tilt_deg) -> canvas`

### 13.3 · C1 轴：残影叠影（motion_echo）

**观众看到**：角色"刚刚高速冲过来"——身后拖着 2–3 个渐隐的残影。  
**最佳时机**：大拍点切入瞬间（0–0.4s），之后残影快速消散。

**实现**：把当前帧立绘复制 N 份，向"来的方向"依次偏移 + 透明度递减。

```python
offsets = [(-30, 0), (-60, 0), (-90, 0)]   # 向左来=向右偏移
alphas  = [0.50,    0.25,    0.10]
for (ox, oy), al in zip(offsets, alphas):
    echo = doll.copy()
    echo.putalpha(ImageChops.multiply(echo.getchannel("A"),
                  Image.new("L", echo.size, int(255*al))))
    canvas.alpha_composite(echo, dest=(cx+ox, cy+oy))
canvas.alpha_composite(doll, dest=(cx, cy))  # 主体最后压顶
```

**方向参数**：可按镜头运动方向自动决定（push_in 残影向下，whip_right 残影向左）。  
**代码接口**：`motion_echo(canvas, doll, cx, cy, direction, n=3, decay=0.5, t_fade=0.4, lt=0.0)`

### 13.4 · B2 轴：漫画分格（manga_panels）

**观众看到**：屏幕分成 3–4 个倾斜漫画格，同一角色不同景别各占一格，格子飞入/弹出。  
**效果**：感觉角色"换了好几个姿势"——实际只用一张立绘的 3 种裁切。

**布局方案**（16:9 画布 1920×1080）：

```
3 格竖分（主用）：
  格1: 全景  x=0,     w=640, 倾斜 -3°
  格2: 半身  x=620,   w=680, 倾斜  0°（主格，最宽）
  格3: 特写  x=1280,  w=640, 倾斜 +3°
格间黑色分割线 6px
```

**入场动效**：格子从各自"飞入方向"滑入（左格←左，右格←右，中格←下），错位 0.08s 间隔。  
**存在期间**：每格内的立绘保持 §13.1 呼吸微动（各格 φ 不同，互不同步）。  
**退场**：重拍时全格同时向各自方向飞出，canvas 回到单人全屏。  
**代码接口**：`manga_panels(canvas, doll, t, lt, n_panels=3, enter_dir="fan_out")`

### 13.5 · B3 轴：拍立得飞落（polaroid_scatter）

**观众看到**：3–5 张拍立得照片从画外飞入，随机角度叠落在屏幕上，复古私拍感。  
**适用场景**：2人对唱段、回忆段、间奏留白段；暖调背景（托斯卡纳）天然契合。

**单张结构**：
```
白色边框 + 底边留白（下边 = 上边 2×，写名字/日期）
内容区 = 立绘裁切（景别按张轮替：全景/半身/特写/局部）
阴影 = 轻柔投影，偏移随机
角度 = rng.uniform(-15°, +15°)
```

**入场序列**（错位 `i * 0.12s` 间隔）：从画外随机方向飞入，`back_out` 缓动落定。  
**叠放顺序**：先落的在下，后落的盖上（`z-index = i`）。  
**拍点扰动**：重拍瞬间最顶层照片做微跳（dy=-8px，0.1s 弹回）。  
**代码接口**：`polaroid_scatter(canvas, dolls, t_start, lt, seed=0)`

### 13.6 · C2 轴：水中倒影（ripple_reflection）

**观众看到**：角色脚下出现波纹倒影，节拍打到时波纹从中心向外扩散。  
**适用场景**：间奏/留白段低强度展示；配合 L2 呼吸动效；尾段余韵。

**实现**：
```python
# 倒影区：立绘 alpha_composite 到下半屏，翻转
reflection = doll.transpose(Image.FLIP_TOP_BOTTOM)
# 波纹扭曲：对倒影区做逐行 x 偏移（sine wave）
amplitude = 6 + dbp * 8   # 重拍时波纹增强
frequency = 0.04
for y in range(reflection.height):
    phase = t * 3 + y * frequency
    dx = int(amplitude * math.sin(phase))
    # row shift...
# 倒影透明度 = 0.5，随 y 线性衰减（越远越淡）
```

**参数锚**：amplitude 静态 6px / 重拍瞬间 14px，衰减 0.4s；倒影区高度 = 立绘高 × 0.6。  
**代码接口**：`ripple_reflection(canvas, doll, cx, cy, t, dbp)`

### 13.7 · B4 轴：镜中镜（mirror_delay）

**观众看到**：左半屏正常角色，右半屏略小的镜像版，比左边慢 0.3s 跟随所有动作——像影子/灵魂出窍/暧昧分身。  
**适用场景**：虐向/神秘段落；L3-C 虐向高光；间奏段。

**实现**：维护立绘状态的 `deque`（队列长度 = `int(delay * FPS)`），每帧从队尾取延迟帧合成。

```python
history.appendleft((cx, cy, scale, angle))
if len(history) > delay_frames:
    cx_d, cy_d, sc_d, ang_d = history[-1]
mirror_doll = doll.transpose(Image.FLIP_LEFT_RIGHT).resize(...)
```

**镜像参数**：scale × 0.72；opacity 0.45；x 位置 = 画面右 3/4。  
**代码接口**：`mirror_delay(history_deque, canvas, doll, cx, cy, scale, angle, delay_s=0.3, mirror_opacity=0.45)`

### 13.8 · C3 轴：碎片聚合（shatter_reveal）

**观众看到**：角色入场时，先是碎成若干方块从四面散开，然后在拍点骤然聚合"组装"成完整人物。  
**最佳时机**：每个角色首次亮相（第一个 solo 镜头）；副歌炸点。

**实现**：
```python
N = 5  # N×N = 25 块
tile_w = doll.width // N
for i, j in product(range(N), range(N)):
    tile = doll.crop((i*tile_w, j*tile_w, (i+1)*tile_w, (j+1)*tile_w))
    # 入场：每块从随机位置飞向归位，ease_out 缓动
    prog = clamp((lt - i*0.02 - j*0.01) / 0.4)  # 错位到达
    tx = lerp(rand_x, target_x, ease_out(prog))
    ty = lerp(rand_y, target_y, ease_out(prog))
    canvas.alpha_composite(tile, dest=(int(tx), int(ty)))
```

**进场时长**：0.4–0.6s（不超过半拍）；到位后立即切换为普通立绘合成。  
**退场变体**：尾段可做"碎裂散开"反向（出场时炸开）。  
**代码接口**：`shatter_reveal(canvas, doll, cx, cy, lt, n=5, duration=0.5, mode="assemble")`
