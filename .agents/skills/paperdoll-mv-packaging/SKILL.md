# 国乙风格短视频 · 标准操作手册（纸片人卡点 MV / 角色 PV / 语音厅 MV）

> **定位**：用户只给三样东西——**立绘、音频（mp3/wav）、歌词**。
> 从这三样到一条可外发的卡点 MV，中间的一切（背景、分级、分镜、光效、胶片、字幕、卡点、质检）**全部按本手册产出**。
> 立绘像素**零改动**（只做仿射变换 + 裁切换景别 + alpha 边缘处理），其余一切全部可设计。
>
> **本手册 = 「怎么包装」的方法论 + 强度分级 + 风格库 + 代码接口，跨选题复用**（skill，不是一次性分镜模板）。
> 与 `video-form-music-video`（i2v/t2v prompt 层）**互补**：那条给"让模型生成一段视频"写 prompt；
> 本条给"用确定性 Python motion-graphics 把不动的立绘卡点动起来"定规范。
>
> 参考实现：`pipeline/voice_room/gen_paperdoll_pv.py`（《明月天涯》纸片人卡点 PV）。
> 源头文档：`docs/语音厅 : CG : 国乙短视频 七级视觉包装标准化执行手册.md`（V2.0，本手册已全量吸收并按项目铁律暖化改写，以本文为准）。

## 0. 输入契约（用户只给三样 · 其余全自动产出）

### 0.1 三输入 → 中间产物

| 输入 | 预处理 | 产物 | 硬要求 |
|---|---|---|---|
| **立绘**（PNG/JPG，一张或几张） | rembg 抠透明 → alpha 硬化去 matte → 边缘羽化（`full_doll`/`prep_layer`/`_feather_edges`） | `doll.png`（透明底，**此后像素零改动**） | 长边 ≥1080；脸部清晰无裁切 |
| **音频**（mp3/wav） | librosa 节拍分析（`load_beats`）+ 能量曲线（RMS/onset strength）+ 结构分段 | `beats.json`（BPM / beats / downbeats / onsets）+ 段落表（前奏/主歌/副歌/间奏/桥段/尾奏 + 每段能量档） | **真实音频**，禁合成假 BGM、禁凭感觉硬凑时间码 |
| **歌词**（文本，可无时间码） | 有 LRC → 直接用；纯文本 → librosa onset 定位人声起音 + 逐句对齐（必要时 whisper 时间戳辅助） | `lyrics_timed.json`（每句 起始/结束 + 逐字 onset 可选） | 每句字幕的入场必须锚在真实人声起音上 |

### 0.2 背景素材从哪来（用户不提供背景）

背景三大基础类型（沿用七级手册 A/B/C 分类），每类都有零外部素材的产出路：

| 类型 | 定义 | 本项目产出路（按优先级） |
|---|---|---|
| **A类·具象远景** | 星空、山川、海面、建筑；轮廓清晰、自带景深 | ① 程序化生成：月盘 `make_moon` + 水墨山脊 `make_ridges` + 云霭 `clouds`；② GPT-image 生成**暖调**远景（走 §1 R2 暖板，prompt 内显式禁蓝紫） |
| **B类·抽象氛围** | 渐变、星云、雾面肌理、流体色块；无实体、留白足 | 程序化：暖色竖向渐变 `make_bg` + 径向光晕 + 光轴 + 粒子场 `Field`（最容易、默认起手） |
| **C类·人物衍生** | 画面内置角色、元素密集、留白少 | **立绘自身的模糊副本**做衍生背景（高斯模糊 + 暖色渐变叠加，即"原图模糊副本"层）——一张立绘既当主体又当背景 |

**背景基础规范**：分辨率 ≥1080P、**与目标画幅同比例**（9:16 或 16:9，禁拉伸凑比例）、无水印；单条视频**背景色系统一**（频繁冷暖切换 = 成片割裂无高级感，直接违规）。

### 0.3 输出规格（双画幅支持）

| 画幅 | 分辨率 | 适用平台/场景 | 何时选 |
|---|---|---|---|
| **9:16 竖屏** | 1080×1920 | 抖音 / 小红书 / 视频号（项目统一画布，`pipeline/screen_dims.py`） | **默认**——未指定画幅一律 9:16 |
| **16:9 横屏** | 1920×1080 | B站 / YouTube / 国乙官方 PV 惯用横幅（《明月天涯》PV 即 16:9） | 用户点名，或投放目标为横屏平台 |

- **开工第一步确认画幅**（SOP ①），此后所有背景生成、分镜构图、字幕排版都按该画幅定，中途不换。
- **双画幅出两版时**：构图参数分开设计（立绘落位/景别裁切/字幕位置各画幅独立），**禁止**一版居中裁切或拉伸成另一版。
- 命名外发：有 BGM `*_with_bgm.mp4`；密 VO 无 BGM `*_no_bgm.mp4`；双画幅加后缀 `*_9x16.mp4` / `*_16x9.mp4`。
- 帧率：标准档 30fps；L7 天花板档 60fps（补帧）。

### 0.4 画幅构图适配规则（同一套包装 · 两种排法）

| 维度 | 9:16 竖屏 | 16:9 横屏 |
|---|---|---|
| **立绘落位** | 居中或中偏下，全身/半身为主（竖构图天然适配立绘长边） | **黄金分割偏置一侧**，另一侧留负空间给字幕/词牌/光效；特写与半身更吃香 |
| **景别裁切** | 全景→半身→特写靠纵向裁切 | 横向裁切；全身镜立绘占画面高 80-90%，两侧留呼吸位 |
| **字幕主位** | 底部安全区（下 1/4）或竖排右侧列 | 立绘对侧的留白区（左置绘→右置字）；底部单行极简（风格 A） |
| **遮幅 letterbox** | 上下暖褐 letterbox **变体**（模拟 2.35:1 气质，实际收窄上下各 ~8%） | 2.35:1 **原生遮幅**（1920×817 有效画面） |
| **程序化背景** | 月盘偏上 1/3、山脊压底、光轴纵向 | 月盘偏立绘对侧、山脊横向多层展开、光轴斜射 |
| **卡点强特效落位** | 画面上下边缘（避字幕，§7 语音厅约束） | 画面左右边缘 + 遮幅内沿 |

**铁律**：换画幅 = 重排构图 + 重生成背景，不是 resize。程序化背景（月/山脊/渐变/粒子场）全部按目标画幅原生生成。

## 1. 铁律（每套风格、每一级、每一帧都适用 · 违规直接判定成片不合格）

| # | 铁律 | 判据 |
|---|------|------|
| **R1** | **立绘像素零改动** | 只允许：仿射（位移/缩放/旋转）、裁切换景别、alpha 边缘羽化/描边。**禁**：i2v/gpt-image 重画、liquify、改脸改造型、换色、贴滤镜改肤色。立绘身上的深色礼服=人物设定，不算违规。 |
| **R2** | **全暖色板** | 所有背景/包装/光效在暖板内取色：`CREAM #f8f4ea` `GOLD #d4af37` `PEACH #f4c7c7` `ORANGE #ff9a5c` `ROSE #f0aa96` `AMBER #e6af78` `WARM_WHITE #fff6e6` `INK #4a3426`。**禁**蓝紫（Dracula `#bd93f9/#ff79c6/#8be9fd`）、冷蓝调、暖红→冷蓝渐变。 |
| **R3** | **禁 AI 味深色画布** | **禁**自造深色画布（`#0a0e14/#141922` 一类）、Linear/Vercel/Cursor 式冷暗开发者美学。起手一律浅色/暖色。 |
| **R4** | **禁刻意冷渲染 · 冷题暖做** | 古风/温情基调禁白呼气雾、冷蓝调压暗。**"清冷/虐/压抑"支线一律暖化表达**，见 §3.4 冷题暖做转换表。 |
| **R5** | **真音源卡点** | 卡点时基必须来自真实音频的 librosa 节拍分析（`beats.json`），禁合成假 BGM、禁凭感觉硬凑时间码。 |
| **R6** | **palette gate 必过** | 成片抽帧跑 `python3 pipeline/gate_check_palette.py <png>`，H=240~290（蓝紫）占比 >5% 直接 fail。 |
| **R7** | **图层排序固定** | 见 §1.1，自上而下不可调换。 |
| **R8** | **防无感校验必过** | 见 §10，"效果添加了但肉眼无感" = 没做，机器 diff 门 fail-closed。 |

### 1.1 图层固定排序（自上而下 · 不可调换）

```
① 字幕/信息层            ← 最顶，任何东西不得遮字幕核心区
② 胶片/遮幅层            （颗粒、划痕、暗角、letterbox；暗角不压字幕安全区）
③ 光影层                 （轮廓光、扫光、局部提亮、光晕——可以叠在立绘之上）
④ 主体层：立绘           【最高保护级 · 严禁长期遮挡五官】
⑤ 氛围动态层             （粒子、流体、薄雾、光斑）
⑥ 衍生背景层             （原图/立绘模糊副本、渐变叠加层）
⑦ 底层：背景图
```

渲染实现顺序对应：`背景(⑦⑥) → 氛围(⑤) → 立绘+三件套(④③贴身部分) → 前景光影(③) → 胶片/遮幅(②) → 调色 → 字幕(①)`。

### 1.2 全局禁止清单

- ❌ 全屏长时间闪白、高频频闪
- ❌ 多层柔光、多层雾效重复叠加（互相抵消 + 画面发灰，只保留【1 层氛围 + 1 层光影】）
- ❌ 密集鼓点连续触发强特效（一拍一动 = 廉价短视频观感；改乐句卡点）
- ❌ 特效大面积覆盖人物面部与字幕区域
- ❌ 全程恒定参数（一切动效必须有【静态基准态 + 激活变化态】）
- ❌ 冷暖色系在一条片内跳切

> **元规范（提升 3 级）**：本手册每一层都给「地板 / 进阶 / **提升3级**」三档。
> 任何时候你觉得"这样够了"，那个"够了"就是标准定低了的信号——强制切到该层的**提升3级**档再验收。
> 依据 memory `feedback_gate-floor-not-target` · `feedback_build-to-reference-not-floor`。

## 2. 核心哲学：灵魂三件套（比边框/胶片感更本质 · 任何等级都先做这个）

一条纸片人 MV 好不好看，**第一决定因素不是边框和胶片感，而是立绘有没有「浮起来 + 有重量 + 跟着音乐呼吸」**。
这三件套决定了"纸片人"和"贴图 PPT"的区别：

### ① 描边光 Rim Light —— 让立绘从背景「浮」出来
- **地板**：沿立绘 alpha 边缘描一圈暖金半透明线。
- **进阶**：双层描边——内层暖白（`WARM_WHITE` 2px）+ 外层金色辉光（`GOLD` 高斯模糊 8px，screen 叠加）。
- **提升3级**：描边**跟卡点脉冲**（重拍瞬间描边亮度+粒度 ×2，随 `pulse(t, downbeats)` 衰减）；描边**方向跟主光源**（月盘方向那侧更亮，形成体积感）；出场时描边从一点**扫过整条轮廓**点亮立绘（显影感）。

### ② 投影 Drop Shadow —— 给立绘「重量」
- **地板**：立绘正下方一层柔性暖褐椭圆接触阴影。
- **进阶**：**双阴影**——贴地接触影（硬、小、深）+ 投射影（软、大、偏移向光源反方向）。
- **提升3级**：投影随立绘缩放/位移**实时联动**（push-in 时接触影收紧变深）；卡点缩放瞬间投影**先被压扁再回弹**（果冻物理错觉，纯靠影子形变，立绘不变）。

### ③ 卡点呼吸 Beat-Breathing —— 让立绘「跟着音乐动」
- **地板**：全程 `scale = 1 + 0.012*sin(t*2)` 微呼吸。
- **进阶**：重拍 `scale *= 1 + dbp*0.05` 缩放冲击 + 手持微抖 `shake`。
- **提升3级**：**速度斜坡**——切镜前 6 帧加速冲向下一拍，切镜瞬间急停（punch-in-then-settle）；副歌把呼吸频率对齐 BPM（`sin(t * BPM/60 * π)`），让每一次缩放都精确压在拍点上。

> **落地顺序铁律**：先把三件套做出来看效果，**再**按 §3 分级叠包装。
> 三件套没做，任何等级的边框和胶片感都只是给"贴图 PPT"化妆——观众照样划走。

## 3. 七级视觉强度体系（L1-L7 × 情绪支线 · 固定量化参数）

### 3.0 两轴模型（先分清"段落强度"和"成片档位"）

七级不是一条直线。**L1-L4 是"一条片内不同段落用多强"，L5-L7 是"整条片瞄多高"**：

| 轴 | 等级 | 语义 |
|---|---|---|
| **段落强度轴** | L1 弱包装 · L2 中等 · L3 较强 · L4 极强 | 同一条片内，按歌曲结构给不同段落分配 |
| **成片档位轴** | L5 院线质感 · L6 艺术电影 · L7 天花板 | 整条片的基底质感抬到哪一档（精品片用 L5/L6 **替代** L1/L2 做基底，不是叠加） |

**成片档位 → 段落分配表**（结合项目 `production_tier`）：

| 成片档 | 对应 production_tier | 开场钩子(0-6s) | 铺垫/主歌 | 副歌/高潮 | 情绪核心段 | 约束 |
|---|---|---|---|---|---|---|
| **标准片** | 探索/轻量 | L4 | L1/L2 | L3 | L3 | L3 总占比 ≤20% |
| **精品片** | 全量 | L4（按 L5 质感做） | L5 | L6 | L6 | L6 高光爆发每段最多 1 次 |
| **天花板** | 代表作/置顶 | L4（光学质感） | L7 基底 | L7 | L7 | 全片高光爆发仅 2~3 处 · 60fps |

**时长硬约束（违规 = 成片不合格）**：L3 全片占比 ≤20%；L4 单次持续 ≤6s、仅用于开头；L6 高光爆发一段镜头最多触发 1 次；L7 全片高光爆发 2~3 处，靠长期氛围取胜。

### 3.1 从三输入自动定级（七级手册的"读取情绪标签"在本项目怎么落地）

用户不标情绪，从音频 + 歌词推：

1. **结构分段**：librosa RMS 能量曲线 + onset 密度 → 切出 前奏/主歌/副歌/间奏/桥段/尾奏；副歌 = 高能量重复段（不确定时人工核对一次段落表，10 秒的事）。
2. **情绪标签**（三类）：歌词语义（告白/思念/离别/战意）+ 调式速度（大调快=甜/燃，小调慢=虐）→ 每段标 `甜/燃/虐` 之一 + 全片主情绪。
3. **支线查表**：

| 等级 | 甜/暖 | 叙事/稳 | 燃 | 虐/清冷 |
|---|---|---|---|---|
| L1 | L1-A | L1-B | — | L1-C |
| L2 | L2-A | L2-B | — | L2-C |
| L3 | L3-A | — | L3-B | L3-C |
| L4 | L4-A | — | L4-B | L4-C |
| L5 | L5-A | L5-B | — | L5-C |
| L6 | L6-A | — | L6-C | L6-B |
| L7 | L7-A | — | L7-C | L7-B |

4. **BGM 卡点事件分级**（全等级通用词汇表）：

| 事件 | 允许触发 | 限制 |
|---|---|---|
| **重鼓点** downbeat | 波纹、闪光、镜头推进、光影爆发 | **仅限 L3/L4/L6/L7** |
| **弱节拍** beat | 持续动态：雾流、缓慢扫光、呼吸缩放 | L1/L2/L5 只允许这类（持续运行不绑单拍） |
| **人声重音/停顿** | 仅局部光影微调 | **禁剧烈镜头运动**（保障字幕可读 · 语音厅MV硬性要求） |
| **乐句分割线** | 所有镜头转场、画面大变化 | **优先对齐乐句结尾**，不落拍间 |

### 3.2 L1-L4 段落强度级 · 固定参数表

> 参数为**固定量化值**，直接抄，不现场发挥。每级末行是「无感修正」：机器校验（§10）判无感时的第一修复动作。

#### L1 弱包装｜流水线保底级（铺垫段落 · 优先保障字幕可读）

| | L1-A 舒缓治愈 | L1-B 平稳叙事 | L1-C 虐向铺垫（暖化） |
|---|---|---|---|
| 背景 | A类柔和风景 / B类浅色低饱和 | A类清晰场景，保留细节 | B类**暖灰/墨褐**暗调渐变、暖雾深色 |

## 4. 五层包装系统（每层三档做法 + 参数 + 代码接口）

自下而上分 5 层，渲染顺序见 §1.1。**每层瞄提升3级档，不是地板档**；具体强度受 §3 等级约束（L1 段落用地板档也合规，L6/L7 必须提升3级档）。

### P1 · 背景场景层（Scene Backdrop）
把立绘放进一个**有纵深的场景**，而不是浮在纯色/渐变上。

| 档 | 做法 |
|---|---|
| 地板 | 暖色竖向渐变 + 中央径向光晕（`make_bg`） |
| 进阶 | + 大月盘（`make_moon`）+ 多层散景视差（`Field(depth)`）+ 移动光轴 god-rays（`light_shafts`）+ 暖云霭（`clouds`） |
| **提升3级** | + **3 层水墨山脊剪影**（远浅近深、视差，`make_ridges`）+ **真实宣纸/水墨纹理**叠底（CC0 宣纸 PNG，`multiply` 15%）+ 背景元素**跟卡点微动**（月盘卡点微亮、山脊卡点微位移）+ **景深虚化**（远层高斯模糊，近层锐利，L5 起错位 ≥8px） |

### P2 · 立绘落位与三件套层（见 §2）
代码接口：`place_doll()` + 待加 `rim_light(layer, dbp, light_dir)`、`drop_shadow(layer, scale, light_dir)`。

### P3 · 边框 / 版式层（Frame & Layout）
**核心原则：不要死框满框**（挤画面、廉价）。用局部装饰。

| 档 | 做法 |
|---|---|
| 地板 | 竖排词牌 + 一条金色竖线（现 `kinetic_text` 的 label 样式） |
| 进阶 | 四角纹样（云纹/回纹 PNG，暖金，低透明）+ 细金线框（非闭合，留气口） |
| **提升3级** | **动态框**——框随卡点**生长/擦除**（笔触从一角画到另一角）；**朱印**（红章 `#c0392b`，盖章瞬间 + 音效同步）；**卷轴/窗棂**边（按风格，见 §5）；框**跟景别联动**（特写用小框、全景去框） |

### P4 · 胶片质感层（Film Texture）

| 档 | 做法 |
|---|---|
| 地板 | 颗粒 `grain` + 暗角 vignette |
| 进阶 | + 漏光 `light_leak` + bloom 辉光 + halation（亮部暖色扩散） |
| **提升3级** | + **竖向胶片划痕 + 尘点**（随机竖线，每几帧刷新）+ **2.35:1 暖褐遮幅**（非纯黑，`INK` 加深；16:9 原生 / 9:16 上下变体，见 §0.4）+ **门闪 film-gate flicker**（整体亮度 ±2% 随机抖）+ **双重曝光**（副歌把上一镜立绘半透叠在下一镜）+ **化学显影色偏**（暗部偏暖褐、亮部偏奶金） |

### P5 · 字幕 / 排版层（Typography · 详见 §8）
古风 MV 的字是**画面的一部分**，不是附加的字幕条。

| 档 | 做法 |
|---|---|
| 地板 | 逐字弹入大标题（宋体，金描边，`kinetic_text`） |
| 进阶 | 竖排词牌 + 副标题渐显 |
| **提升3级** | **歌词卡点字幕**——每句按**人声起音时刻**逐字/逐词显影（笔锋"写"出来）；**书法笔触入场**（毛笔起收笔 alpha mask 显影）；**关键字放大**（金句核心字 ×1.5 + 描金）；**竖排右起**；字**避让立绘**（人物在左则字在右，动态排版） |

## 5. 风格预设库（6 套 Style Pack · 立绘像素都不变，只换外层包装）

每套是一个**完整配方**：定位 / 适用气质 / 配色（暖板内）/ 边框 / 胶片 / 光效 / 字幕 / 卡点侧重 / 差异化 / **适配等级**。
做新片时选 1 套为主，可局部混搭。**所有配色都在 R2 暖板内**，无一例外。

### 风格 A · 电影遮幅·极简 `cinematic-letterbox`
- **一句定位**：克制、高级、留白多，靠光影和运动撑场。最接近现代国乙官方角色 PV。
- **适用气质**：冷峻/矜贵/成熟男主（西装、长袍、军装）。**适配等级**：L5/L7 基底首选。
- **配色**：主 `CREAM` / 辅 `AMBER` / 强调 `GOLD`，暗部 `INK`。低饱和、大光比。
- **边框**：**2.35:1 暖褐遮幅**，四角极细金线，无满框。
- **胶片**：强——划痕 + 门闪 + halation + 化学色偏拉满。
- **光效**：单一主光（大 god-ray 斜射）+ 强边缘光。粒子极少（一两点飘尘）。
- **字幕**：底部单行极简 + 竖排小词牌。歌词一次一句、淡入淡出。
- **卡点侧重**：**切镜 + zoom-punch + 闪白**为主（少花哨），重拍落在遮幅微开合。
- **差异化**：靠"少"取胜——每镜一个主体、大量负空间。

### 风格 B · 古画卷轴·水墨 `ink-scroll`
- **一句定位**：最"国风"、装饰最满，宣纸水墨 + 卷轴装裱。
- **适用气质**：文人/侠客/古装（书生、剑客、王侯）。**适配等级**：L2/L5 叙事段 + L6-B 虐向。
- **配色**：主 宣纸米黄 `#efe0b0` / 辅 墨褐 `INK` / 强调 朱砂 `#c0392b` + `GOLD`。
- **边框**：**卷轴上下轴杆 + 窗棂/回纹侧边**，四角云纹。可做"展开卷轴"入场。
- **胶片**：中——宣纸纤维纹理叠底 + 淡墨晕，少划痕（古画不是胶片）。
- **光效**：柔和散射（阴天古画感），水墨晕开转场（笔刷擦除）。
- **字幕**：**竖排书法右起** + 朱印。歌词用毛笔笔锋逐字"写"出。
- **卡点侧重**：**水墨晕开/笔刷擦除转场** + 印章盖章卡点 + 花瓣/落叶随拍飘。
- **差异化**：转场全用水墨笔触，字全书法，最强东方装帧感。

### 风格 C · 朱砂工笔·浓彩 `gongbi-vermilion`
- **一句定位**：传统重彩工笔，浓艳、华丽、金碧辉煌。
- **适用气质**：华服/皇室/神话（凤冠、金甲、仙君）。**适配等级**：L3-A/L6-C 高光段 + L7-C 史诗。
- **配色**：主 `PEACH`+`ROSE` / 辅 朱砂 `#c0392b` / 强调 **真金 `GOLD` 描金拉满**。饱和高。
- **边框**：**描金重彩框** + 缠枝纹 + 宝相花四角，可满框（本风格本就华丽，唯一例外）。
- **胶片**：弱——工笔要清透，只留极淡颗粒 + 金粉飘落粒子。
- **光效**：**金粉/流光**为主（大量暖金粒子 + 流光线条），bloom 拉高。
- **字幕**：描金宋体 + 花钿装饰。歌词逐字描金显影。
- **卡点侧重**：**金粉爆发 + 流光扫过 + 描金脉冲**，重拍金光炸开。
- **差异化**：最"贵"最满，金色和粒子密度最高。

### 风格 D · 现代国乙·杂志 `modern-magazine`
- **一句定位**：无框满画幅 + 大字排版冲击，年轻、快、短视频卡点感。
- **适用气质**：都市/现代 AU/时尚（西装、街头、校园）。**适配等级**：L3/L4 高潮钩子段最猛选择。
- **配色**：主 `WARM_WHITE` / 辅 `ORANGE` / 强调 `GOLD`。干净高对比。
- **边框**：**无边框**，靠大字排版分割画面（英文/拼音大字压边）。
- **胶片**：中——轻颗粒 + 漏光，无遮幅（要满画幅）。
- **光效**：光效 + 粒子为主，节奏猛。
- **字幕**：**超大字卡点弹入** + 中英混排 + 关键词高亮。歌词大字快切。
- **卡点侧重**：**最猛**——每拍一个视觉变化，whip / RGB 错位（慎用，保持暖）/ 速度线 / 大字弹入 / 频闪切镜（注意 §1.2 禁高频频闪，密集段 ≤2s）。
- **差异化**：最快最猛，排版即设计，最像抖音爆款卡点。

### 风格 E · 暖金梦幻·琉璃 `dream-glow`
- **一句定位**：梦幻、柔焦、光晕流动，唯美耽美向。
- **适用气质**：温柔/病弱/精灵系男主（白衣、羽翼、花海）。**适配等级**：L2-A/L3-A 抒情段 + L6-A。
- **配色**：主 `WARM_WHITE`+`PEACH` / 辅 `AMBER` / 强调 `GOLD`。**全暖，绝不碰冷色**（梦幻≠冷，用暖金梦幻）。
- **边框**：柔性光晕虚化边（vignette 加强）+ 星芒装饰，无硬框。
- **胶片**：柔——强 bloom + 强 halation + 柔焦（整体轻高斯），少颗粒。
- **光效**：**光斑 bokeh + 星芒 flare + 花瓣雨**为主，一切都在发光。
- **字幕**：细体 + 柔光描边，歌词柔和渐显。
- **卡点侧重**：**光斑脉冲 + 柔性缩放呼吸 + 花瓣随拍**，卡点靠光而非硬切。
- **差异化**：最柔最梦幻，全画面发光，适合抒情段/副歌。

### 风格 F · 水墨留白·禅意 `zen-void`
- **一句定位**：极致留白、单色水墨、大道至简，高级冷淡但暖调。
- **适用气质**：出尘/宗师/隐士（道袍、僧衣、白发）。**适配等级**：L1/L5-B 铺垫段 + 前奏/间奏/收尾。
- **配色**：主 宣纸 `CREAM` / 辅 淡墨 `INK`（低透明）/ 强调 一点朱砂 `#c0392b`。近单色。
- **边框**：无框，超大留白，立绘偏置一侧（黄金分割）。
- **胶片**：极弱——宣纸纹理 + 一点墨晕，几乎无颗粒。
- **光效**：极简，一道淡光 + 偶尔一片落叶。
- **字幕**：极简竖排书法，一次一字，大量停顿。
- **卡点侧重**：**慢**——靠呼吸和留白节奏，卡点用极轻的位移 + 墨点晕开，重拍才一次大动作。
- **差异化**：反其道而行——用"静"和"空"制造高级感，节奏最慢，适合前奏/间奏/收尾。

> **一周形式 A/B 用法**：这 6 套天然是 6 种"视觉语汇"，可直接对应周维度 7 天差异化（见 CLAUDE.md 周形式 A/B 规则）。
> 同一角色同一立绘，套不同 Style Pack 出 6 版，是零新增素材的"完全不同形式"，可归因哪套数据最好。

## 6. 卡点动效字典（Beat → Effect 映射 · 可复用）

时基来自 `load_beats()`：`beats`（全部拍）、`downbeats = beats[::2]`（重拍）、`drop`（副歌/高潮，onset-strength 峰值标注 + 人工核对）。

| 拍类型 | 触发 | 动效候选（按强度） | 参数锚 | 等级限制 |
|---|---|---|---|---|
| **弱拍** every beat | `pulse(t, beats, 0.14)` | 描边微脉冲 · 粒子闪烁 · 呼吸微缩放 | scale +2% | 全等级 |
| **重拍** downbeat | `pulse(t, downbeats, 0.22)` | zoom-punch · 闪白 · 手持抖 · 投影压弹 · 月盘微亮 | scale +5%, flash 0.15 | **仅 L3/L4/L6/L7** |
| **切镜点** shot 边界 | `lt < 0.16` | 闪白 / 光扫切 swipe / zoom-blur match-cut / 水墨晕开（B风格） | 0.16s 转场 | 落在 downbeat **且优先乐句结尾** |
| **drop / 副歌炸点** | 标注时间码 | 粒子中心爆发 · 速度线放射 · 描边全亮 · 大字弹入 · 双重曝光叠影 · 遮幅开合 | 全 FX 叠加 | L3+ · 遵守各级爆发次数上限 |
| **人声起音** onset | librosa onset | 歌词逐字显影 · 字锋写出 | 对齐 onset 时刻 | 全等级 |
| **人声重音/停顿** | onset 强峰 | **仅局部光影微调** | — | **禁剧烈镜头运动**（字幕可读） |
| **间奏 / 留白** | 低能量段 | 慢呼吸 · 落叶/花瓣飘 · 光轴缓移（F风格靠这个撑） | 一切放慢 | 全等级 |

**卡点铁律**：
1. 切镜点**必须**落在 `downbeats` 上（不能落在拍间），且大转场优先对齐**乐句结尾**；
2. 重动效**必须**压在拍点 ±1 帧内，否则"卡点"就散了；
3. **拒绝一拍一动**——L1/L2/L5 的持续动效横跨多拍匀速运行；密集鼓点段禁连续触发强特效（廉价感）。

现有实现：`place_doll` 用 `dbp` 驱动缩放/抖动；`render_frame` 用 `bp/dbp` 驱动闪白/zoom-blur；转场用 `lt<0.16` + `shot.trans`。

## 7. 背景 × 光影 × 特效联动自适应规则（渲染前必查）

背景选定后，所有光效参数按背景性质**自动修正**（这一步决定"看得见"还是"糊一片"）：

| 背景判定 | 判据（可机器化） | 修正 |
|---|---|---|
| **亮色系背景** | 全帧亮度均值 > 60% | 所有光效、粒子透明度**统一 +20%**（亮色吞光效） |
| **深色暗调背景** | 亮度均值 < 30% | 所有光效透明度**统一 -15%**（防发白、丢层次） |
| **线条繁杂/元素密集**（花草、城市、C类立绘衍生） | 边缘密度高（Canny 边缘占比 > 阈值） | **删多层粒子流体，仅保留局部光影**；强卡点特效只放画面边缘 |
| **干净留白**（渐变、云雾、天空） | 边缘密度低 | 完整启用全套氛围动效 |

**语音厅 MV 专属约束（人声优先）**：
- 禁高饱和、高对比度背景（干扰居中字幕）；
- 所有强卡点特效放**画面上下边缘**，避开字幕区域；
- 人声重音/停顿处禁剧烈镜头运动（§6 铁律）。

**色系统一硬性要求**：单条视频背景色系统一（同在暖板内也不许大幅冷暖漂移）；跨段落色温变化只允许缓慢渐变（如 L6-A 的 5% 暖偏移），禁跳切。

## 8. 歌词字幕系统（字是画面的一部分）

1. **安全区**：字幕核心区按画幅定（9:16 底部 1/4 或竖排右侧列；16:9 立绘对侧留白区或底部单行，见 §0.4），任何特效/暗角/遮幅不得侵入；字幕不遮立绘五官（五官区 ≈ alpha bbox 顶部 1/5）。16:9 遮幅开启时字幕落在遮幅内沿之上，不压遮幅条。
2. **时基**：每句入场锚**真实人声起音**（`lyrics_timed.json`）；逐字显影用逐字 onset；无人声段（间奏）不出词，出词牌/落款。
3. **样式跟风格包**（§5）：A 极简单行 / B 竖排书法+朱印 / C 描金+花钿 / D 超大字快切 / E 柔光渐显 / F 一次一字。
4. **样式跟等级**（§3）：L1/L2 字幕克制（描边+淡入即可）；L3+ 才允许流光/弹跳/放大；L7 高光仅调光影**禁止放大**。
5. **可读性硬指标**：手机端（540×960 复检，§10）逐句清晰可读；描边 ≥2px；与背景亮度对比度不足时自动加半透衬底（L1-B 样式）。
6. **禁**：字幕条式白底黑字大条（廉价）；歌词错位/超前人声 >200ms。

## 9. 全流程 SOP（从三输入到外发 · 人工/AI 自动化通用）

```
① 画幅+素材入库 确认画幅（9:16 / 16:9，未指定默认 9:16，§0.3）；

② 音频分析    load_beats → beats.json；RMS/onset → 段落表（前奏/主歌/副歌/…+能量档）

④ 情绪定调    歌词语义 + 调式速度 → 全片主情绪（甜/燃/虐）+ 每段情绪标签

⑧ 三件套先行  描边光 + 投影 + 卡点呼吸（§2）先做出来看效果，再叠其余包装
⑨ 分镜        按 Shot 排镜：切镜落 downbeats + 乐句结尾 · 最长 3s 一镜 ·

⑩ 五层包装    §4 逐层叠，强度按 §3 各段等级参数表，档位瞄提升3级
```

**返工闭环**：⑬⑭ 任一 fail → 按 §10 诊断库定位 → 只改 1-2 变量重渲该段（逐段增量渲染，禁全片重渲当常态）→ 上限 3 轮，3 轮救不活换风格包/换等级方案并登记。

## 10. 防「无感/廉价/糊」强制校验（成片必检 · 机器 fail-closed）

原七级手册为肉眼工序，本项目升级为可机器执行的硬门：

### 10.1 四道机器门

| 门 | 检法 | fail 判据 | 修复公式 |
|---|---|---|---|
| **开关对比门**（防无感） | 抽 ≥5 帧（必含 1 重拍帧），逐效果 render FX-on/off 两版，算 mean abs diff | diff 过小 = 肉眼无差异 | 该效果**透明度 +20% / 运动幅度 +30%** 后重渲复检 |
| **小屏门**（双端预览） | 1080 帧 downscale 至 540×960 重跑开关对比 + 字幕可读检查 | 大屏可见小屏失效 | 参数 +20% |
| **动态基准门** | 每个动效参数的时间序列 std | std=0（全程恒定） | 违规，必须有基准态+激活态 |
| **卡点精度门** | 重动效峰值帧 vs 拍点帧 | 偏差 >1 帧 | 修时间映射，不是调参数 |

另：palette gate（R6）抽帧必过；遮挡检测——特效峰值帧的特效 bbox 不得压立绘五官区与字幕安全区。

### 10.2 故障诊断库（fail 后按序排查）

| 故障 | 排查顺序 | 修复 |
|---|---|---|
| **1 · 特效加了肉眼看不见** | 图层错位距离（L5 需 ≥8px）→ 透明度 → 是否全屏叠加互相抵消 → 动画时长 | 透明度 +20% / 运动幅度 +30%；各级"无感修正"行的锁定底线不可下调（如 L5 轮廓光 8%、L6 前景 ≥5%、L7 追光 4px） |
| **2 · 画面廉价、网红感重** | 是否频繁闪光 → 多层粒子叠加 → 一拍一动 | 删频闪；增加镜头时长；**节拍卡点改乐句卡点** |
| **3 · 画面脏乱发灰、层次消失** | 多层柔光/雾效叠加 → 光效铺满全屏 → 背景与特效线条重叠 | 只保留【1 层氛围 + 1 层光影】，删重复滤镜 |
| **4 · 高级感缺失、画面扁平** | **核心根源：缺「空间速度差、明暗差、虚实差」**——不是特效数量不够，是缺强弱对比 | 上 L5 双层景深（错位 ≥8px）/ L6 三层速度差（1.0/1.0/1.8）；给画面留静区，让动的地方"值钱" |

### 12.3 Style Pack / Level 参数 schema（建议 dataclass）
```python
@dataclass(frozen=True)
class StylePack:
    name: str
    palette: dict          # {main, aux, accent, ink} 全在暖板内
    frame: str             # none / letterbox / scroll / gilded / corner_only
    film: str              # heavy / medium / soft / paper
    light: str             # single_ray / diffuse / gold_dust / bokeh_glow / minimal
    type_style: str        # minimal / calligraphy_vertical / big_type / gilded / zen
    beat_bias: str         # cut_punch / ink_wipe / gold_burst / max_kinetic / glow_pulse / slow
    letterbox_ratio: float # 0=off, 2.35, 1.85...
    grain_amp: float
    bloom_strength: float
    particle_density: float

@dataclass(frozen=True)
class LevelParams:         # §3 参数表的代码化，按 "L3-A" 键查表
    breath_amp: float      # 呼吸缩放幅度
    breath_period: float
    fx_opacity: dict       # {mist, particle, sweep, rim, ...}
    bg_blur: int
    parallax_px: int       # L5+ 错位位移（≥8 硬门）
    layer_speeds: tuple    # L6 三层速度 (far, mid, fg)
    burst_budget: int      # 本段允许的高光爆发次数
    camera: str
    transition: str
```
6 套 = 6 个 `StylePack` 实例；21 个支线 = 21 组 `LevelParams`；`render_frame` 读 `pack + level` 决定各层参数。
这样"多种风格 × 多级强度"在**一份代码 + 两组 preset**里全覆盖，符合"skill≠template"（配方复用，非克隆分镜）。
