## 1. 导演编译目标

将三输入编译为可执行视觉总谱：

```text
歌曲结构决定什么时候变化
歌词语义决定画什么
人物关系决定谁前后相连
能量曲线决定画面有多强
素材条件决定使用哪种技术
```

导演层先回答“为什么出现这幅画面”，包装层再回答“它如何动、如何发光、如何排字”。禁止用包装参数替代叙事编排。

## 2. 输入与中间产物

### 最低输入

- 音频：真实 mp3/wav
- 歌词：LRC 优先，纯文本可对齐
- 人物立绘：一张或多张

### 尽量获取

- 人物姓名、身份、性格、关系
- 谁对应哪段歌词或声线
- 目标画幅、平台、时长、世界观
- 必须出现/禁止出现的内容

### 强制中间产物

```text
brief.json              需求契约
beats.json              BPM / beats / downbeats / onsets
lyrics_timed.json       逐句时间
music_map.yaml          段落、乐句、三级卡点、能量
character_map.yaml      导演功能、关系、出场预算
visual_score.yaml       逐镜机器可执行导演指令
asset_plan.yaml         已有/缺失/补图/i2v/来源
storyboard.md           给人看的分镜说明
animatic.mp4            低成本节奏验证
```

`visual_score.yaml` 未通过校验，禁止选风格包、生成正式素材或渲染成片。

## 3. 十二条硬规则

1. 先拆歌曲，后排立绘。
2. 每镜只承担一个主要导演任务。
3. 一级切点落在段落、乐句、主语或关系变化处，不为每个鼓点换镜。
4. 普通节拍驱动镜内事件，不滥用硬切。
5. 低能量用空场/单人/远景；高能量用双人/群像/特写/大字。
6. 副歌相对主歌至少提升六个能量旋钮中的两项。
7. 人物第一次出现说明身份，第二次建立关系，第三次推进选择、情绪或冲突。
8. 相邻镜至少共享颜色、主体、意象、空间或运动方向中的一项。
9. 转场从前镜尾帧开始设计，禁止事后随机套模板。
10. 单镜只保留一个核心动作；人物动作、复杂运镜、换景不可同时抢主位。
11. 高潮之后必须释放，以远景、空场、淡出或封面回归收束。
12. 角色一致性高于运动幅度；无法稳定实现的动作改为补图或确定性合成。

## 4. 音乐地图

### 4.1 先标宏观结构

标出前奏、主歌、预副歌、副歌、间奏、桥段、最终副歌和尾奏。每段记录：

- 时间范围
- 小节范围
- RMS/onset 能量
- 人声是否进入
- 情绪功能
- 1-5 级能量

### 4.2 三级卡点

| 级别 | 音乐位置 | 视觉事件 |
|---|---|---|
| 一级 | 段落、强重拍、主语变化 | 切镜、换角色、换空间 |
| 二级 | 乐句重音、关键词 | 改景别、人物进入、大字出现 |
| 三级 | 普通鼓点、装饰音 | 扫光、粒子、涟漪、微震动 |

规则：一级少于二级，二级少于三级。一级切点优先服从语义完整性；不要在歌词说到一半时切走主体。

### 4.3 时长建议

| 音乐能量 | 推荐镜头时长 |
|---|---:|
| 1-2 | 4-8 秒，或长镜内可见运镜 |
| 3 | 2-4 秒 |
| 4 | 1.5-3 秒 |
| 5 | 0.75-2 秒快切，或单镜连续重构 |

这只是起点，实际镜界必须落在真实音乐节点。

### 4.4 `music_map.yaml` 最小结构

```yaml
duration: 60.0
bpm: 96.0
sections:
  - id: verse_a
    time: [4.0, 12.0]
    music_role: verse
    energy: 2
    emotion: 克制叙述
cues:
  - at: 4.0
    level: 1
    source: phrase_start
  - at: 6.0
    level: 2
    source: lyric_accent
```

`source` 必须来自真实音乐分析或歌词时间，不写“凭感觉”。

## 5. 歌词语义地图

不要按字幕行机械拆镜；按完整意思拆语义单元。

| 语义类型 | 优先画面 |
|---|---|
| 人物身份、称号 | 单人英雄镜头、完整立绘 |
| 性格、信念 | 表情、姿态、象征物 |
| 环境、地点 | 空镜、全景、小人物 |
| 友情、爱情、敌对 | 双人关系、对视、背对、左右对照 |
| 冲突、决心 | 动作姿势、剑光、快速推近 |
| 回忆、遗憾、离别 | 背影、倒影、留白、外拉 |
| 世界观总结 | 群像、城市、山河 |
| 核心金句 | 巨型关键词，人物退为次级 |

用下式裁决字面与情绪冲突：

```text
字面环境词 + 当前情绪功能 + 人物关系 = 最终画面
```

例如“明月照千山”：孤独段用小人物与大月亮；团聚段用月下群像。

## 6. 人物与关系地图

### 6.1 定义导演功能

每个角色必须有本片功能，而不只是姓名：

```text
A：主视角，带观众进入世界
B：对手/挚友，制造关系张力
C：情绪核心，承担回忆与低能量段
D：行动角色，承担副歌和世界扩张
```

### 6.2 制定出场预算

为每个角色记录：首次介绍、单人、双人、动作、情绪、群像次数。除刻意主角占优外，主要角色有效曝光不得低于平均值 60%。

### 6.3 关系镜头是强制项

多角色片至少包含：

- 每个主要角色一次可识别的首次介绍
- 至少一组双人关系镜头
- 至少一次副歌/高潮群像
- 至少一次高潮后的关系或情绪回收

只有 A→B→C→D 轮播、没有双人关系的方案判“电子相册”，退回重排。

### 6.4 `character_map.yaml` 最小结构

```yaml
characters:
  - id: A
    name: 白衣角色
    director_function: 主视角，带观众进入世界
    traits: [克制, 正直]
    symbols: [月光, 剑]
    source_asset: assets/A.png
    appearance_budget: {intro: 1, solo: 2, relation: 2, group: 2}
relationships:
  - pair: [A, B]
    dramatic_function: 朋友与对手并存
    reveal_section: pre_chorus
```

## 7. 能量曲线

### 7.1 六个旋钮

| 维度 | 低能量 | 高能量 |
|---|---|---|
| 人物数量 | 空场、单人 | 双人、群像 |
| 景别 | 远景、全身 | 半身、特写 |
| 镜头速度 | 慢推、轻移 | 快推、快速重构 |
| 文字 | 小字、少字 | 巨型关键词 |
| 光效 | 雾、月光 | 闪白、剑光、强扫光 |
| 剪辑密度 | 4-8 秒 | 1-2 秒或镜内多事件 |

### 7.2 强度规则

- 主歌不提前用完全部手段。
- 副歌相对相邻主歌至少提升两项。
- 全曲峰值至少提升四项。
- 全程同一能量判 fail。
- 最强峰值通常不放在全片前 30%，但 0-3 秒钩子可短暂预演强画面。
- 峰值后必须出现至少一个低 1-2 级的释放镜头，除非歌曲在峰值直接截断。

### 7.3 60 秒四角色参考骨架

```text
0-4s    建立世界：空场/群像封面
4-12s   认识 A、B：两个单人镜
12-16s  建立 A-B 关系
16-20s  补全 C/D
20-28s  第一副歌：双人关系与群像
28-32s  情绪回落：C 特写/生活场景
32-36s  冲突准备：D/背影/动作准备
36-44s  第二次爆发：对抗/快马/剑光
44-52s  全曲峰值：群像与关键词
52-56s  情绪释放：远景/淡出/空场
56-60s  回到封面，完成闭环
```

时间不可生搬，必须重新贴合乐句。

## 8. 镜头语法

### 8.1 每镜先写导演任务

合格示例：

- 让观众第一次记住 A 的身份。
- 让观众意识到 A 与 B 既是朋友也是对手。
- 在副歌前让四个人第一次进入同一空间。
- 用 C 的特写降低能量，为下一次爆发准备。

“这张图很好看”不是导演任务。

### 8.2 单镜事件上限

一个 3-5 秒镜头最多包含：

- 一个主体事件
- 一个文字事件
- 一个装饰事件
- 一个转场准备事件

超过时拆镜。`primary_action` 只能是一件事。

### 8.3 四秒镜头节奏参考

```text
0.00  一级卡点：切入主体
0.50  小字/歌词进入
1.50  缓慢推近或人物显现
2.00  二级卡点：关键词出现
3.25  三级卡点：扫光/粒子增强
3.60  转场介质开始覆盖
4.00  一级卡点：切下一镜
```

24fps 下，大型动作通常提前 4-10 帧启动，让结果落在重拍。

## 9. 首尾帧与转场

### 9.1 首尾帧规则

- 首帧说明从哪里开始。
- 尾帧说明如何进入下一镜。
- 同镜只发生一个主要状态变化。
- 相邻镜共享一种可见元素。
- 先设计尾帧，再写动效或视频提示词。

### 9.2 接力结构

```text
人物化为水滴 → 下一镜从水滴落地开始
幕布完全闭合 → 下一镜从同色幕布打开开始
花瓣遮满画面 → 下一镜从花瓣散开开始
剑光扫过屏幕 → 下一镜沿同方向揭示
人物淡出为空场 → 下一镜使用同一空场或封面
```

### 9.3 转场决策

| 条件 | 使用 |
|---|---|
| 构图、颜色、主体位置相近 | 硬切 |
| 雾/幕布/花瓣覆盖超过 70% | 遮挡切 |
| 运动方向一致 | 动作匹配切 |
| 两镜安静但差异较大 | 6-10 帧短叠化 |
| 满月/白字占满画面 | 闪白或水墨遮罩 |
| 剑、冲突、强重拍 | 斜向光带揭示 |
| 完全不连续 | 补 1-2 秒过桥镜头 |

禁止默认旋转、翻页、立方体和随机缩放转场。

## 10. 技术路由与缺失素材

### 10.1 路由规则

```text
身份介绍/歌词/群像排版 → 2.5D
雾/花瓣/光带/摄影机运动 → 确定性合成
0.5-2 秒大字快切 → 静态图
转身/抬手/消散等有机动作 → i2v
缺侧身/背影/动作/关系姿势 → 先补生成图
```

### 10.2 源立绘与补图边界

- 源立绘使用项目合法来源类型（通常 `source_type: real_private`）并标记 `asset_role: source_portrait`，像素不可重画。
- 补姿势登记为 `source_type: synthetic_visual` + `asset_role: generated_supplement`，作为新资产保存。
- 补图必须引用角色源图，记录 prompt/provider/seed/成本。
- 检查脸、发型、服装结构、饰品、身高和身体比例。
- 补图失败三次，改写分镜，不继续赌随机结果。
- 中文标题和歌词由合成层排版，不让图像模型生成。

### 10.3 先从分镜反推素材

不要先漫无目的生成图。`asset_plan.yaml` 逐镜记录已有素材、缺失素材、生成方式、来源、身份检查和使用镜头。

```yaml
assets:
  - id: A_source
    path: assets/A.png
    source_type: real_private
    asset_role: source_portrait
    character: A
    used_by: [S02, S04]
  - id: A_back_pose
    path: generated/A_back_pose.png
    source_type: synthetic_visual
    asset_role: generated_supplement
    character: A
    source_refs: [A_source]
    required_by: [S07]
    purpose: 离别段背影
    generator: gpt-image-2
    prompt_file: prompts/A_back_pose.txt
    identity_checks: [face, hair, costume_structure, accessories, body_ratio]
    status: planned
```

`source_portrait` 永不被覆盖；生成补图必须使用新文件名和独立来源记录。

## 11. 视觉总谱

使用 `assets/visual-score.template.yaml` 起稿。每镜必填：

```text
id / 时间 / 音乐段落 / 能量
导演任务 / 数据杠杆
人物 / 歌词 / 构图
单一核心动作 / 三级卡点
首帧 / 尾帧 / 转场共享元素
技术路线 / 已有与缺失素材
```

### 11.1 导演评分

| 项目 | 权重 |
|---|---:|
| 音乐匹配 | 25 |
| 歌词语义 | 20 |
| 人物与关系推进 | 20 |
| 能量曲线 | 15 |
| 镜头连续性 | 10 |
| 素材可实现性 | 10 |

- 总分低于 80：重排。
- 任一项低于该项满分 60%：只重写对应部分。
- 硬规则失败：禁止进入素材生成。

## 12. 验收与返工

### 导演门

- [ ] 是否先完成 music_map 和 character_map？
- [ ] 每镜是否有唯一导演任务？
- [ ] 多角色片是否有关系镜和群像，而非角色轮播？
- [ ] 歌词主语与出场人物是否一致？
- [ ] 副歌是否比主歌至少强两项？
- [ ] 峰值后是否释放？
- [ ] 相邻镜是否有连续元素？
- [ ] 每镜首尾帧是否可画出来？
- [ ] 技术路线是否服从镜头任务？

### 返工顺序

```text
节奏错 → 改镜界和卡点
人物错 → 改角色分配和关系推进
能量平 → 改人物数/景别/文字/光效/速度
接不上 → 改尾帧、共享元素或补过桥镜
实现不稳 → 2.5D、补图、i2v 重新路由
包装弱 → 最后才调风格包和特效参数
```

不得用“再加特效”修复导演结构问题。
