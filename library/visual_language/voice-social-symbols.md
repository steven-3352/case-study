# 语音社交视觉符号语汇字典

## 摘要

**10 个跨平台通用可用符号 + 7 个平台专属禁用元素**  · 每个符号含"是什么 + 出现在业务哪个环节 + 建议用在 MV 哪一段"三要素。这是**候选池**不是必选清单 · 视觉语言策展师按情绪弧线二次筛选。

---

## 1 · 跨平台通用符号 · 可用（S1-S10）

| # | 符号 | 是什么 | 出现在业务哪个环节 | 建议用在 MV 的哪一段 |
|---|---|---|---|---|
| **S1** | 麦克风剪影（专业播音款 · 非直播款） | 上麦即"发声者身份"符号 | 主麦位/CV 上麦瞬间 | 前 3s 钩子 · CV 逐位亮相时叠加（每人 1 只麦替代传统头像框） |
| **S2** | 声波/波形/EQ 频谱 | 声音可视化 · 音频类内容通用 | 试听/直播/CV 献声全过程 | 中段声叠合高潮 · 多条不同颜色的波形叠加暗喻"真同框" |
| **S3** | 耳机/头戴式耳机剪影（深黑款 · 非游戏电竞款） | 深夜私密收听场景 | 用户进厅/沉浸消费 | 前 3s 或末段收束 · 暗喻"这是给耳机党的" |
| **S4** | 月亮/月光/月轨圆环 | 深夜时段 · 私密氛围 · 与深夜 MV 主题呼应 | 深夜厅/情感陪聊时段 | 全片背景基调可用 · 尤其深夜段落 |
| **S5** | 烛光/暖光光晕 | 温暖陪伴氛围 · 反冷色调 | 陪聊厅/私厅氛围 | 中后段情绪高潮 · 群像叠合时的暖光烘托 |
| **S6** | 老式收音机/电台按钮（不是 app UI） | 深夜电台隐喻 · **情绪叙事的核心视觉锚**（对治 app 元素） | 内圈受众"想找深夜电台"心理位移 | 前 3s 反差钩子 或 末段收束（作为"这不是语音厅 app · 是深夜电台"的隐喻） |
| **S7** | 粒子/星尘/漂浮光斑 | 声音在空气中的可视化 · 抽象 | 声音扩散/情绪扩散 | 全片可作转场层 · 尤其声叠合高潮 |
| **S8** | 单色几何抽象（圆/长条/竖线）作"麦位阵" | 8 麦位圆环 UI 的**去 app 化抽象**（保留"多位声音并列"符号但去 app 元素） | 麦位/CV 阵容展示 | 中段并列出现 · 4 个圆/方位并列（对治单人全屏） |
| **S9** | 卷帘幕布/黑丝绒/剧场大幕 | 舞台感 · 演出感 · 剧场 CV 献声 | 主麦上麦"开演" | 前 3s 或每位 CV 亮相前的转场（"开幕"感） |
| **S10** | 风/纸片飘落/竹叶/花瓣 | 古风/日韩风景延伸 · 立绘元素外延 | 特定风格 CV 段落（古风/日韩系） | 逐位亮相时叠加对应元素（竹叶/花瓣） · 差异化视觉 |

**分层使用建议**：
- **S1-S3** = 声音社交通用锚 · 全片贯穿
- **S4-S7** = 氛围底色 · 按情绪弧线分段用
- **S8-S10** = 差异化拆件 · 逐位 CV 各配 1-2 个专属

## 2 · 平台专属禁用元素（N1-N7）

| # | 禁用元素 | 禁用理由 |
|---|---|---|
| **N1** | Soul 星球图标 / 灵魂匹配 UI | Soul 专属 · 一出现下游复盘直接判"变 Soul 广告" · 违反"平台无关"硬约束 |
| **N2** | TT 麦位圆环 UI / 声控专区标识 | TT 专属 · 圆环 8 麦 UI 是 TT 标志性视觉 · 直接用会污染 skin · 用 S8"单色几何抽象"替代同一功能 |
| **N3** | 贡献榜/魅力榜第 1 名图标（皇冠/王座/钻石框） | 直接触发内圈弃坑受众"氪金求存在感"抗拒记忆（`library/quotes/voice-social/churn-anti-monetization.md` 印证） |
| **N4** | 具体 app logo（Soul 圆蓝紫、TT 红黄、克拉粉、兔耳紫等） | 任何具体 app logo 出现都违反"软 CTA · 平台无关" · 运营文案也不带 |
| **N5** | 具体房间截屏/进厅进度条/送礼动画 | 直接暴露 app UI · 触发内圈"又是老掉牙广告"抗拒 · 违反心理位移禁触发 |
| **N6** | PK 对战 UI / 相亲头像墙 / 才艺连麦 UI | "陪聊/PK/相亲"隐喻反例（`library/quotes/voice-social/awkward-fatigue.md` 印证） · 全片禁 |
| **N7** | 福利倒计时 / 限时优惠 / 首充送 XX 弹窗式画面 | 平台推广老套路 · 硬导流 · 违反软 CTA |

## 3 · 使用协议

**视觉语言策展师起手前必查**：
- [ ] 每个候选符号是否属 S1-S10？（不属 = 需说明理由）
- [ ] 是否触发 N1-N7 任一？（触发 = 立即替换）
- [ ] 起手方向是否包含至少 1 个浅色画布？（memory `feedback_no-ai-visual-dark-canvas` 铁律 · 不得让暗色成为唯一默认）

**动画导演/摄像分镜前必查**：
- [ ] 每个分镜的视觉元素是否 ≥ 1 个 S 符号？
- [ ] 是否触发 N1-N7？（触发 = 返工）
- [ ] 全片视觉家族数量 ≥ 5 种？（对治 v2 形式单一）

**封面设计前必查**：
- [ ] 从 S1-S10 直接选 3 个作候选（S 符号覆盖率 ≥ 30%）

## 4 · 特殊补充

### 4.1 · 4 CV 差异化专属飘落元素（S10 的具体化）

对治 v2 "4 人都长一样" 病灶 · 每位 CV 独立配对 · 视觉差异化关键：

| 风格特征 | 建议飘落元素 |
|---|---|
| 现代绅士/低音陪聊 | 光粉尘（暖色 · 慢降）|
| 街头暗黑/摇滚 | 火星/暗色粒子（跳跃 · 短生命）|
| 古风书生 | 竹叶（旋转 · 慢降）|
| 日韩系温柔 | 花瓣（飘 · 中速）|

（本 4 类分配是从 v3 语音厅立绘反推的建议 · 具体项目应按实际立绘美术风格重新映射）

### 4.2 · 与 gate_check_palette.py 联动

**已有兜底**：`pipeline/gate_check_palette.py` 检测主色域 HSL H=240~290（蓝紫）占比 >5% fail-closed · pre_publish 必过。

配套铁律见 memory `feedback_no-neon-palette`：
- 禁 Dracula 紫 `#bd93f9` · Dracula 粉 `#ff79c6` · Dracula 青 `#8be9fd`
- 禁暖红→冷蓝渐变
- 强调红用 `#e53935` 不用 `#ff5252`
