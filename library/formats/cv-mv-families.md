# CV MV/群像 MV 现存做法 · 三大家族

## 摘要

**CV MV/群像 MV 现存做法可归为 3 类家族** · 每类含代表做法 + 具体案例 + 表达上限 + 与不同选题的距离评估。给形式策略官 + 编导 + 留存节拍设计师作**候选池对比基准** · 不必闭门造车。

---

## 家族 A · CV 阵容字幕直给型（卡牌 PV / 广播剧 PV）

### 代表做法
- 前 3s 直接打字幕"XXX × XXX × XXX 联合献声"或"XX 阵容首次同框"
- 立绘快切 · BGM 高潮切入
- 靠 CV 名字本身的号召力抓中圈

### 具体案例
- B 站广播剧 PV 通行做法
- 豆瓣配音/CV/广播剧豆列 · https://www.douban.com/doulist/152058785/ · 聚合《六爻》《小蘑菇》《两不疑》《苍兰诀》《杀破狼》《默读》《相见欢》等作品的 CV 阵容展示

### 表达上限
- **中低**
- 依赖 CV 知名度
- 对外圈路人几乎无效（不认识 CV）

### 与不同选题的距离
- **中圈 CV 声控** 40% → 强
- **外圈路人** 40% → 弱
- **单一使用会输前 3s 划出**（外圈划走）
- **建议**：只在中段用 · 不放前 3s

---

## 家族 B · 高燃快剪群像混剪型（B 站群像剪辑家族）

### 代表做法
- BGM 强节奏踩点
- 群像人物快切 · 每人 0.5-1.5s
- 短时间内展示"人多阵容强"感
- 常用《Sold Out》《Believer》《惊鸿一面》等高节奏 BGM

### 具体案例
- 数英文章"B 站自制剧仰卧起坐" · https://www.woshipm.com/share/5883453.html
  - 提到 B 站 UP 主"三千鱼"的混剪拉郎影视视频最终催生了《古相思曲》剧集
- CSDN "B 站影视剪辑区谁的出镜率最高" · https://blog.csdn.net/aotodata/article/details/104809829 · 分析群像剪辑高频人物

### 表达上限
- **中高**
- "群像感"密度靠快切累积
- **但对静态立绘物料而言 · 快切 ≠ 有效动作变化**
- 需配合 zoompan/遮罩形变 · 否则回到 v1 事故（PPT 感）

### 与不同选题的距离
- **CV MV / 阵容展示** → 强
- **与 v3 立项单要求"6 运镜 × 5 转场"方向一致**
- **建议**：主要参考此类型 · 但需动效技术导演拆出"快切 + 单镜内位移 ≥12%"的组合方案

## 家族 C · 情绪叙事氛围型（MV 情绪叙事家族）

### 代表做法
- 跟 BGM 情绪曲线走
- 前 3s 反差钩子（chaos → punch → reveal 三连 · memory `feedback_contrast-hook-3s`）
- 中段情绪推进
- 末段收束回味
- 不靠"人多"靠"氛围"

### 具体案例
- 抖音"深夜情感音乐"账号 · https://www.chuanshenggang.com/media/detail/88595 · 定位"深夜里的隐形陪伴者"
- 抖音早睡电台直播账号"@迅猛龙特蕾莎" · https://tech.chinadaily.com.cn/a/202204/07/WS624e97fea3101c3ee7acf4ff.html · 累计观看 53 万 · 点赞 17 万 · 主打治愈氛围

### 表达上限
- **高**
- 但对静态立绘物料而言 · 氛围推进主要靠色板/滤镜/BGM 情绪层次
- **视觉语言策展师 + 声音设计师是关键**

### 与不同选题的距离
- **深夜声音陪伴 / 都市青年情绪层** → 强
- **CV 阵容展示** → 中
- **建议**：作为基座 · 与家族 A/B 组合

---

## 组合策略建议

**单一家族都不够** · 推荐组合结构：

| 段落 | 主家族 | 叠加家族 | 说明 |
|---|---|---|---|
| 0-3s | 类型 C 反差钩子 | 类型 A 阵容字幕 | 混合 · 兼顾外圈情绪抓取 + 中圈稀缺感 |
| 3-15s | 类型 A 逐位亮相 | 类型 B 快切叠加 | 阵容展示 + 群像快剪 |
| 15-35s | 类型 B 高燃快剪 | 类型 C 情绪高潮 | 群像叠合 + 情绪推进 |
| 35-53s | 类型 C 收束 | — | 单一 · 让观众回味 |

## 数据基础

| 类型 | 平均时长 | 每人镜头时长 | 转场频次 |
|---|---|---|---|
| A · 阵容字幕 | 30-60s | 1.5-3s | 中（10-15 次/分） |
| B · 高燃快剪 | 60-120s | 0.5-1.5s | 高（30-50 次/分） |
| C · 情绪叙事 | 45-90s | 3-8s | 低（8-15 次/分） |

抖音同人 MV 大盘：**≤30s 短片占主流** · MV 类因 BGM 需要通常 45-60s。
