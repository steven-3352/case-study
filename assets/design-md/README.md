# DESIGN.md 参考库

这里存放从 `awesome-design-md` 等来源精选来的视觉语言参考，用于视觉语言策展师产出 `publish/{week}/Dxx-*/design/design_language.md`。

## 使用规则

- 只保存本账号常用的少量参考，不全量复制外部仓库。
- 参考文件用于萃取色板、字体层级、组件、布局和 Do/Don't，不用于品牌仿冒。
- 每条内容必须把参考本地化为 `design/design_language.md`，不能直接把某个 `DESIGN.md` 当成成片风格命令。
- 若参考来源是具体商业品牌，禁用 logo、商标、品牌专有文案和可识别包装。

## 推荐初始参考

| 场景 | 可选参考 | 用途 |
|------|----------|------|
| AI 工具 / 系统演示 | Linear / Vercel / Cursor | 暗色产品截图、克制 accent、开发者质感 |
| 小红书图文 / 清单 / 字段表 | Notion / Airtable / Mintlify | 明亮卡片、标签、知识库/表格结构 |
| 观点复盘 / 强标题图文 | WIRED / The Verge | 编辑部、杂志感、强标题层级 |
| 小老板流程自动化 | Zapier / Intercom / Shopify | 亲和、流程化、SaaS 可理解 |
