# 本人参考照片

> ⏸ **暂停**：当前视频不出真人/数字人，自拍非必须。恢复数字人时再拍。

## 放哪里（恢复时用）

把自拍文件直接放进本目录，例如：

```
assets/avatar/reference/
├── front.jpg          # 正面
├── front_slight.jpg   # 正面微侧
├── left_30.jpg        # 左 30°
├── right_30.jpg       # 右 30°
└── desk.jpg           # 半身 + 桌面背景（可选）
```

支持 `jpg` / `jpeg` / `png` / `heic`（HEIC 建议导出为 jpg 再上传 SaaS）。

## 数量与角度

| 建议 | 说明 |
|------|------|
| **3–5 张** | 大多数数字人工具的最小要求 |
| **正面 1–2 张** | 直视镜头，自然表情 |
| **左右侧脸各 1 张** | 约 15°–30°，不要极端侧脸 |
| **半身 1 张** | 露到胸口，背景干净（书房/桌面） |

## 拍摄注意

- **光线**：脸亮、背景略暗，避免大逆光
- **背景**：书房、书架、桌面；不要绿幕感、不要滤镜过重
- **表情**：正常说话状态，嘴微张或闭合均可，**不要夸张笑**
- **眼镜**：常戴就戴，和不戴保持一致
- **衣服**：偏日常商务休闲，避免纯黑纯白大块（抠像工具有时吃亏）

## 不要放这里

| 文件 | 应放位置 |
|------|----------|
| 口播录音 | `assets/avatar/dry_audio/` |
| 数字人生成成品 | `assets/avatar/exports/` |
| 固定背景图 | `assets/avatar/scenes/` |
