# 报价草稿演示小工具 · W27X06

本地可演示的「自动报价草稿」页面，供小红书轮播录屏/截图（证据优先）。

## 打开

```bash
open pipeline/demo_tools/quote_draft/index.html
```

或用 Chrome：

```bash
open -a "Google Chrome" pipeline/demo_tools/quote_draft/index.html
```

## 演示脚本（建议录屏 15–20s）

1. 左侧改「客户名 / 项目类型 / 备注」
2. 改一行明细数量或单价
3. 点「生成草稿」→ 右侧即时出新版报价
4. 可选点「复制全文」
